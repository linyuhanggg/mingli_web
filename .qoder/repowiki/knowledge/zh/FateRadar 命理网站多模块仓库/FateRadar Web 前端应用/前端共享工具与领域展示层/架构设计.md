本模块是纯函数式与数据模型型的前端共享库，按职责拆分为若干独立文件，彼此通过 TypeScript 类型和少量 import 耦合：
- `api.ts` 作为 HTTP 客户端入口，集中定义所有后端请求/响应类型（Profile、Reading、Account 等），封装 `requestJson`/`jsonPost`，统一处理 CSRF Token（从 Cookie 读取或调用 `/api/v1/guest-sessions`）、403 自动重试、幂等键（`Idempotency-Key` 头）以及 `ApiError` 异常；对外暴露 `createProfileDraft`、`startPreviewReading`、`pollReading`、`getReadingResult` 等用例级函数。
- `reading-display.ts` 将后端 `ReadingFact[]` 转换为面向 UI 的 `FactPresentation` 与 `BaziChartView`，内置字段标签映射表（性别、时间口径、子时策略、四柱、月令、目标周期等）与敏感键过滤（`SENSITIVE_KEY`），保证不向用户展示内部 token/prompt 等值。
- `chart-workspace.ts` 在 `reading-display` 之上构建“命盘工作区”视图模型（`ChartWorkspaceView`），仅做纯展示映射，明确声明“不在前端排盘或推算”，缺失层以 `unavailable`/`empty` 状态呈现。
- `fortune-period-markers.ts` 从 `ReadingFact` 中抽取周期标记，复用 `reading-display.formatDateTimeLike` 做日期格式化。
- `date-time.ts` 基于 `Intl.DateTimeFormat` 计算指定 IANA 时区在给定本地时间的真实 UTC 偏移，用于修正夏令时边界。
- `iana-timezones.ts` 维护完整 IANA 时区白名单并提供 `isIanaTimeZone` 校验。
- `product-capabilities.ts` 集中声明三大产品能力（bazi/fortune/liuyao）及其导航、首页文案、页脚链接，派生 `PUBLIC_PRIMARY_NAVIGATION`、`PUBLIC_UTILITY_NAVIGATION`、`PUBLIC_FOOTER_APPLICATIONS` 等只读常量。
- `idempotency.ts` 基于 `JSON.stringify(intent)` 指纹生成稳定幂等键，避免重复提交。
依赖方向单向：业务展示层（chart-workspace、fortune-period-markers）依赖 api 的类型定义与 reading-display 的格式化能力，但 api.ts 不反向依赖任何展示逻辑。
