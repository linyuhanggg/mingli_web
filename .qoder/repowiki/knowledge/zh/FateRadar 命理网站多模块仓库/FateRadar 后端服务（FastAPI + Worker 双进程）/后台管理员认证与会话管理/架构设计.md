模块按分层组织：`models.py` 定义 SQLAlchemy ORM 模型 `StaffUser`、`StaffSession`、`AdminAuditEvent`（继承自 `app.identity.models.Base`），并通过唯一约束与索引限定 staff 邮箱、状态、token_hash 等字段；`schemas.py` 使用 Pydantic v2 声明 API 请求/响应结构，并枚举受支持的 `StaffRole`（support/finance/ops/superadmin）；`repository.py` 封装对 `AsyncSession` 的只读查询与写操作（按 email 查 active staff、按 token_hash 查有效 session、revoke_session、添加审计事件），将持久化细节从业务层隔离；`service.py` 中的 `AdminAuthService` 编排登录流程（校验凭据→可选 bootstrap 创建首个 superadmin→生成 opaque token/csrf_token→写入 session 与审计事件），并提供 `build_stub_overview` 返回占位 KPI；`passwords.py` 仅依赖 stdlib 实现自定义 scrypt 编码格式（`scrypt$N$r$p$salt$digest`）；`cookies.py` 通过 FastAPI `Response.set_cookie/delete_cookie` 设置 `mingli_admin_session`（httponly=True）与 `mingli_admin_csrf`（httponly=False）两个专用 cookie，安全参数取自 `app.config.Settings`。依赖方向单向：service → repository → models，service 还依赖 `app.identity.security` 做通用 token hash，不反向依赖上层路由。
