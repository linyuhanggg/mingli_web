# METIS / 青囊视觉相关片段摘录

> 摘自 `2026-08-12-reference-site-audits` 两份产品审计。**原文是只读页面走查，没有采集配色值、字重、圆角、阴影这类视觉工艺数据**——下面只是把审计里出现的响应式断点、尺寸和版式信息挑出来，供你判断密度与版式基调，不是完整的视觉规范。

## 响应式断点（实测，非估计）

- **METIS**：起盘页导航切换点约 520px（不是 768px）；结果工作台在手机宽度直接纵向重排；768px 起强制左右两栏。
- **青囊**：导航断点实测 768px——767px 及以下用精简顶栏 + 固定五项底栏 + 全屏抽屉；768px 起完整桌面顶栏，取消底栏。

## 盘面/工作台版式尺寸

**METIS 结果工作台**（左盘右读两栏）：

| 视口 | 左栏（盘） | 右栏（读） |
|---|---|---|
| 360×800 | 520px 盘缩放后置顶，下接解读，整页约 7700px 长 | — |
| 768×1024 | 固定 520px | 仅剩约 237px（拥挤） |
| 1024×768 | 固定 520px | 约 493px |
| 1440×900 | 固定 520px | 约 909px |

METIS 顶栏高度 52px（1440 下）。审计明确指出 768px 竖屏右栏过窄是缺陷，建议断点应让阅读栏不低于 360px。

**青囊各术数结果页**（360 / 1440 两档实测）：

- 八字：360 下四柱仍四列，单格约 47px；1440 下日主气数从单列变 `100px + 522px`，大运流年从五列变十列。
- 紫微：360 下十二宫盘压成 4×4，盘宽约 316px。
- 七政：360 下主星盘 SVG 自适应约 322×322。
- 三术合参：1280px（Tailwind `xl`）起才从堆叠变左右双栏，1440 实测约 698px + 664px。

## 表单密度

- 青囊八字输入表单：360 下外框约 304px，内容约 224px；768 起固定约 670px 居中。360 下年月日时仍硬塞四列，`select` 可点击区域约 21×20px——审计标注为负面案例（偏挤），建议小屏改 2×2 或用底部选择器。
- METIS 起盘表单：432px 居中，各视口不变。

## 皮肤/主题提法（仅提法，无具体色值）

青囊个人中心「偏好」下有三套皮肤：**华彩、素简、墨夜**——审计只记录了名称，未展开每套皮肤的具体配色或字体差异。

## 明确没有的数据

两份审计都不含：色板/色值、字体族、字号阶梯、字重、行高、圆角半径、阴影层级、间距系统、图标风格、动效时长。这些如果要对齐，需要单独做一次针对性的视觉走查（截图 + 取色/量尺），而不是复用这两份产品结构审计。
