# 增广沈氏玄空学 — Procedures

## SP-01 查询流程

1. 先读 `validation.md` 确认版本限制。
2. 查术语时读 `terms.md`，再用 `chapter-map.md` 定位原文。
3. 涉及“论玄空/论紫白/论下卦/论起星”等理论问题，读取对应正文 done 章节。
4. 涉及阴宅、阳宅案例，只作历史案例说明，不输出现实应验承诺。
5. 涉及挨星图、分金表，回到 raw HTML/image refs；未结构化前不得给出完整表格。

## SP-02 与风水主 skill 的关系

- 形峦问题优先查 `hanlong-jing`、`yilong-jing`、`xuexin-fu`。
- 理气玄空问题可查本 pack。
- 蒋大鸿/青囊系源流问题优先查 `dili-bianzheng`、`qingnang-jing`、`tianyu-jing`。
- 择日问题不要从本 pack 派生，转到 selection 层。

## SP-03 安全输出

- 输出措辞使用“沈氏玄空文本中如何论述”。
- 不给现实住宅、墓地、家族、财运、疾病、灾祸做确定判断。
- 不承诺改门、改向、安葬、迁居会带来具体结果。
