## 测量纪律

1. 每个指标的评价窗口为自然月（可用性）或演练当次（RTO/RPO）。
2. 计划维护窗口必须提前公告并计入可用性，不得通过不公告维护粉饰指标。
3. 模型生成耗时只计入「解读任务收敛」，不计入非模型 API 延迟。
4. 区域级灾难不纳入 P0 可用性承诺；P2 再以跨地域备份/OSS 复制/DNS 切换覆盖。
