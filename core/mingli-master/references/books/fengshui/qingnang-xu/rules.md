# 青囊序 — Rules

> 理气水法核心规则；所有 verified 为 false。涉吉凶规则均加 caveats 现代使用边界。

## R-01: 看雌雄认金龙察血脉

- **source_chapter**: s1-cixiong
- **rule**: 杨公养老法以"看雌雄"为总；先看金龙动不动、次察血脉认来龙；龙分两片阴阳取，水对三叉细认宗。
- **applicable_to**: 理气派水法总纲
- **caveats**: 现代使用边界：仅作文化研究参考。
- **verified**: false

## R-02: 山管山，水管水

- **source_chapter**: s2-shanshui
- **rule**: 山以山为对、水以水为对；山管山兮水管水，此是阴阳不待言；不可混淆。
- **applicable_to**: 理气派山水分论原则
- **caveats**: 现代使用边界：仅作文化研究参考。
- **verified**: false

## R-03: 二十四山四十八局

- **source_chapter**: s3-24shan
- **rule**: 先天罗经十二支、后天再用八干四维辅正位，共二十四山；二十四山分顺逆，共成四十八局；五行从此中分，祖宗从阴阳出。
- **applicable_to**: 理气派罗经基础
- **caveats**: 现代使用边界：具体局位推演必须使用 tool.fengshui.luopan，严禁手算。
- **verified**: false

## R-04: 净阴净阳前后八尺不宜杂

- **source_chapter**: s4-jingyinyang
- **rule**: 用净阴净阳法时，前后八尺不宜杂；斜正受来阴阳取，气乘生旺方无煞。
- **applicable_to**: 理气派纳气精度判断
- **caveats**: 现代使用边界：仅作文化研究参考；具体精度由 tool.fengshui.luopan 判定，不可手算。
- **verified**: false

## R-05: 山龙水龙不交涉

- **source_chapter**: s4-jingyinyang
- **rule**: 山上龙神不下水、水里龙神不上山；用此量山步水，百里江山一饷间。
- **applicable_to**: 理气派山龙水龙分判
- **caveats**: 现代使用边界：仅作文化研究参考。

- **source_chapter**: s5-shengwang

- **applicable_to**: 理气派城门水法
- **caveats**: 现代使用边界：仅作文化研究参考。

## R-07: 直射直流家业退

- **source_chapter**: s5-shengwang
- **rule**: 截定生旺莫教流，直射直流家业退；射破生方定少亡，沖破旺位财狼藉。
- **applicable_to**: 水法凶煞判断
- **caveats**: 现代使用边界：仅作文化研究参考；"少亡""家业退"为古代水法评价语，不作现代决定论陈述。

## R-08: 进退神生入克入

- **source_chapter**: s6-jintui
- **rule**: 生出克出名为退、生入克入名为进；进神宜进则家资旺，进神若退则家不兴；退神宜退亦同旺，退神若进则主官刑。
- **applicable_to**: 水法进退神判断
- **caveats**: 现代使用边界：仅作文化研究参考；具体进退判断由 tool.fengshui.luopan 完成。
- **verified**: false

## R-09: 公位水神配八卦三男三女

- **source_chapter**: s7-gongwei
- **rule**: 乾坤艮巽长男兴、寅申巳亥长伶丁；甲庚丙壬中男发、子午卯酉中男杀；乙辛丁癸小男强、辰戌丑未小男殃。
- **applicable_to**: 水法公位人事判断
- **caveats**: 现代使用边界：仅作文化研究参考；"长男杀""小男殃"等表述为古文措辞，不作现代决定论陈述。
