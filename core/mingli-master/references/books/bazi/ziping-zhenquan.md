## Position In Lineage

- 在八字子平体系中的位置：**格局派精修版**，是《渊海子平》格局雏形的系统化。
- 与上游：
  - 《渊海子平》：本书格局思想的直接雏形来源。
  - 《三命通会》：本书格局思想与《三命通会》的格局章节互为旁证。
- 与下游：
  - 《滴天髓阐微》：本书从格局视角出发，滴天髓从旺衰气势视角出发；二者是子平两主线。
  - 《穷通宝鉴》：本书不主调候；调候由《穷通宝鉴》精修。
  - 《神峰通考》：与本书略同期（同为清乾隆间），可互为旁证。

简言之：**格局成败救应 = 子平真诠；气势生克通关 = 滴天髓阐微；调候 = 穷通宝鉴；三者是子平三大精修派别。**

## Core Concepts

> 仅列入本 pack 用于路由 / 解释 / 互证的关键概念。

- **月令格局**：以月令所藏本气透干为优先取格；本气不透看中气、余气。
- **用神（格局派）**：本书"用神"指格局之所需（格局的核心干支），**不同于** 旺衰派"用神"（扶抑之神）。
- **相神**：辅助格局成败的干支；格局成败救应的关键变量。
- **顺用 / 逆用**：
  - 正官、正印、正财、食神 → 顺用（生扶）。
  - 七煞、伤官、偏印（枭）、偏财 → 逆用（克制、化、合）。
- **格局成败**：
  - 成格条件：格局清纯、相神得用、无破格之神。
  - 败格条件：破格之神出现且无救应。
- **救应**：格局被破格之神所坏，但有另一干支救应（合、制、化）→ 格局可回成。
- **外格**：不属于标准八格（正官、七煞、正财、偏财、食神、伤官、正印、偏印）的特殊格局。
- **建禄 / 月刃（阳刃）**：本书不取为格，以扶抑论。

## Operational Rules

> 本节只列**路由级、可被主 skill 调用**的判断要点；不抄录原文段落。

### R1 排盘前置

- 八字推演前必须有**确定的四柱**。
- 本书不替代排盘工具；遇到事实层未确定的盘，主 skill 必须先调用 `tool.bazi.paipan`。

### R2 月令为本（精修版）

- **取格优先月令本气透干**：本气透干 → 以本气取格。
- **本气不透**：看中气、余气；若中余气皆无透，再以其他柱透干参看。
- **不取格的情况**：建禄、月刃（阳刃）本身不取格，以扶抑论。
- 后续路由：本规则是格局派核心；其它派别（旺衰、调候）另论。

### R3 十神顺逆用

- **顺用**：正官、正印、正财、食神 → 宜生扶。
- **逆用**：七煞、伤官、偏印（枭）、偏财 → 宜克制、化、合。
- **顺用神逢克、逆用神逢生** → 格局败坏或需救应。

### R4 用神 / 相神 / 成败救应

- **用神（格局派）**：格局核心所需之神（格局本身）。
- **相神**：辅助格局成败的关键干支；相神得用则格成，相神失用则格败。
- **成败救应**：格局被破格之神所坏，但有另一干支救应（合、制、化）→ 格局可回成。

### R5 格局分类

- **八格**：正官、七煞、正财、偏财、食神、伤官、正印、偏印。
- **外格**：不属于八格的特殊格局（如曲直、炎上、稼穑、从革、润下；或从格类）。
- **建禄 / 月刃**：不取格，以扶抑论。

### R6 神煞使用边界

- 本书不主神煞；神煞仅作事项点缀。
- 神煞与格局 / 用神冲突 → 以格局 / 用神为主线。
- 后续路由：神煞综合查找 → `bazi/sanming-tonghui`；神煞源流 → `luming-nayin/*`。

### R7 与《渊海子平》的分工

- 《渊海子平》是格局雏形；本书是格局精修。
- 本书不替代《渊海子平》作术语源流回查。

### R8 与《滴天髓阐微》《穷通宝鉴》的分工

- 本书只看格局成败；旺衰气势 / 通关 / 病药 → `bazi/ditiansui-chanwei`。
- 本书只看格局所需调候；调候用神细则 → `bazi/qiongtong-baojian`。
- 多派冲突时按 `conflict-policy.md` §1.2 裁判。

### R9 徐乐吾评注的使用边界

- 徐乐吾评注属于 commentary 层；在输出中必须单独标注 [徐评]。
- 不得把徐乐吾评注当作原典规则。
- 若徐乐吾评注与原典冲突 → 以原典为准；评注作为"民国格局派视角"单独列出。

## Cautions And Limits

- **不要把徐乐吾评注当作原典**。评注是 commentary 层，必须单独标注。
- **不要把本书当作"子平全部"**。本书只精修格局派；旺衰、调候、神煞各有专精派 pack。
- **不要把"格局"当作"命运全部"**。格局成败是宏观骨架；具体事项还需大运 / 流年 / 神煞 / 调候综合判断。
- **不要在事实层数据不足时硬断格局**。月令未定 → 给条件性回答。
- **不要把"建禄 / 月刃"硬取为格**。本书明确不取。
- **不要把"外格"滥用**。外格是特例；需严格判定条件。
- **不要直接混用本书与现代格局派教学**。现代教学派有进一步再诠释，需单独进 modern 层 pack。
