- 表单统一使用 `react-hook-form` + `zodResolver`，字段错误通过 `errors.*.message` 渲染到 `formControls.error` 段落并配合 `aria-invalid`/`aria-describedby` 标注无障碍语义。
- 异步提交前用 `ref` 标记 `busyRef.current` 并在 `finally` 中复位，同时设置 `busy` state 禁用按钮与 `aria-busy`，避免重复触发。
- 对外部 API 调用使用 `stableKeyForIntent(intentKeyRef, payload)` 生成幂等键传入 `start*Reading`，确保网络重试不会创建重复解读。
- 读取型组件（如 `reading-result`）通过 `useEffect` 内维护 `cancelled` flag 与 `setTimeout` 轮询，并在 cleanup 中清除定时器与标志位。
- 复杂视图拆分为子组件并按能力类型（bazi/fortune/liuyao）在聚合组件中以条件渲染组合，而非继承或运行时切换实现。
- 样式组织遵循一组件一 CSS Module 文件命名约定，并通过 `clsx` 复用 `form-controls.module.css` 中的 `action`/`field`/`actions` 等原子类。
