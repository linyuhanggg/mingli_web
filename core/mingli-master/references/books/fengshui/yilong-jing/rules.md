# 疑龙经 — Rules

## R-01: 干上寻龙真可据，枝上多花假
- **source_chapter**: shangpian
- **rule**: 干龙长远去无穷，行至中间阳气聚为真；枝龙身上半是虚花半是胎，结实者必有护送回顾。
- **applicable_to**: 形势派寻龙判别干枝之先后取舍
- **caveats**: 现代使用边界：仅作文化研究参考。"虚花""结实"系古人形容词，非客观度量；不可据此作阴宅选址决策。
- **verified**: false

## R-02: 护纒疊数辨枝龙真假
- **source_chapter**: shangpian
- **rule**: 枝龙护纒须观疊数，三重五重抱回来则可于枝龙腰上做穴；一疊回顾则只是护龙叶交互，非真穴。
- **applicable_to**: 枝龙立穴可取性之初判
- **caveats**: 现代使用边界：仅作文化研究参考；阴宅选址不应单凭古文判断。
- **verified**: false

## R-03: 二水相交风水劫处非穴
- **source_chapter**: shangpian
- **rule**: 寻得干龙穷处，若见二水相交、风吹水劫之地，必非真穴；当看水交纒处外有山聚会，翻身顾母为回龙转身处。
- **applicable_to**: 干龙尽头识穴否定型规则
- **caveats**: 现代使用边界：仅作文化研究参考。涉及阴宅选址，不替代地质勘察与法律合规。
- **verified**: false

## R-04: 朝山真假以"特来"为验
- **source_chapter**: shangpian
- **rule**: 朝山若真则特来低昂起伏，向穴有情；若假则尖圆如画却直去倾仄，名为"墜朝山"，与穴无关。
- **applicable_to**: 朝山真假判别
- **caveats**: 现代使用边界：仅作文化研究参考。
- **verified**: false

## R-05: 明堂避风惜水
- **source_chapter**: shangpian

- **applicable_to**: 明堂格局总要求
- **caveats**: 现代使用边界：仅作文化研究参考；不替代专业堪舆与现场踏勘。

## R-07: 鬼山官山辨干龙行尽

- **rule**: 干龙行尽处必有外山隔水来顾为官山；若有逆转之鬼山拖脚后环则向前寬处安穴，"凡山大曲水大转，必有王侯居此间"。

## R-10: 怪形异穴亦能出贵
- **source_chapter**: xiapian
- **rule**: 不可只爱左右抱者强；虚花左右似有情，仔细辨来非正形；怪形异穴识得裁穴卻無難，子孙世襲官。

## R-12: 抱养僧道香火承嗣论
- **source_chapter**: wen-1-baoyang
- **rule**: 山川灵气降为神，神随主者家生人；只要祀事香火明，抱养子与僧道嗣续皆可承蔭，与亲生同气；古"招魂葬"汉家四百年旺为证。
- **applicable_to**: 嗣续与公位之扩展解释
- **caveats**: 现代使用边界：仅作文化研究参考。属传统民俗信仰，不作现代亲属法律或殡葬政策依据。
