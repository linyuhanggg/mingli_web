模块按职责划分为 identity 与 security 两个子包：
- `app/identity` 采用分层结构：`models.py` 定义 SQLAlchemy ORM 模型（User、LoginIdentity、DeviceSession、GuestSession、AuditEvent）及命名约定；`repository.py` 通过 `AsyncSession` 暴露对会话、身份与审计事件的 CRUD 抽象；`service.py` 中的 `GuestSessionService` 与 `AuthService` 编排业务流——创建访客/设备会话、发送 OTP、校验 OTP 并自动注册首次登录用户；`otp.py` 实现地址归一化、HMAC 签名、`InMemoryOtpChallengeStore`（挑战码 TTL/冷却/尝试次数）与三层速率限制器（guest/network/destination），并通过 `app.adapters.otp` 注入外部投递通道；`security.py` 提供不透明 token 生成与 SHA-256 哈希；`schemas.py` 用 Pydantic 描述 API 请求/响应契约；`cookies.py` 统一设置/清除 `mingli_guest`、`mingli_session`、`mingli_csrf` 三个 Cookie。
- `app/security/envelope.py` 独立提供 `EnvelopeCipher`，使用 `cryptography` 的 AES-256-GCM + AAD 上下文进行带指纹认证的加解密，支持文本与 JSON 两种载荷。
依赖方向单向：service → repository/otp/security → models；对外仅通过 service 与 schemas 暴露能力，session 由调用方注入。
