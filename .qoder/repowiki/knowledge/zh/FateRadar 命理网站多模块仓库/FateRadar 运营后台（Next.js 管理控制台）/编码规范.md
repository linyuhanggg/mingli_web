- 页面组件通过包裹 `<AdminShell>` 复用导航、会话校验与页面头部，并在 props 中传入 `title` 与 `duty` 描述。
- 所有对后端的请求统一走 `adminFetch<T>`，由其在请求前自动附加 `credentials: same-origin`、`content-type` 与 `x-csrf-token` 头。
- 异步副作用使用 `useEffect` 内声明 `let cancelled = false` 并在 cleanup 中置位，避免组件卸载后的状态更新。
- 路由级页面文件位于 `src/app/<feature>/page.tsx`，每个功能域一个子目录，保持路由与代码结构一一对应。
- 样式全部使用 CSS Modules（如 `admin-shell.module.css`、`ui.module.css`），并通过 `clsx` 组合多个类名。
- 对外暴露的类型集中在 `src/lib/api.ts`，页面仅 import 类型而不重复定义后端响应结构。
