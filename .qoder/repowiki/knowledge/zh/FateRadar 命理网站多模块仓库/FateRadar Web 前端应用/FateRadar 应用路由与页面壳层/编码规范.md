- 受保护路由（`/app`、`/account`）的 layout 统一导出 `dynamic = "force-dynamic"`、`revalidate = 0`、`fetchCache = "force-no-store"` 并通过 `PrivateShell` 包裹 children。
- 公共路由的 layout 在根 `layout.tsx` 中集中配置站点级 `Metadata`（title template、viewport、themeColor）并引入 Noto Sans/SC 字体变量。
- 错误、加载与未找到状态统一通过 `StatusPanel` 组件并以 `state="error"|"loading"|"empty"` 区分，避免在各页面重复实现 UI。
- 业务功能路由按领域划分子目录（如 `fortune`、`readings`、`ask/liuyao`），每个子路由以独立的 `page.tsx` 暴露，参数路由使用 `[id]` 命名约定。
- SEO 控制集中在 `robots.ts` 中统一 disallow `/app/`、`/account`、`/api/`，并在各私有 layout 的 metadata 中再次设置 `robots: { index: false, follow: false, nocache: true }` 双重防护。
