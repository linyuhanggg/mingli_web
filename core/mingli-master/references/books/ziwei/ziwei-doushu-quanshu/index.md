## 简介

《紫微斗数全书》是明代陈希夷（实际成书托名于宋代陈抟，明清以来由罗洪先等增补润色）传世的紫微斗数核心典籍，为紫微斗数北派最重要的祖本之一。维基文库当前源为三卷：

- **卷一**：紫微斗数总论赋文（太微赋、形性赋、星垣论、斗数准绳、斗数发微论、重补斗数彀率、增补太微赋）+ 诸星问答论（紫微/天机/太阳/武曲/天同/廉贞/天府/太阴/贪狼/巨门/天相/天梁/七杀/破军 14 主星，文昌/文曲/左辅/右弼/天魁/天钺/禄存/天马 8 辅星，化禄/化权/化科/化忌四化，擎羊/陀罗/火星/铃星 4 煞，天空/地劫/天伤/天使/天刑/天姚/天哭/天虚 8 辅煞）+ 斗数骨髓赋 + 女命骨髓赋 + 格局诸论（定富贵贫贱十等论 / 十二宫诸星得地合格诀 / 失陷破格诀 / 得地富贵论 / 失陷贫贱论 / 定富局 / 定贵局 / 定贫贱局 / 定杂局）
- **卷二**：紫微斗数安星例（安身命例 + 12 宫起例）+ 十二宫详断（命宫 / 兄弟 / 妻妾 / 子女 / 财帛 / 疾厄 / 迁移 / 奴仆 / 官禄 / 田宅 / 福德 / 父母）
- **卷三**：紫微斗数杂论与运程（谈星要论 / 论人命入格 / 论格星数高下 / 论男女命同异 / 论小儿命 / 论小儿生时 / 论小儿克亲 / 论命先贫后富 / 论大限十年祸福 / 论二限太岁吉凶 / 论行限分南北斗 / 论流年太岁吉凶星煞 / 论阴骘延寿 / 论羊陀迭并 / 论七杀重逢 / 论大小限星辰过十二宫遇十二支所忌诀 / 论立命行限宫歌 / 论诸星同垣各司所宜分别富贵贫贱夭寿）
