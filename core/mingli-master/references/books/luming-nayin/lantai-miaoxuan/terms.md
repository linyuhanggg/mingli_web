# 蘭臺妙選 — Terms

> 术语以本书三篇为界，供主 skill 按需加载。所有术语解释只用于文本理解，不直接构成真人断语。

| term | layer | meaning_in_text | use_for_skill | caveat |
|---|---|---|---|---|
| 三命 | core | 天元、地元、人元的总称，配合六十甲子与四柱论命。 | 识别本书不是纯子平十神体系，而是三元/纳音取象体系。 | 需与现代“年月日时四柱”概念区分。 |
| 六旬 | core | 六十甲子范围；每甲管十支辰。 | 作为格局取象的干支范围。 | 不等于单纯旬空法。 |
| 根基 | core | 以四时生旺判断五行基础是否稳固。 | 路由到旺衰/季节背景。 | 不可简化成现代日主强弱。 |
| 格局 | core | 由生月取用与三合局等决定“格/局”。 | 解释本书“格清局妙”的基本语言。 | 与《子平真诠》格局法同名异义。 |
| 禄马 | core | 官、财、驿马等综合符号。 | 判断是否讨论迁动、财官、贵人。 | 失地反贱等断语须 reframe。 |
| 贵神 | core | 可向用、救格或成格的贵助符号。 | 作为格局成败的条件之一。 | 需要排盘工具提供实际神煞位置。 |
| 凶煞 | risk | 七煞、羊刃、伤官等凶性符号，有制可转荣。 | 冲突裁判：凶煞不必然坏，重在制化。 | 真人分析不得硬断灾厄。 |
| 纳音取象 | method | 用干支纳音与地支象（龙、凤、天池、河汉等）构成格名。 | 抽取格名/象名时的总原则。 | 象名具有文学性，不能机械套盘。 |
| 鬼人/鬼物 | risk | 中篇用来描述煞鬼乖时、吉位逢凶等类型。 | 只作古籍分类术语。 | 不得用于人格贬损。 |
| 刑冲破害 | risk | 中篇负面象类核心。 | 需标记为风险 reframe。 | 不得作疾病、死亡、刑伤确定判断。 |
| 日轮 | symbol | 下篇以戊午等作为日轮取象。 | 识别日月光象格。 | 需查原文条件，不可只见字即套。 |
| 画桥 | symbol | 下篇“人立画桥”类取象。 | 识别水木金火组合象格。 | 格名应用依赖具体组合。 |
| 桃花滚浪 | symbol | 下篇桃花、水势、季节与贵神组合。 | 用于解释文学格名。 | 桃花词不可作现代情感断语硬套。 |
| 桂影横波 | symbol | 下篇月华/季秋相关取象。 | 识别季节时令参与成格。 | 需保留时令条件。 |
| 文星入河汉 | symbol | 下篇文星与河汉组合，有得时失时之分。 | 提醒同一象格须区分得时/失时。 | 职业断语必须软化。 |
