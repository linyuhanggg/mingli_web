# 果天经/果老星宗 — 流程

> 7 个核心流程，编号 `GP-01～GP-07`。
> 所有流程**强制依赖** `tool.xingming.bindisk`；不允许手算星盘。

---

## GP-01 起盘流程

**目的**：用户提供出生时刻 / 地点 → 起出七政四余命盘。

**步骤**：
1. **用户输入**：出生年月日时（公历或农历，含真太阳时纠正信息）+ 出生地经纬度。
2. **工具调用**：调用 `tool.xingming.bindisk`，传入上述参数。
3. **工具返回**：
   - 11 曜（日月金木水火土 + 罗计紫炁孛）的当下黄经位置
   - 命宫起算（依出生时太阳所躔 + 节气）
   - 12 宫分宫
   - 三主（宫主 / 度主 / 身主）
   - 各神煞起例位置（依 GR-02-01 ～ GR-02-12）
4. **数据校验**：禁止使用古书所载行度表（已被岁差打乱）；以工具返回为准。
5. **存入上下文**：将盘排好的 11 曜位置 + 三主 + 神煞 写入会话上下文，供后续流程引用。

**禁止**：
- 不接受用户手算之"我命躔虚日鼠"等输入；必须工具实算。
- 不接受古书"立春虚一起"等节气行度作为现代盘星位依据。

---

## GP-02 三主取用流程

**目的**：依 GR-05-01 / GR-05-02 取出三主并判强弱。

**步骤**：
1. **取宫主**：依命宫所属 12 宫之五行，定宫主星（如子宫属土，宫主为土星）。
2. **取度主**：依命宫所躔之具体宿度（含星禽），定度主星（如躔虚日鼠则度主为日）。
3. **取身主**：太阴所躔度之主星。
4. **强弱判**：
   - 三主皆入垣 / 升殿 / 庙旺 / 喜乐 → 全强
   - 三主混合或有 1 弱 → 部分弱
   - 三主皆失次 / 受克 / 伏逆 → 全弱
5. **昼夜判**：昼生看命度主为重；夜生看身度主为重。
6. **女命**：女命身主太阴最为切要（参 GR-05-03）。

**输出**：三主表 + 强弱标签 + 主导星。

---

## GP-03 神煞起例 + 命盘组合流程

**目的**：依 GR-02-01～GR-02-12，从年干 / 月支 / 日干 起出全套神煞。

**步骤**：
1. **变曜起例**：依年干化曜（GR-02-01）确定本命之化曜。
2. **吉星组**：依各起例口诀起出 文官星群（GR-02-04）+ 经纬马驿（GR-02-05）+ 贵人星群（GR-02-06）。
3. **煞星组**：依起例起出 权煞群（GR-02-07）+ 凶煞群（GR-02-08）+ 孤虚群（GR-02-09）+ 三刑六害劫亡天罗地网（GR-02-10）。
4. **格局判定**：检查是否出现"经纬夹拱""五曜连珠""二星合璧""太乙抱蟾""玉兔腾空"等贵格（GR-04-03）。
5. **冲突识别**：标识同宫吉煞混杂、对照三方等关系。
6. **safety-redlines 标记**：对凶煞群中"杀身""死兵下""恶死""灭祖"等具体寿命 / 灾祸断语条目打 redline 标。

---

## GP-04 限度行运流程

**目的**：依 GR-01-06 / GR-03-01 / GR-05-05 排算大限 + 童限 + 小限。

**步骤**：
1. **大限**：依洞微百六限分配（命 15 + 禄 15 + 妻 11 + 田 4.5 + ……）：
   - 子午卯酉宫各管 15 / 15 / 11 / 5 年 = 四强宫共 45 年。
   - 寅申巳亥辰戌丑未八宫共管 55 年。
   - 相貌宫 10 年；疾厄迁移各 7.5 年。
   - 总和 = 106 年。
2. **童限**：童限自婴幼期起按古歌分配。
3. **小限**：每年一小限。
4. **限主**：每限行宫之主星即为限主。
5. **顺逆**：判限主顺行 / 逆行 / 伏逆，影响吉凶力度。
6. **三方对照**：本宫见星 10 分力 / 对宫 7 分力 / 三合 4 分力（GR-05-06）。

## GP-05 与 xingming-suyuan 互参流程

**目的**：本书与《星命溯源》同源，二者互证。

**步骤**：
1. **优先级**：星命溯源为祖本（鼻祖）；果天经为后世广之；含义冲突时优先听星命溯源。
2. **天官派 vs 果老派**：四库提要明指"化气当从天官，正气当从果老"；本书属"果老正气"派。
3. **互参点**：
   - 三主取用法两书相同。
   - 神煞名相多有重叠；同名异义时以星命溯源 yiwen 为主。
   - 限度分配相同。
4. **写作输出**：引用本书规则时如有星命溯源对应条目，附"参见星命溯源 XR-NN-MM"。

## GP-06 safety-redlines 屏蔽流程

**目的**：拦截寿命 / 死亡 / 重大灾祸 / 子嗣 / 婚姻成败的硬判断询问。

**触发**：
- 关键词："我能活多久""我会不会死兵下""我哪一年遭灾""我会不会绝嗣""我离不离婚"等。
- 章节范围：GR-02-07 / GR-02-10 / GR-04-02 / GR-05-03 整段。
- 神煞涉及：阳刃 + 八煞 + 飞廉 + 劫煞 + 天罗地网 同时具体年份 + 死法判断时。

**响应**：
1. 不调用 rules.md 中具体死法 / 寿命断语条目。
2. 返回标准文案：
   > "您询问的内容涉及七政四余古文中的寿命/灾祸/婚姻具体硬判断条目。这类条目属古代价值体系下的劝诫文献，受占星术语境约束，不具备对具体个人未来作硬断的依据。本助手按 safety-redlines 屏蔽该类输出，建议改为咨询命盘的趋势分析、性格倾向描写或风险注意事项建议。"
3. 可选引导：用户改问命盘风格 / 优势倾向 / 行运压力点等中性问题，启用 GP-02 / GP-03 / GP-04。

## GP-07 写作输出流程

**目的**：将命盘解读包装为符合 xingming 系统规范的文本。

**输出格式**：
```
> [七政四余·果老星宗] 古文中提到 ……（短引≤80字）
> 出处：篇X·篇名（normalized#LXXXX）
> 三主：宫主=X，度主=Y，身主=Z（强弱：…）
> 限运：当前限主=X（顺/逆，本宫力 10 / 对照 7 / 三合 4）
> verified: false ｜ 工具：tool.xingming.bindisk
> caveats: [需要的 caveats 列表]
```

**强制字段**：
- `[七政四余·果老星宗]` 前缀
- 短引 ≤ 80 字
- 篇章锚点 + verified 标志位
- 工具引用
- 完整 caveats 列表

**禁止**：
- 复制超过 200 字原文。
- 输出"必死""必富""必贵""必夭""必绝嗣""必离婚"等绝对硬断语。
- 不附 verified / caveats / 工具引用即输出。
- 不经过 tool 重排盘，直接用古书行度数据出结论。

## 流程依赖关系

```
GP-01（起盘） ─> GP-02（三主取用） ─> GP-03（神煞起例 + 格局）
                                  ↓
                              GP-04（限度行运）
                                  ↓
                              GP-05（与 xingming-suyuan 互参）
                                  ↓
                              GP-06（safety-redlines 检测，命中则中止）
                                  ↓
                              GP-07（写作输出，统一包装）
```

GP-01 是所有流程的前提（盘必须先排）；GP-07 是所有流程的终点（任何输出都经包装）。
GP-06 在 GP-03 / GP-04 召回后立即执行检测；命中即不进入 GP-07 而走标准化拒绝文案。
