### 命理解读
- 定义：项目的核心业务：根据用户输入（八字、卦象等）调用 Runtime 与模型生成解读结果，并通过 Reading Orchestrator 编排准备、执行、校验与交付的完整流程。
- 别名：reading、命理计算

### Reading Orchestrator
- 定义：显式的命理解读编排器，替代此前的 agent loop，负责将读取请求分解为 prepare → execute → verify → deliver 的确定性阶段，并处理失败恢复与 fencing。
- 别名：读取编排器

### Accepted Copy
- 定义：经服务端 Narrative Guard 校验后最终交付给客户端的命理解读结果副本，客户端不得伪造或篡改排盘结果，只展示服务端返回的 Accepted Copy。
- 别名：已接受副本

### Guest Session
- 定义：未登录访客的会话标识，基于 Cookie 中的随机不透明 token，配合服务端 HMAC 哈希存储，用于限制 OTP 创建频率与网络窗口。
- 别名：访客会话

### Runtime Gate
- 定义：发布门禁：Mac mini `native-full` 全量回归必须通过后方可进入正常开发、合并、发布与验收流程，禁止启动 VZ/Rosetta/QEMU 或 `linux-certify` 绕过。
- 别名：原生门禁、native-full gate

### Task 13
- 定义：当前迭代中围绕真实 Runtime + DeepSeek 模型的端到端产品轨迹联调任务，测试服已产出 5/5 accepted 的真实轨迹证据。
- 别名：task13

### 紫微 UI-only
- 定义：从 Metis 紫微项目中仅借用 UI 组件与交互参考，不复制品牌资产、具体版式、私有 API 或支付参数。
- 别名：borrow ziwei ui

### Bazi 工作台
- 定义：命理解读结果页中的八字可点选工作区，属于 Phase 2 已上线的功能之一。
- 别名：八字工作区
