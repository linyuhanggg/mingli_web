本模块为纯文档与规范资产，按用途划分为四个子目录：
- `docs/adr/`：采用 ADR（Architecture Decision Records）编号顺序（0001–0010）记录关键架构决策，如模块化单体、JSON 适配器隔离、不可变版本档案、统一订阅与计费、Web First 策略等，构成产品演进的历史契约。
- `docs/plans/`：按日期命名的短期实施计划（Phase 0/1、Task 13 前置、紫微 UI-only 等），是迭代的执行蓝图。
- `docs/releases/`：发布产物与运行证据，含测试部署记录、Task13 轨迹 runner 日志、`evidence/` 下的 JSON/日志快照，用于可复现验证与审计。
- `design-system/mingli-web/`：前端设计系统规范，`MASTER.md` 定义全局色板、排版、间距、动效 token 与组件栈契约（CSS Modules + Radix UI + motion/react + React Hook Form + Zod），各页面通过 `pages/[page-name].md` 覆盖 Master 规则，形成“总则 + 页面特例”的分层规范结构。
顶层若干 `HANDOFF_SNAPSHOT_*`、`PRODUCT_BLUEPRINT_*`、`PHASE_0_GATES.md` 等文件充当跨会话交接与阶段门禁的权威入口，被其他计划与 ADR 引用以保持一致性。
