# 葬书 — Rules

> 判断规则按内/外/雜篇抽取。所有 verified 为 false；涉及阴宅死亡的规则均加 caveats 说明现代使用边界。

## R-01: 葬乘生气

- **source_chapter**: neipian-1
- **rule**: 葬地必须乘地中流行之生气，使遗骨与生气相合方能荫子孙；离生气则葬法不立。
- **applicable_to**: 阴宅葬地择址（古文献语境）
- **caveats**: 现代使用边界：仅作文化研究参考，"鬼福及人""反气入骨"为古代同气相感之修辞，不构成当代葬地选择依据。
- **verified**: false

## R-02: 风水以得水为上、藏风次之

- **source_chapter**: neipian-2
- **rule**: 气界水则止、乘风则散；故葬地优先得水（界气止气），其次藏风（聚气不散）。
- **applicable_to**: 形势派选址通则
- **caveats**: 现代使用边界：仅作传统聚落选址、人居环境美学参考；不替代工程地质评估。
- **verified**: false

## R-03: 浅深得乘风水自成

- **source_chapter**: neipian-2
- **rule**: 葬于涸燥之地宜浅，葬于坦夷之地宜深；浅深与气之聚散对应。
- **applicable_to**: 葬法深度（古文献）
- **caveats**: 现代使用边界：仅作文化研究参考，不构成实际葬地施工建议。
- **verified**: false

## R-04: 全气葬止

- **source_chapter**: neipian-3
- **rule**: 千尺为势、百尺为形；势来形止处为全气之地，葬应葬其止而不葬其行。
- **applicable_to**: 形势派寻穴定位
- **caveats**: 现代使用边界：仅作景观与古典风水学习参考。
- **verified**: false

## R-05: 五不可葬

- **source_chapter**: neipian-4
- **rule**: 童山（无草木生气绝）、断山（形断气不续）、石山（土行不通）、过山（龙气未止）、独山（无龙会）五者皆不可葬，强葬则消已福、生新凶。
- **applicable_to**: 山形排除性判断
- **caveats**: 现代使用边界：仅作文化研究参考，不构成对现代墓地、骨灰安置的现实判断依据。
- **verified**: false

## R-06: 支葬其巓、垄葬其麓

- **source_chapter**: waipian-1
- **rule**: 平地隐起之"支"葬于其顶（如首），高山起伏之"垄"葬于其足（如足）；支垄不辨则气脱如逐。
- **applicable_to**: 形势派穴位选择
- **caveats**: 现代使用边界：仅作古典葬法名词参考；现代殡葬以法律法规与地形安全为准。
- **verified**: false

## R-07: 不蓄之穴为腐骨之藏

- **source_chapter**: waipian-3
- **rule**: 龙势千尺顿息而外无聚护、内气散于地中者为不蓄之穴；强葬则成腐骨之藏。
- **applicable_to**: 穴法排除判断
- **caveats**: 现代使用边界：仅作文化研究参考；"腐骨""敗槨"为古代评价语，不作现代叙述。
- **verified**: false

## R-08: 騰漏之穴为败椁之藏

- **source_chapter**: waipian-3
- **rule**: 龙虎不护、中阜叠叠、左空右缺、前旷后折、生气散于飘风者为腾漏之穴；不可葬。
- **applicable_to**: 穴法排除判断
- **caveats**: 现代使用边界：仅作文化研究参考。

## R-09: 土质五色具备为吉

- **source_chapter**: waipian-3
- **rule**: 土宜细而坚、润而不泽、备具五色（如裁肪切玉）；干如穴粟、湿如刲肉、水泉砂砾皆为凶宅。
- **applicable_to**: 穴土质量判断
- **caveats**: 现代使用边界：仅作古典土质评价语参考；现代墓地以法律和地质安全规范为准。

## R-10: 四兽形势

- **caveats**: 现代使用边界：仅作文化研究参考；"破死""含尸"等为古文措辞，不作当代陈述。

- **source_chapter**: waipian-4
- **rule**: 朱雀以水形相应；水流要源生派盛、朝旺泽衰、流囚顾我，每折瀦后泄方为吉；湍激直泻则为悲泣。
- **applicable_to**: 水法形势判断
- **caveats**: 现代使用边界：仅作传统聚落与园林选址美学参考。

## R-14: 三吉六凶

- **source_chapter**: zapian-xia
- **rule**: 穴有三吉（天光下临地德上载、阴阳冲和五土四备、目力工力趋全避缺）；葬有六凶（阴阳差错、岁时之乖、力小图大、凭福恃势、僭上逼下、变应怪见）。穴吉葬凶与弃尸同。
- **applicable_to**: 穴法葬法综合判断
