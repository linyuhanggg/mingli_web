仓库按职责拆分为 backend（FastAPI HTTP + 独立 worker 进程）、web_app（Next.js 公共站点）、admin_console（Next.js 管理控制台）、contracts（OpenAPI 与 JSON Schema）、infra（Nginx/TLS/systemd/Docker Compose）与 docs_and_design（ADR/计划/发布证据）。跨子模块的协作通过 contracts 中定义的 OpenAPI 3.1 规范与 Mingli Command/Result JSON Schema 完成：web 与管理端调用 backend 暴露的同源 `/api`，worker 通过共享 PostgreSQL 与适配器协议消费阅读任务；infra 用 Nginx 把生产流量统一路由到同一域名下的 web、backend 与 admin。Makefile 在根层统一编排 `install`、`test`、`check`、`build`、`migrate`、`worker-once` 等命令，使四个子模块共用同一套依赖安装、测试与质量门禁流程。
