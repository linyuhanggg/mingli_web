# 神相全编 — 流程

> 6 个核心流程，编号 `SP-01～SP-06`。
> 所有流程旁证层；不接收真人面部图像；不替代命盘判断。

---

## SP-01 旁证查询主流程

**目的**：响应用户对相术语义/古文出处/分类术语的查询。

**前置条件**：
- 命盘（八字 / 紫微 / 七政）已存在；本流程仅作 augment。
- 用户**未上传**真人照片或视频帧（系统级屏蔽）。

**步骤**：
1. **请求解析**：识别用户询问的相术术语、部位、相格、流派或赋文。
2. **范围判定**：判定查询是否落在 safety-redlines 整段屏蔽范围（SR-03-05 / SR-05-04 / SR-05-07 / SR-09-03）。
   - 若是：返回标准化拒绝文案（见 SP-04）。
3. **术语匹配**：从 terms.md 中匹配定义；从 chapter-map.md 中找原文出处锚点。
4. **规则检索**：从 rules.md 中召回相关规则（同卷优先；跨卷备选）。
5. **贬义判定**：判定召回内容是否含贬义判语；含则执行 SP-05 reframe。
6. **输出包装**：附标准 caveats："旁证层 / 不参与命盘硬判断 / verified: source-checked / 引用 normalized 锚点"。

**输出字段**：term / definition / source_chapter / short_quote(≤80字) / caveats / refs。

## SP-02 命盘 vs 相术冲突裁判

**目的**：当 8 字 / 紫微命盘判断与神相全编规则冲突时，给出确定性裁决。

**步骤**：
1. **冲突检测**：将命盘核心论断（如格局、用神、十神组合）与神相召回规则对比，标出方向性冲突。
2. **层级判定**：神相为旁证层（side_evidence），命盘为主判断层（primary）。
3. **裁决**：
   - 命盘明确：以命盘为主，相术只作"风格补充"输出。
   - 命盘有歧义、相术 3 条以上同向召回：相术作"倾向性提示"，仍不能反转命盘结论。
   - 二者皆模糊：返回"可参考性低"提示，不强行结论。
4. **写作输出**：包装为"命盘指向 X，相术古文中亦有 Y 类描写可作风格参考"语言。

## SP-03 神骨 / 形神气声 提取流程

**目的**：从用户提供的**自我描述**（非照片）抽取神骨 / 形神气声四要素描述并匹配古文。

**步骤**：
1. **接收自描**：用户文字描述自己的面相 / 气质 / 体型；**禁止接收照片**。
2. **要素归类**：将自描归入"形 / 神 / 气 / 声 / 骨"五类之一或多类。
3. **古文召回**：从 rules.md 召回 SR-01-10 / SR-03-01 / SR-05-02 / SR-09-02 中相关规则。
4. **分类标签返回**：仅返回"古文中存在与之相近的描写类别"，不输出"你的相为某格主何吉凶"。
5. **现代视角附注**：每条召回都附"古文相术属传统文化范畴，不作命运硬判"。

## SP-04 safety-redlines 屏蔽流程

**目的**：拦截用户对凶相诸格 / 六恶六贱 / 寿夭孤疾 / 何知诀系列的具体个人化询问。

**触发**：
- 关键词："我会不会短命""我克不克妻""我有没有子""我会不会遭灾""我是不是凶相""我贱不贱"等。
- 章节范围：SR-03-05 / SR-05-04 / SR-05-07 / SR-09-03 整段。
- 流年部位 / 十二宫 / 富贵贫贱诸相 涉及个人未来年份判断。

**响应**：
1. **不调用规则**：不命中任何 rule body。
2. **返回标准文案**：
   > "您询问的内容涉及古文相术中的灾祸/寿命/疾病/贵贱等预测条目。这类条目属古代价值体系下的劝诫文献，不具备对具体个人未来作硬判断的依据。本助手按 safety-redlines 屏蔽该类输出，建议改为咨询命盘的趋势分析、性格风格描写或健康行为习惯建议。"
3. **可选引导**：若用户改问"我适合什么职业风格""我性格倾向"等中性问题，启用 SP-01 / SP-03。

## SP-05 贬义 reframe 流程

**目的**：保留古文语义骨架，剥离价值贬义。

**步骤**：
1. **识别贬义**：判定召回片段是否含"贱""恶""凶""愚""贫""夭""孤""刑""克"等贬义字。
2. **三选一处理**：
   - **替换**：愚顽→思维稳定型；刚强→果决型；俗→实用型；薄→敏感型。
   - **删除**：动物喻象的吉凶判语整段删除（如"狼目主凶"→"狼目（一种眼形分类）"）。
   - **现代视角附注**：在原文出处后附"原文反映古代社会偏见，现代仅作语义研究使用"。
3. **保留出处**：reframe 后仍保留 normalized 锚点供溯源。

---

## SP-06 旁证层留痕流程

**目的**：每次相术调用都在输出中留下"旁证层"标识，避免被误读为硬判断。

**输出格式**：
```
> [旁证·神相全编] 古文中提到 ……（短引≤80字）
> 出处：卷X·篇名（fulltext.md LXXXX）
> verified: source-checked ｜ 仅作旁证参考，不参与命盘硬判断
```

**强制字段**：
- `[旁证·神相全编]` 前缀
- 短引限 80 字内
- 卷次 + 篇名锚点
- verified 标志位
- 旁证 caveats 整句

**禁止**：
- 复制超过 200 字原文。
- 输出"主吉""主凶""主富""主贵""主贫""主夭"等价值判语。
- 对真人照片作出判断。
- 不附 verified / caveats 即输出召回内容。

## 流程依赖关系

```
SP-01（主流程） ─┬─> SP-04（safety-redlines 检测，命中则中止）
                ├─> SP-03（神骨形神气声专项）
                ├─> SP-02（与命盘冲突时）
                └─> SP-05（贬义召回时）→ SP-06（统一留痕包装）
```

所有流程**最终经 SP-06 包装输出**；任一流程独立调用都不得跳过 SP-06。
