本模块以 Next.js App Router 作为入口：`src/app/` 下的路由页面（app_routes）负责 URL 到页面的映射与布局壳层；页面通过 `src/components/` 中的 React 客户端组件组装具体交互界面（表单、图表、结果展示等）；所有跨页面共享的 API 调用、时区处理、产品能力注册、中文展示格式化等逻辑集中在 `src/lib/`，被页面与组件共同引用。`scripts/start-standalone.mjs` 提供独立启动脚本，`vitest.config.ts` 与 `test/` 目录统一覆盖路由、组件、lib 的测试。整体形成 app → components → lib 的单向依赖链，lib 不反向依赖页面或组件。
