# 果天经/果老星宗 — Distillation Pack

> 本 pack 对古今图书集成 + 后世汇刊本《张果星宗》/《果老星宗》进行全书 distillation。
> 七政四余星命术（xingming）总系；不参与八字判断；不接受手算排盘。

## 概览

- **书名异名**：果天经 / 果老星宗 / 张果星宗 / 五星正宗（多版本异称）。
- **托名作者**：唐·张果（八仙之一）。**实际编撰者不详**；成书层累，自唐宋至明清不断增补。
- **核心内容**：以二十八宿、十二宫、十一曜（七政 + 四余 = 日月金木水火土 + 罗计紫炁孛）、命度宫主、限度神煞 推命。
- **本地全文**：`references/fulltext/xingming/guotian-jing/fulltext.md`（1670 行；4-17 卷分散排列；见 chapter-map）。

## 流派定位

- **system**：xingming（七政四余 / 星命 / 五星推命）。
- **school**：[七政四余, 果老星宗, 五星推命]。
- **重要**：与 xingming-suyuan《星命溯源》同属一系；二者互参（《星命溯源》自署祖本）。
- **不属于**：八字子平（bazi）/ 紫微斗数（ziwei）/ 七政四余之"天官派"（天官五星术与本派化气取用不同）。
- **与 xingming-suyuan 关系**：四库提要明指"世所传五星之书以星命溯源为鼻祖，别有所谓果老星宗者，盖因此本而广之"。果老 = 星命溯源的扩展版；二派可互参（天官派从化气，果老派从正气）。

## 版本说明（**version_notes**）

1. **古本**：张果原书早佚；现存皆为后世托名 / 增补本。
2. **本 pack 来源**：综合古今图书集成《术数典》与明清坊刊本《果老星宗》《张果星宗》。
3. **版本异说**：同书在不同版本中卷次顺序、子目数量、神煞名相均有出入；本 pack 以"主题分组 + 章名锚点"为主，**卷号不作硬关联**。
4. **真伪争议**：四库提要直言"明皇杂录载果多神怪之迹，不言其知禄命，独是编以五星推命之学依托于果"；明确为托名书。
5. **行度数据**：本书载有大量"二十四气太阳行度""二十八宿度数"等天文表，**这些数据已不准确**（受岁差影响），**现代必须使用 tool.xingming.bindisk 重新计算**。

## 核心数理框架

1. **十二宫**：子丑寅卯辰巳午未申酉戌亥；每宫配西法十二宫名（宝瓶 / 磨羯 / 人马 / 天蝎 / 天秤 / 双女 / 狮子 / 巨蟹 / 阴阳 / 金牛 / 白羊 / 双鱼）+ 中国分野。
2. **二十八宿**：东方青龙（角亢氐房心尾箕）/ 北方玄武（斗牛女虚危室壁）/ 西方白虎（奎娄胃昴毕觜参）/ 南方朱雀（井鬼柳星张翼轸）。每宿带"星禽"（角木蛟、亢金龙……）+ 度数。
3. **十一曜**：七政（日月金木水火土）+ 四余（罗 = 火之余 / 计 = 土之余 / 紫炁 = 木之余 / 月孛 = 水之余）。
4. **三主 / 四主**：宫主（命宫所属五行星）/ 度主（命度所属之星）/ 身主（太阴所躔度之主）+ 福主（福德宫主）。
5. **限度**：洞微百六限（命 15 + 禄 15 + 妻 11 + 田 4.5 + 子孙 4.5 + 奴仆 4.5 + 财 5 + 兄弟 5 + 相貌 10 + 疾厄 ~ 7.5 + 迁移 ~ 7.5）= 106 年。
6. **格局**：星辰入垣 / 升殿 / 庙旺 / 喜乐 / 贵格 / 贱格 ；夹拱、辅夹、朝拱、引从 等组合。
7. **神煞群**：天禄 / 天暗 / 天福 / 天耗 / 天荫 / 天贵 / 天刑 / 天印 / 天囚 / 天权 / 科名 / 魁星 / 文昌 / 唐符 / 国印 / 天雄 / 地雌 / 阳刃 / 咸池 / 三刑 / 六害 / 劫杀 / 亡神 / 孤辰 / 寡宿 等 60+ 神煞。
