# 蘭臺妙選 — Procedures

## Query Routing

1. 用户问“纳音格局/古法禄命/三命/兰台妙选格名”时加载本 pack。
2. 先调用排盘工具取得：四柱干支、胎元、纳音、月令季节、三合局、禄马贵人、刑冲破害、神煞。
3. 再按问题类型读取：
   - 格名/象名：`terms.md` + `rules.md` LT-R04/LT-R06。
   - 源流：`index.md` + `chapter-map.md`。
   - 凶煞疾病刑伤类：`rules.md` LT-R05 + `quote-index.md`，必须安全改写。
4. 输出时固定包含：
   - “本书属于禄命纳音取象层”。
   - “是否可作主断”：默认否，只作旁证。
   - “需要复核的原文短引”：引用 `quote-index.md` id。

## Safety Gate

- 不预测死亡、疾病、刑伤、贫贱、人格贬损。
- 不把“鬼人/鬼物/白虎衔尸/元武披发”等术语用于真人评价。
- 不替代医学、法律、财务建议。

## Evidence Gate

任何规则输出至少绑定一个 `LT-Qxxx` 短引；没有短引则只能说“待查”。
