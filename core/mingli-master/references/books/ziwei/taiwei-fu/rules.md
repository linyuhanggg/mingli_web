# 太微赋 — Rules

> 紫微斗数早期赋文判断规则抽取。每条规则字段：`source_chapter` / `rule` / `applicable_to` / `caveats` / `verified`。

> 涉及寿夭/疾病/死亡的规则 caveats 一律标注："仅作文化研究参考，不得铁口断寿断病"。

## TR-01 至玄至微

- **source_chapter**: zonglun/zhi-xuan-zhi-wei
- **rule**: 斗数至玄至微，理旨难明；寿夭贤愚、富贵贫贱，不可一概论议。
- **applicable_to**: 所有紫微推命场景（开篇纲领）
- **caveats**: 提醒断命须留余地，不作一概而论。
- **verified**: false

## TR-02 入庙为奇 / 失度为虚

- **source_chapter**: zonglun/rumiao-shidu
- **rule**: 入庙为奇，失度为虚；身命为福德之本，加以根源为穷通之资。
- **applicable_to**: 所有星曜入庙判断
- **caveats**: 入庙/失度的具体配位需查《紫微斗数全书》卷二。
- **verified**: false

## TR-03 禄逢冲破

- **source_chapter**: liyue/lu-feng-chongpo
- **rule**: 禄存逢冲破，吉处藏凶。
- **applicable_to**: 禄存星在命/财/官位被冲破
- **caveats**: 现代教学保留为"吉中藏忧"参考，不作绝对凶论。
- **verified**: false

## TR-04 马遇空亡

- **source_chapter**: liyue/ma-yu-kongwang
- **rule**: 天马遇空亡，终身奔走。
- **applicable_to**: 天马入空亡之地
- **caveats**: 现代解读为漂泊倾向，不作绝对断语。
- **verified**: false

## TR-05 生逢败地 / 绝处逢生

- **source_chapter**: liyue/sheng-feng-baidi
- **rule**: 生逢败地发也虚花；绝处逢生，生花不败。
- **applicable_to**: 主星与四长生（败/绝）位的相互关系
- **caveats**: 须结合大限流年综合判断。
- **verified**: false

## TR-06 日月反背 / 禄马交驰

- **source_chapter**: liyue/riyue-fanbei
- **rule**: 日月最嫌反背（日不入南、月不照北）；禄马最喜交驰（禄存与天马同会）。
- **applicable_to**: 太阳/太阴宫位判断；禄马同会判断
- **caveats**: 反背为不吉倾向，非铁口凶论。
- **verified**: false

## TR-07 紫府辅弼

- **source_chapter**: liyue/ziwei-tianfu-fubi
- **rule**: 紫微天府全依辅弼之功；辅弼夹帝为上品。
- **applicable_to**: 紫微/天府主星与左辅右弼组合
- **caveats**: 须辅弼真夹（紧夹）方为上品；隔宫效力减半。
- **verified**: false

## TR-08 七杀破军 / 杀破狼

- **source_chapter**: liyue/qisha-pojun-yangling
- **rule**: 七杀破军专依羊铃之虐；诸星吉，逢凶也吉；诸星凶，逢凶也凶。
- **applicable_to**: 七杀/破军/贪狼三星与火铃羊陀的组合
- **caveats**: 现代杀破狼格局教学已与羊铃组合分离，须按派系细分。
- **verified**: false

## TR-09 桃花犯主

- **source_chapter**: liyue/taohua-fanzhu
- **rule**: 桃花犯主为至淫；贪居亥子，名为犯水桃花；刑遇贪狼，号曰风流彩杖。
- **applicable_to**: 紫微会贪狼/桃花星的组合
- **caveats**: "至淫"古文价值观需 reframe 为"情感繁复倾向"，不作道德定性。
- **verified**: false

## TR-10 魁钺同行

- **source_chapter**: liyue/kuiyue-tongxing
- **rule**: 魁钺同行，位居台辅；君臣庆会，材善经邦。
- **applicable_to**: 天魁天钺同宫或夹会命宫
- **caveats**: 现代解读为贵人扶助倾向，不作绝对仕途论。
- **verified**: false

## TR-11 太阳居午（日丽中天）

- **source_chapter**: liyue/taiyang-juwu
- **rule**: 太阳居午，谓之日丽中天，有专权之贵、敌国之富。
- **applicable_to**: 太阳坐命宫或重要宫位在午
- **caveats**: 现代为富贵倾向参考，不作铁口断富。
- **verified**: false

## TR-12 太阴居子（水澄桂萼）

- **rule**: 太阴居子，号曰水澄桂萼，得清要之职、忠谏之材。
- **applicable_to**: 太阴坐命宫或重要宫位在子
- **caveats**: 现代为清贵职业倾向参考。
- **verified**: false

## TR-13 太阳会文昌于官禄

- **verified**: false

- **verified**: false

## TR-15 禄居奴仆

- **source_chapter**: liyue/lu-ju-nupu
- **rule**: 禄居奴仆，纵有官也奔驰；帝遇凶徒，虽获吉而无道。
- **applicable_to**: 禄存落奴仆宫；紫微会煞星
- **caveats**: 现代解读为为他人作嫁倾向，不作仕途铁断。

- **source_chapter**: liyue/qisha-lianzhen-tongwei
- **rule**: 七杀廉贞同位，路上埋尸；破军暗曜同乡，水中作冢。

- **caveats**: ⚠️ 死亡断语 — 仅作文化研究参考，不得铁口断寿断病；现代 reframe 为外出风险倾向。

## TR-19 七杀临身命加恶杀

- **source_chapter**: liyue/qisha-lin-shenming
- **rule**: 七杀临于身命加恶煞，必定死亡；铃羊合于命宫遇白虎，须当刑戮。
- **applicable_to**: 七杀+羊陀火铃在身命；铃星擎羊+白虎在命

- **applicable_to**: 幼年/老年大限流年遇煞
- **caveats**: ⚠️ 寿夭断语 — 仅作文化研究参考，不得铁口断寿断病。

## TR-21 各司其职

- **source_chapter**: zonglun/ziwei-shezhuan
- **rule**: 土星苟居其垣若可移动；金星专司财库最怕空亡；帝星动则列宿奔驰；贪守空而财源不聚。
- **applicable_to**: 紫微（土）/武曲（金）/贪狼空亡判断
- **caveats**: 各主星本性归属，须结合宫位综合判断。
