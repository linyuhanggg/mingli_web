# TabTin 完成度方向：分析、取舍、落地

判读：这是一次**完成度与动效时序**的方向钉，不是换皮肤。受众已经接受宣纸/墨/朱砂。TabTin 提供的是「看起来做完了」的编辑节奏，不是我们的色板。

旋钮（本轮只动完成度，不改盘面密度）：公共页 VARIANCE 5 / MOTION **4**（章节揭示）/ DENSITY 5；盘面工作台仍 VARIANCE 4 / MOTION **2** / DENSITY 7。

---

## 1. 它为什么显得完整

TabTin 完整，不是因为功能多，而是因为**每一屏都像被写完、演完、停住**。下面五条是原因，不是功能清单。

### 1.1 章节叙事

页面是 01—07 的论文，不是站点地图。编号 + 一屏一事 + 大标题 + 短正文。读者永远知道「现在讲第几件事、下一屏换题」。完整感来自**叙事闭合**：第七章讲完，故事结束，而不是卡片还可以再加一张。

我们首页已有「卷首入门」这种朱砂卷标种子，但后面马上变成命盘/事件/见相/合参/辅助的**同等卡片网格**——目录感，不是章节。八字/梅花结果页是模块堆叠，M1–M12 对设计师成立，对用户是「还在填表」。

### 1.2 字号与留白

标题和正文不在同一量级。一屏只养一个大标题，正文短、行宽窄，空白是章节的边，不是组件 gap。完整感来自**对比**：大的真大，小的真小，中间没有一堆 20px 标题抢戏。

我们 Hero 已经到 `clamp(3rem, 5.5vw, 56px)`，这是对的。但折页 `h2` 落回 24px 章节号，结果页盘面标题用 20px 卡片标题——Hero 像样张，内页像后台。盘面域字 28/40px 不要再放大；要放大的是**章节题**，不是干支格。

### 1.3 产品入画

Hero 三个 CTA 之后立刻是「TabTin Desktop」——真 UI 装在桌面窗里，不是插画堆砌。完整感来自**证物**：你看见的就是将要用的东西。

我们首页用墨气、纸纹、追光制造气氛（§6.3.1 允许），但没有把**真盘**放进画框。结果页的四柱矩阵和三卦是真的，却躺在通用 1px 卡片里，像报表，不像册页里的一张盘。

### 1.4 动效：进出场、滚动揭示、时序；什么故意不动

完整站点把动效当指挥：进场、错开、落定、**停止**。滚动只揭示一次。窗框、导航、正文落定后不再动。未在本环境测到 TabTin 打包后的精确毫秒；采用该类完成度站点的通用时序（入场 400–520ms、stagger 50–80ms、出缓），钉死为我们已有的 expo 出缓，而不是再引入一套曲线。

我们首页已经有 stagger 60ms、`y: 12`、450ms 入场、滚动揭示、磁吸按钮、墨气循环（首页例外）。盘面几乎**没有入场**——数据突然出现，所以像半成品。缺口是「盘没有抵达」，不是「盘不够炫」。

### 1.5 导航 / CTA 克制

TabTin 顶上只有三件事：免费下载、开源仓库、加入群聊。其余屏不再发明主按钮。完整感来自**决策闭合**：每屏一个下一步。

我们 Hero 两个 CTA（开始排盘 / 命盘合参）是对的。后面每张术数卡都是入口，等于每屏十二个下一步。结果页不要再叠营销条。

## 2. 采用 / 改编 / 拒绝

| 条 | 处置 | 纸墨里的具体做法 |
|---|---|---|
| 01—07 编号、一屏一事 | **改编** | 用「01 / 卷二」式索引，不用英文 SaaS 功能名。首页 01 开卷 → 02 先做这一件 → 03 机制 → 04 命盘 → 05 问事 → 06 合参 → 07 开盘。结果页只给 4–6 个章节号，不给每个 M 模块编号（那是规格书）。 |
| 大标题 + 短正文 | **改编** | 首页章节题 32–40px；结果页章节题 24–28px。正文 16px、行宽 ≤42em。盘面格内字阶不动。禁止 6rem 装饰标题（§4 仍在）。 |
| 产品入画 | **改编** | 真组件装进**册页框**（1px 墨线、现有纸影、6–10px 半径）。框上是术印 + 术名，**不要** macOS 红绿灯、暗色桌面窗、科技蓝描边。首页用已有空盘剪影（无假干支/假卦名）；结果页框住活盘。 |
| 进出场 + 滚动揭示 | **改编** | 章节块 `opacity + translateY(12px)`，一次，`whileInView once`。只动 transform/opacity。 |
| 时序 / easing | **改编** | 单一系统 `motion/react`。曲线 `cubic-bezier(0.16, 1, 0.3, 1)`（已有 `--ease-out`）。时长见 §4。 |
| 窗框、导航、落定后的字、盘面域字不动 | **采用** | 顶栏不漂。干支、爻画、卦画、体用印入场后静止。空盘剪影禁止呼吸。 |
| 暗色整站、霓虹、科技蓝 | **拒绝** | 预览盘面保持宣纸。金只属于证据。朱砂只作交互强调。 |
| 无限循环装饰 | **拒绝**（盘面） | 盘面零循环。首页墨气/符箓/涟漪仍只限 `/`，且 `prefers-reduced-motion` 必须关掉（§6.3.1）。不把循环扩到结果页。 |
| 盘面卡片翻转、悬停放大 | **拒绝** | 高亮只用边框、底洗、字重（§21.1）。禁止 rotateY、scale>1.02、常驻脉冲。 |
| 滚动劫持 / 视差 | **拒绝** | 页面滚动是浏览器的。不锁滚、不把盘当舞台。 |
| CTA 弹跳 / 常亮光 | **拒绝** | 主钮墨底纸字。首页磁吸仅 `/`、仅非 reduced-motion。结果页不加第三条营销 CTA。 |
| 插画代替产品 | **拒绝** | 入画必须是真实 `BaziChart` / `MeihuaChart`（或它们的 silhouette 态）。禁止另画一套假盘。 |

## 3. 完成度合同（「看起来做完了」）

一页算做完，当且仅当同时成立：

1. **叙事闭合**：用户能数出本章是第几章、这一屏只讲一件事。
2. **字阶对比**：章节题与正文至少差两级字阶；不是一排同号卡片。
3. **证物在框里**：主盘（四柱或三卦）在册页框中，而不是散落定义列表。
4. **动效有收场**：入场最多 520ms，错开最多 4 个子项，然后静止。reduced-motion 下首帧就是终态。
5. **每屏一个主下一步**：Hero/收束各一对 CTA；结果页主操作是时间层或深读，不跟卡片抢。

半成品的典型相反面（预览上仍在）：模块等权、标题都 20px、盘在通用卡里、数据已经到了但没有抵达动作、一屏很多入口。

## 4. 动效时间轴（ms）

单一系统：`motion/react` + CSS transition。禁止再加 Lenis / GSAP / Lottie。

| Token | ms | 曲线 | 用在 |
|---|---|---|---|
| `--duration-feedback` | 160 | `--ease-out` | chip 选中、焦点、边框变色 |
| `--duration-overlay` | 220 | `--ease-out` | 抽屉、浮层、时间层列交叉淡入 |
| `--duration-page` | 280 | `--ease-out` | 壳层/路由内容（`RouteEnter`） |
| `--duration-chapter` **新增** | 480 | 同上 expo | 章节块、册页框入场 / 滚动揭示 |
| stagger | 60 | — | Hero 子项；章节内最多 4 个子项 |
| 子项延迟 | 40–80 | — | 框先到、题后到、正文最后 |
| 数字跳动（仅首页规模数） | 900–1100 | 现有 | `data-count`；reduced-motion 直接终值 |

**入场位移**：`y: 12`（Hero 子项）或 `y: 16`（章节）。不要 40px 以上，不要 scale 入场。

**谁动**

| 场景 | 动 | 不动 |
|---|---|---|
| `/` Hero | 卷标 → 主标两行 → 副标 → CTA → 规模数，stagger 60ms | 墨气层按 §6.3.1；reduced-motion 全关 |
| `/` 折页 | 章节块 whileInView once 480ms | 卡片网格不要逐卡弹入超过 4 项 |
| 八字 S3 | 册页框整框 480ms 一次；随后章节块揭示 | 四柱格、干支、十神、藏干、关系弧 **不做逐格 stagger**（会像老虎机） |
| 八字时间层 | 叠加列 220ms 透明度；chip 160ms 边框/字重 | 本命盘不卸载、不翻面 |
| 梅花 S3 | 三卦作为**一个**入画组 480ms；可核验块、体用、旺衰、判断按章揭示 | 爻画不逐爻画出；体用印不闪 |
| 抽屉 / 古籍 | 240ms 内 | 打开过程不缩放盘面 |

**`prefers-reduced-motion: reduce`（硬）**

- 所有 `initial`/`whileInView`/`stagger`/`animate` 改为终态。
- 首页追光、纸纹、墨气、磁吸、数字跳动关闭（现有 `data-reduced` 必须继续有效）。
- 骨架屏形状仍匹配盘面，但不闪。
- 焦点环、错误、`aria-live` 不依赖动画。

## 6. 状态 · 响应式 · 可访问 · 真数据

| 状态 | 做法 |
|---|---|
| 空 | 框在，剪影在，一句「提交后由服务端生成，可核验」。无假数。 |
| 加载 | 骨架等于盘的轮廓（四柱 / 三卦），480ms 内不要用通用圆 spinner 代替盘。 |
| 错误 | 诚实失败文案；无入场动画；可再试。 |
| 超长 | 问题、引文、摘要按既有折叠；不要为了「大字」截断证据。 |
| 360 | 一章一屏改为「一章一叠」；册页框通栏；首页框可藏。 |
| 768 | 章节题仍大于正文；三卦尽量横列。 |
| 1024+ | 八字左盘右读；梅花三卦通栏。 |
| 键盘 | 章节揭示不能抢走焦点。盘面键盘路径（悬停/锁定/方向键）保持。 |
| 真数据 | 入画组件只消费 ViewModel。内部键继续走映射表，未知则藏。 |

## 8. 验收

桌面 1440 与 360 各走一遍：

1. `/`：能数出 01–07（或等价卷号）；Hero 大、折页题明显大于卡片正文；有一处真剪影在册页框里（360 可无框）。主 CTA 仍是开始排盘。无科技蓝、无暗底。
2. `/bazi` S3：四柱在框里；章节号可见；时间层切换 220ms 级交叉淡入、失败仍留本命。无翻牌、无悬停放大。
3. `/meihua` S3：游客仍留 `/meihua`；三卦在框里；可核验/体用/旺衰/判断成章；无内部键。360 不三列挤死。
4. 系统「减少动态效果」：首页装饰层消失；无位移入场；数字直接是终值；盘面信息不少。
5. 付款/隐私/错误路径仍无娱乐动效。

单测绿不等于完成。完成 = 这三页在预览上不再像半成品。
