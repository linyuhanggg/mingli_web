模块以 `router.py` 为唯一装配点：`build_api_router` 创建带 `/api/v1` 前缀的根路由器，并通过 `include_router` 按业务域挂载子路由（health、guest_sessions、auth、account、profiles、readings、admin），每个子文件定义独立的 `APIRouter(prefix=..., tags=[...])` 暴露一组端点。
- 依赖注入集中在 `dependencies.py`：提供 `database_session`（异步事务上下文）、`require_guest_csrf`/`require_device_csrf`/`require_owner`/`require_owner_csrf` 等安全依赖，实现 Cookie + `x-csrf-token` 双提交 CSRF 校验与 Guest/Device Session 解析。
- 错误模型通过 `errors.ApiProblem` 异常统一表达，由上层异常处理器转换为 RFC 风格 JSON；`rate_guard.check_rate_limiter` 将速率限制器异常转为 429 并附带 `Retry-After` 头。
- 健康探针 `health.py` 通过可插拔 `ReadinessProbe` 回调暴露 `/health/live` 与 `/health/ready`，便于外部编排注入。
- 各业务路由仅做请求组装与异常映射，核心领域逻辑委托给 `app.{domain}.service`（如 `AuthService`、`ProfileService`、`AdminAuthService`），依赖方向单向指向 service/repository/config/network 等下层包。
