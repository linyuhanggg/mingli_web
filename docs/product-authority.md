## 5. 防误读边界（必须逐字执行）

1. **设计验证稿 ≠ 生产页面完成**：玄序交接的 HTML/截图/断言是设计验证产物；生产页面以 S0–S3 施工后的真实代码与真实浏览器验收为准。
2. **本地对象 ≠ main 交付**：任何本地 commit、worktree、设计目录或附件（包括 `892662af…` 与玄序验证稿）在被以精确 `origin/main` 为 parent 的最终集成收口之前，都不是 main 交付物，不得据此宣称功能完成或启动发布。
3. **第三方展示参考 ≠ 算法权威**：问真、METIS、青囊及任何第三方站点/仓库只提供展示与结构参考；算法与字段永远只认自有 Runtime/ViewModel。
4. **能力分层 ≠ 视觉候选**：`DESIGN.md` §20 的 A/B/C 是 Runtime 能力分层（判断规则数量），与已废弃的视觉方向 A/B/C 候选无关，不得互相引用。
5. **五行色 ≠ 语义状态色**：五行域色只编码盘面事实域；成功/警告/危险/焦点等通用语义一律走玄序语义令牌。
