# 子平真诠 规则集

> 以下规则只来自 47 个沈氏原典核心章节。命盘计算必须由工具完成，LLM 不手算四柱、大运、合冲刑会。

## ZPR-01: 以月令求用神
- **source_chapter**: zp-08
- **rule**: 八字用神专求月令，以日干配月令地支，按生克不同分财官印食、煞伤劫刃等格局。
- **source_anchor**: fulltext.md L173-L188
- **caveats**: 不向月令求用神而妄取用神，属执假失真；但建禄月劫须另取财官煞食。
- **verified**: false

## ZPR-02: 善神顺用，恶神逆用
- **source_chapter**: zp-08
- **rule**: 财官印食为善而顺用；七煞、伤官、阳刃、月劫为不善而逆用。顺逆配合得宜皆可成贵格。
- **source_anchor**: fulltext.md L173-L188
- **caveats**: “善/不善”是格局术语，不是道德评价。
- **verified**: false

## ZPR-03: 成败之后须看救应
- **source_chapter**: zp-09
- **rule**: 格局不能只判成败，还要看败中是否有救、成中是否被破；救应能改变格局可用性。
- **source_anchor**: fulltext.md L189-L208
- **caveats**: 救应判断依赖完整四柱透藏合冲，必须由结构化排盘工具供给。
- **verified**: false

## ZPR-04: 用神会因透干会支而变化
- **source_chapter**: zp-10
- **rule**: 月令所藏多气，透干或会支可使财变官、官变印、煞化印等，用神随之变化。
- **source_anchor**: fulltext.md L209-L228
- **caveats**: 变化不是任意取用，仍须先以月令为主。
- **verified**: false

## ZPR-05: 相神为格局成败关键
- **source_chapter**: zp-15
- **rule**: 用神之外，须看相神是否得力；相神能辅成用神或救护格局，是高低成败关键。
- **source_anchor**: fulltext.md L301-L314
- **caveats**: 不可只看日主强弱而忽略相神位置。
- **verified**: false

## ZPR-06: 杂气月取用看透干会支
- **source_chapter**: zp-16
- **rule**: 辰戌丑未为杂气，取用须看所藏何神透出、会合何局，不能只按单一藏干判断。
- **source_anchor**: fulltext.md L315-L338
- **caveats**: 墓库开闭与刑冲必须结合全局。
- **verified**: false

## ZPR-07: 四吉神也能破格
- **source_chapter**: zp-18
- **rule**: 财官印食虽为四吉神，但遇冲克混杂、护卫不当，也能破格。
- **source_anchor**: fulltext.md L355-L366
- **caveats**: 不可见吉神即判吉。
- **verified**: false

## ZPR-08: 四凶神也能成格
- **source_chapter**: zp-19
- **rule**: 煞伤劫刃虽为四凶神，但制化得宜、配合得所，也可成格。
- **source_anchor**: fulltext.md L367-L376
- **caveats**: 不可见凶神即判凶。
- **verified**: false

## ZPR-09: 生克先后影响吉凶
- **source_chapter**: zp-20
- **rule**: 同一组十神因生克先后、位置远近、透藏关系不同，吉凶结论不同。
- **source_anchor**: fulltext.md L377-L402
- **caveats**: 需要工具输出四柱位置与干支关系。
- **verified**: false

## ZPR-10: 星辰神煞不关格局
- **source_chapter**: zp-21
- **rule**: 本书明确降级星辰神煞，格局判断以月令用神、相神、成败救应为主。
- **source_anchor**: fulltext.md L403-L416
- **caveats**: 神煞最多作旁证，不得覆盖格局层。
- **verified**: false

## ZPR-11: 外格只在月令无用时权取
- **source_chapter**: zp-22
- **rule**: 外格是月令无用时的权取；若月令自有用神，不可别寻外格。
- **source_anchor**: fulltext.md L417-L430
- **caveats**: “提纲有用提纲重”，有官莫寻格局。
- **verified**: false

## ZPR-12: 行运能成格也能变格
- **source_chapter**: zp-25, zp-26
- **rule**: 行运不只是增减强弱，还会成格、变格、救格、破格。
- **source_anchor**: fulltext.md L461-L512
- **caveats**: 大运干支必须由历法排盘工具计算。
- **verified**: false

## ZPR-13: 喜忌干支有别
- **source_chapter**: zp-27, zp-28
- **rule**: 运中天干、地支作用不同，支中喜忌逢运透清又有特别规则。
- **source_anchor**: fulltext.md L513-L538
- **caveats**: 不可把干运支运混为一谈。
- **verified**: false

## ZPR-14: 正官、财、印、食神各有成格与取运
- **source_chapter**: zp-31-zp-38
- **rule**: 四吉神各有成格条件、破格条件和取运路径，不能用同一模板套判。
- **source_anchor**: fulltext.md L569-L752
- **caveats**: 需结合具体章目读取，不做一刀切。
- **verified**: false

## ZPR-15: 偏官、伤官、阳刃、建禄月劫各有制化取运
- **source_chapter**: zp-39-zp-46
- **rule**: 四凶/特殊格须看制、化、合、配与取运，凶神得制化可成，失制化则败。
- **source_anchor**: fulltext.md L753-L918
- **caveats**: 不可用现代强弱派直接覆盖沈氏格局法。
- **verified**: false

## ZPR-16: 杂格不可滥用
- **source_chapter**: zp-47
- **rule**: 杂格应在正格不足以取用时讨论，且须严格按原文条件，不可泛化为万能例外。
- **source_anchor**: fulltext.md L919-L954
- **caveats**: 与外格同属边界规则，优先级低于月令正用。
- **verified**: false
