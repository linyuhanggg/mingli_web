模块按职责分为三层：
- 页面外壳层：`private-shell.tsx`、`public-page-shell.tsx`、`app-surface.module.css`、`site-header/footer.tsx` 等负责登录态下的侧边导航布局与公共站点 chrome。
- 流程编排层：`bazi-flow.tsx`、`fortune-flow.tsx`、`liuyao-form.tsx` 等是入口表单，通过 `react-hook-form + zod` 校验后调用 `@/lib/api` 发起 `startPreviewReading` / `startTodayReading` / `startWeekReading` 等接口，并用 `@/lib/idempotency.stableKeyForIntent` 生成幂等键防止重复提交，完成后路由跳转到 `/app/readings/:id`。
- 解读结果与工作区层：`readings/reading-result.tsx` 作为聚合组件，轮询 `pollReading` 获取服务端状态机（`input_ready` → `prepared` → `completing` → `accepted` 等），根据 `capability_id`（bazi/fortune/liuyao）动态组合子组件；`chart-workspace-shell.tsx` 提供可复用的排盘工作台壳（时间层标签 + 面板 + 焦点抽屉），数据由父组件以纯函数 `renderBoard` 注入，自身不持有业务状态。
依赖方向单向向外：组件仅依赖 `@/lib/api`、`@/lib/chart-workspace`、`@/lib/reading-display` 等纯库，不反向被 lib 模块引用；样式采用 CSS Modules（每个 `.tsx` 配同名 `.module.css`），并通过 `clsx` 组合共享样式类（如 `form-controls.module.css`）。
