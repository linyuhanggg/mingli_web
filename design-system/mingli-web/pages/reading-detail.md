# Reading Detail — Surface Override

**Routes:** `/app/readings/[readingId]` and related reading result surfaces  
**Mode:** Operate + Read  
**World:** Eastern Editorial Archive

## Motion thesis

- **Focal moment:** Accepted copy + numbered reading sections arrive as a paper archive, conclusion first.
- **Continuity:** Status cards enter once when processing/error; workspace shell has a short board entrance.
- **Feedback:** Pillar cards, evidence rows, form radios, and primary actions use ≤180ms transform/color only.
- **Budget:** Section stagger via CSS delays (max ~0.32s). No continuous decorative loops. Drawer open state uses opacity/transform only.

## Rules

- Never invent evidence, payment, or delivery states.
- Sticky evidence rail remains desktop-only.
- Reduced motion: all surface-enter animations off.
