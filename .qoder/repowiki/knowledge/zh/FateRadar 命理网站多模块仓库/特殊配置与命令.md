根 Makefile 提供统一入口：`make install` 同时执行 `uv sync --project backend --group dev`、`npm install --prefix web`、`npm install --prefix admin`；`make test` 串联 backend pytest 与 contract 测试、web 单元测试；`make check` 追加 ruff/mypy 与 web lint/typecheck/build；`make migrate` 执行 Alembic upgrade head；`make worker-once` 单次运行异步 worker。本地开发需分别启动 uvicorn、worker 与 `npm run dev`，或通过 infra 的 Docker Compose 从 `http://127.0.0.1:8080` 一键拉起。
