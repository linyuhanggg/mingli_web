# 冰鉴 — Rules

> 全书规则按 7 篇分组。规则编号：`BR-NN-MM`（NN：章次 01-07；MM：章内序号）。
> 每条规则带 `source_chapter` `source_anchor` `applicable_to` `caveats` `verification_status`。
> 所有规则 `verification_status: unverified`（清刊本未对校）。
> **重要**：本书属 **旁证层**。每条规则的 caveats 都包含 "**仅作旁证参考，不参与命盘硬判断**"。
> 含贬义判语的规则均附 **现代 reframe** 子句。

## 通用 caveats（所有 BR-NN-MM 共享）

- **旁证层**：本书规则**仅作旁证参考，不参与命盘硬判断**。命盘 vs 相术冲突时，命盘（bazi/ziwei/xingming）优先。
- **贬义 reframe**：含"贱 / 敗 / 穷 / 死 / 短寿 / 子嗣不立 / 食人 / 市井 / 禽兽 / 赴法场 / 一世穷"等判语的规则，**禁止**直接套用具体个人；输出层必须 reframe 为"古典语义还原"。
- **现代禁用场合**：相貌不可作为招聘、伴侣选择、刑侦、医疗诊断、保险定价的依据。
- **safety-redlines**：寿命、生死、疾病、子嗣、女命、灾祸的硬判一律屏蔽，详见 `matrices/safety-redlines.md`。
- **不替代命盘**：本书不能单独支撑富贵贫贱、子嗣 / 婚姻 / 寿命 / 健康的结论。
