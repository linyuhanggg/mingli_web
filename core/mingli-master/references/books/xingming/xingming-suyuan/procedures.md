# 星命溯源 · 流程集

> 流程编号 `XP-NN`。所有流程必须经 XP-07 输出包装。
> 强制工具依赖：`tool.xingming.bindisk`。

---

## XP-01 起盘流程（强制工具化）

**目标**：从公历生日时分（含时区）→ 生成七政四余命盘（命宫、十一曜垣度、二十八宿躔位、神煞、十干化曜）。

**步骤**：
1. 输入：公历生日时分秒、出生地经纬度、性别。
2. 调用 `tool.xingming.bindisk(birth, location)` 得：
   - 12 宫位（命宫、财帛、兄弟、田宅、男女、奴仆、妻妾、疾厄、迁移、官禄、福德、相貌）
   - 11 曜实际黄经（日、月、木、火、土、金、水、罗、计、紫炁、孛）
   - 二十八宿对应躔位（命度所在宿、躔多少度）
   - 七煞神煞（劫煞、亡神、驿马、贵人、破碎、贯索、桃花）
   - 五要神煞（斗杓、卦气、唐符、国印、天雄、地雌）
   - 浮沉、羊刃、八煞、的煞、雌煞、雄煞
   - 量天尺定坐宫 + 洞微大限起运表
3. 校验：所有古书行度数据已自动按今日岁差校正。
4. **禁止**：任何手工套用古书行度数据。

**前置规则**：XR-05-01 量天尺定坐宫、XR-05-02 洞微大限。

## XP-02 三主取用流程

**目标**：定本命三主（宫主、度主、身主）。

**步骤**：
1. 由 XP-01 得命宫地支 → 查 12 地支五行对应表得**宫主**（如命宫亥 → 水为宫主）。
2. 由 XP-01 得命度躔某宿 → 查二十八宿星名得**度主**（如命躔角宿 → 木为度主）。
3. 若夜生：取月所躔之宿对应星为**身主**。
4. 三主取舍：
   - 默认以**度主为正**（XR-02-01）。
   - 度主失经时，按 XR-02-03 转生取用（展转生扶链）。
   - 若度主、宫主、身主冲突 → 度主优先；身主仅在夜生时启用。
5. 同时由 XP-01 得本生日干 → 查官魁例（XR-02-07 / [terms.md 5.2](./terms.md#52-十干化曜表卷四官魁例)）得**官星 / 魁星**。

**输出**：度主 / 宫主 / 身主 / 官星 / 魁星 / 恩主 五元素。

## XP-03 格局识别流程

**目标**：识别命盘所属贵格 / 败格。

**步骤**：
1. 由 XP-01 命盘 → 检测以下格局命中：
   - **五曜连珠**（XR-01-01）：五行星黄经连续 ≤ 60° 分布
   - **二星合璧**（XR-01-02）：日月或两大主星同宫同度
   - **朝拱辅夹**（XR-01-03）：吉星三方朝拱 + 左右辅夹命主
   - **经纬夹拱**（XR-01-04）：经纬两位有星夹拱命主
   - **卦禄斗并**（XR-01-05）：卦气 / 禄宫 / 斗杓三合一
   - **七政并旺**（XR-01-07）：七政齐旺
2. 反相格局检测：
   - **四主咸屯**（XR-01-08）：四主皆受困
   - **拱夹不起**（XR-01-09）：拱夹星不起本宫本度
3. 综合评判：吉格 ≥ 1 且无强败格 → 主贵 / 主富；强败格 ≥ 1 → 主败。
4. 引用四库案例时，引用前必须冠以"古书记载"前缀。

**输出**：贵格列表 / 败格列表 / 综合命格层级（参 XR-06-03 14 等口诀分级，但**剔除师尼娼妓项**，最低保留至"医卜""杂流"）。

## XP-04 行限推演流程

**目标**：推算大限、流年应象。

**步骤**：
1. 由 XP-01 得量天尺坐宫 + 洞微大限起运表。
2. 输入待查时间点（流年）→ 工具返回当前大限所在宫、流年太岁、流星位置。
3. 检测三方对照（XR-05-04）：流年三方有何吉凶星。
4. 检测四凶（XR-05-06）：冲、刑、压、逼。
5. 检测限主忌曜延病（XR-05-05）：若限主遇忌星但居旺乐廟 → 主病再延，**仅作典籍记录，不作硬判**。
6. **safety**：所有寿夭、死法、横死、缢死、产亡、虎咬蛇伤断语**全段屏蔽**（XR-08）。

**输出**：当前大限趋势（事业 / 财帛 / 健康），仅作"古文修辞性提示"，不作具体灾厄硬判。

## XP-05 与果老星宗互参流程

**目标**：本书与 [guotian-jing](../guotian-jing/index.md) 取用冲突时的优先级裁判。

**步骤**：
1. **起例层（神煞、洞微限、十一曜垣度、十干化曜）** → guotian-jing 优先（果老实操更详）。
2. **心法层（三主、强弱败旺、朝拱辅夹、经纬夹拱、五曜连珠）** → 本书优先（《星命溯源》是早期定本）。
3. **化气格** → 取果老起例（化气当从天官 → 但天官已佚 → 实际取果老）。
4. **正气格** → 取本书起例（正气当从果老 → 实际本书系果老之祖）。
5. 当两书互参仍冲突 → 在输出中标注"二家互异，本输出取 X 书理由 Y"。

## XP-06 与命主体系隔离流程

**目标**：避免与子平、相术混用。

**步骤**：
1. 输入命主信息 → 默认按本书 + guotian-jing 走七政四余路径。
2. 若用户已使用子平（八字）系统咨询 → **不允许混用术语**：
   - 子平"用神"（五行）≠ 本书"用神"（星辰）
   - 子平"格局"（食神制杀等）≠ 本书"格局"（五曜连珠等）
   - 子平"行运"（大运十年柱）≠ 本书"行限"（量天尺洞微限）
3. 若用户提供相貌 / 相术信息（神相全编） → 仅作**旁证层**辅助判断；本书命盘结论不被相术结论改写。
4. 当用户混合询问时，明确分系统输出，不作跨系统结论合并。

## XP-07 输出包装与 safety 屏蔽流程（强制最末环节）

**目标**：所有结论输出前的最终包装与屏蔽。

**步骤**：

### 7.1 输出前缀
所有本书相关回答必须冠以前缀：`[七政四余·星命溯源]`。

### 7.2 safety 全段屏蔽（最高级，无例外）
检测以下关键词 / 主题 → **整段屏蔽 + 引导至专业资源**：
- 寿命具体年限（"X 岁死""活到 Y 岁"）
- 具体死法（兵亡、溺水、虎咬、蛇伤、雷震、缢死、毒死、产亡、跌死、被打死、自缢、横死、暴死）
- 子嗣硬断（"无子""绝嗣""刑子""克妻"）
- 疾病硬判（"瞽""聋""喑""血毒""喘肺中疾""脾胃疾""血光"）
- 自残自伤倾向（直接转 24 小时危机干预热线）

### 7.3 女命 reframe（强）
检测女命相关查询 → 应用 XR-06 reframe：
- 删除"娼妓""师尼""三嫁不休""鼓盆""产亡"等贬义标签
- 改用"古代礼教记载，仅作典籍内部上下文留存"提示
- 现代女命取用与男命同等对待，不作专属女命贬斥

### 7.4 学派标注
回答中若涉及具体推命结论，须明示：
- 本结论源于七政四余《星命溯源》（化气从天官、正气从果老）
- 不替代子平四派
- 古书行度已通过 `tool.xingming.bindisk` 校正岁差

### 7.5 verified 标识
所有具体规则引用须附 `verified=false` 标识，提示用户：典籍内部一致性 ≠ 客观事实。

### 7.6 短引限制
直接引用原文 ≤80 字；超出须改写为现代汉语转述并标注出处。
