模块以 `main.py` 中的 `create_app()` 为唯一装配点：读取 `config.Settings`，构造并注入 `Database`、OTP 挑战/限流器、多种 OTP 投递适配器（fake/smtp/production-fail-closed/disabled）以及多个 `WindowRateLimiter` 到 `application.state`；注册全局异常处理器（`ApiProblem`、`RequestValidationError`），安装日志与请求可观测中间件，并挂载 API Router。
- `config.py`：基于 `pydantic-settings` 的 `Settings` 通过自定义 `settings_customise_sources` 将 `DEEPSEEK_API_KEY` 单独注入并从其他来源剥离，`model_validator` 集中执行生产环境安全策略（强制 secure cookie、禁止 fake adapter、校验 base64 32 字节内容密钥、冻结 P0 模型参数、锁定运行时路径与 manifest digest 等），并以 `@lru_cache(maxsize=1)` 暴露单例 `get_settings()`。
- `database.py`：封装 SQLAlchemy async engine/session factory，提供 `probe()` 健康检查与 `session()` 上下文管理器。
- `observability.py`：通过 `configure_logging` 设置结构化 JSON 日志并抑制敏感传输库日志，`install_request_observability` 注册 HTTP 中间件生成/透传 `X-Request-ID` 并记录请求指标。
- `network.py`：提供 `parse_trusted_proxy_cidrs` 与 `resolve_client_ip`，仅信任来自 `trusted_proxy_networks` 的 `x-forwarded-for` 链，防止任意头伪造。
- `persistence.py`：仅导出 `ImmutableRecordError` 作为不可变记录的领域异常，被上层持久化层复用。
依赖方向单向：`main` → `config/database/observability/network`，各子模块不反向依赖 `main`，便于测试时传入 mock 依赖。
