模块为独立的 Next.js 16 + React 19 应用（`admin/package.json`），通过 `src/app` 目录按路由划分页面：`/` 总览、`/users`、`/orders`、`/refunds`、`/readings`、`/audit`、`/login`，共享布局在 `src/app/layout.tsx` 中定义元数据与全局字体。
- 壳组件层：`src/components/admin-shell.tsx` 作为所有业务页面的父容器，负责导航菜单、会话校验（调用 `/api/v1/admin/me`）、登出跳转以及标题/职责描述渲染。
- 客户端 API 层：`src/lib/api.ts` 集中封装 `adminFetch`，自动注入 `same-origin` 凭据与 `x-csrf-token` 头，统一处理 204 空体、JSON 解析失败与错误响应中的 `title` 字段；类型定义覆盖 `StaffRole`、`AdminMeResponse`、`AdminOverviewResponse` 等。
- 环境标识：`src/lib/env.ts` 读取 `NEXT_PUBLIC_MINGLI_ENV` 并归一化为 `local|test|staging|production`，配合 `EnvBadge` 组件在页面上显示当前部署环境。
- 部署形态：`scripts/start-standalone.mjs` 将 `next build` 产物复制到 `.next/standalone`，拷贝 `public` 与静态资源后以 Node 进程启动，`package.json` 的 `start` 脚本即调用该入口。
依赖方向单向：pages → components → lib/api → 后端 `/api/v1/admin/*` 接口，不直接访问数据库或第三方服务。
