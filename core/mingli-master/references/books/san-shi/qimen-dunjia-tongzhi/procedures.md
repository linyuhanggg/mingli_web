# 奇门遁甲统宗大全 — Procedures

## Skill Loading Procedure

1. 先读 `index.md` 的版本说明和限制。
2. 按问题类型选择章节：源流/版本读源流；规则总纲读凡例；基础格局读卷一；构件定义读卷二；起局流程读卷三；应用占断读“奇门演义”；赋文归纳读卷十至十二。
3. 引用规则前，到 `quote-index.md` 找至少一条短引，再回 `fulltext.md` 查上下文。
4. 涉及择日、阴阳宅、出行、兵事避忌时，同时调用择日/风水 corpus，而不是只读本书。
5. 涉及起局计算时，输出“需排盘核验”的中间状态；不要让语言模型凭记忆排局。
6. 输出给用户时必须说明：此为传统术数文本整理与文化研究，不是现实确定性预测。

## D3 Skill Extraction Targets

- `concepts.yaml`: 三奇、六仪、八门、九星、八神、值符值使、九宫、阴阳遁。
- `patterns.yaml`: 龙回首、鸟跌穴、龙逃走、虎猖狂、腾蛇妖矫、朱雀投江、五不遇、门迫等格局。
- `decision_flow.md`: 问事分类 -> 是否需起局 -> 取动静/方向 -> 宫门星神奇仪 -> 生克衰旺 -> 互证来源。
- `safety.md`: 禁止确定性承诺、重大决策边界、版本不确定性提示。
