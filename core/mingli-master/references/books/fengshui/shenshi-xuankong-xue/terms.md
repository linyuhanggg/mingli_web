# 增广沈氏玄空学 — Terms

### 玄空
- **义**：沈氏以“一至九”与“九窍”等解释玄空，用于九星飞布体系的总名。
- **出处**：论玄空。

### 天心
- **义**：玄空理气中取中、立极、定向的核心观念。
- **出处**：论天心。

### 罗经
- **义**：二十四山、分金、山向与理气操作的工具层。
- **出处**：论罗经、罗盘图说。

### 紫白
- **义**：一白至九紫飞星系统，是沈氏玄空论述的核心数理层。
- **出处**：论紫白、九运挨星立成图。

### 下卦 / 起星
- **义**：玄空排盘操作中决定星盘飞布的技术环节。
- **出处**：论下卦、论起星。

### 到山到向 / 上山下水
- **义**：山星、向星与形势配合的吉凶判断术语。
- **出处**：论上山下水、到山到向。

### 城门
- **义**：玄空水路/气口取用的重要法门。
- **出处**：论城门。

### 七星打劫
- **义**：玄空派中关于特殊格局与劫夺取用的术语。
- **出处**：论七星打劫。

### 反吟伏吟
- **义**：飞星盘与山向、元运关系中的重复/冲突格局。
- **出处**：论反吟伏吟。

### 阴宅秘断 / 阳宅秘断
- **义**：以实际墓宅案例说明山向、元运、形水与飞星应验的案例层。
- **出处**：卷三阴宅秘断、阳宅秘断。
