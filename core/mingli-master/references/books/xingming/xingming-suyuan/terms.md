# 星命溯源 · 术语表

## 1. 三主取用（本书核心）

### 1.1 宫主
命宫所在地支宫位的对应五行所主之星。例如命宫在亥则水为宫主。本书认为袁天纲早期"专用宫主"为偏，应改用度主为正。

### 1.2 度主
命宫所躔二十八宿星宿的本宿之星（角木为木、亢金为金、氐土为土、女土为土、虚日为日、心月为月等）。本书定调"专用宫主为非，度主为是"。

### 1.3 身主
夜生人取月所躔之宿之星为身主，与命主互参。

### 1.4 三主互用
张果原意为宫主、度主、身主三者互参不偏废；先生最终主张以度主为正、宫主身主为辅。

## 2. 格局取贵纲领

### 2.1 五曜连珠
五大行星（木火土金水）连续排列于相邻或同宫，主大格君臣庆会。

### 2.2 二星合璧
日月或两大主星会合于一宫一度，主清贵。

### 2.3 戴天履地 / 出乾入巽
戴天即首星顶部、履地即足星根部；出乾入巽指星气流动的方位次序。

### 2.4 文武两班
五星分别朝拱命宫两侧如文武百官分立朝堂，主君臣慶會大格。

### 2.5 朝拱
三方（120°位）星辰相向而朝，名朝拱。

### 2.6 辅夹（夹拱）
左右（命宫前后宫）两星相辅相夹，名夹拱。

### 2.7 居三隔三
星辰分布间隔三宫均匀排列。

### 2.8 守一空一
一星守命位、相邻一宫空位无星。

### 2.9 经纬
经为南北子午线（命迁线）、纬为东西卯酉线（身福线）；经纬夹拱主大格。

### 2.10 直撞 / 横冲
南北对冲为直撞、东西对冲为横冲；流年逢之有应。

## 3. 强弱败旺四态

### 3.1 强（旺）
得令时令、入垣升殿庙旺、得生扶。

### 3.2 弱
失时失令、不入垣不入庙、生气孤立。

### 3.3 败
被克太重、坐败地、限运逢冲克。

### 3.4 旺
四时令旺：木旺春、火旺夏、金旺秋、水旺冬、土旺四季月。

### 3.5 得令 / 失时 / 入垣 / 失次
四组对仗术语，描述星曜状态。

### 3.6 登殿入庙
- 升殿：太阳到午、太阴到子等本气主位。
- 入庙：行星到自身所主宫位（木到寅卯、火到午、金到酉、水到子、土到辰戌丑未）。
- 入垣：到与自身五行同气之地。
- 喜乐：到与自身五行相生之地。

## 4. 神煞与限度

### 4.1 斗杓
北斗星之柄（魁罡指向）；卦气、唐符、国印、斗杓为本书"五要"神煞。

### 4.2 卦气
天禄之余气，主食禄。

### 4.3 唐符
直年之星，主武官权柄。

### 4.4 国印
朝廷之印，主正官印授；值空亡到任而死。

### 4.5 天雄
乾象阳刃，主威权但带破相、性凶。

### 4.6 地雌
坤象阴刃，与天雄对，女命忌之。

### 4.7 天耗 / 地耗
对宫大耗、本宫小耗，守命忌财鄉。

### 4.8 飞廉
金煞之最重者，主夭、暴亡。

### 4.9 劫煞 / 亡神 / 驿马 / 贵人 / 破碎 / 贯索 / 桃花
七煞神并称，本书后天口诀以此为推命要素。

### 4.10 浮沉 / 羊刃 / 八煞
浮沉为水土相克、羊刃为五行刃星、八煞为坐对各干之命煞。

### 4.11 阴注阳受
干支注、五星受；身命值之可化凶为吉，但需吉星扶。

### 4.12 量天尺 / 洞微大限
两套行限工具：量天尺定坐宫、洞微大限定行运。

## 5. 十干化曜（官魁例）

### 5.1 官魁
"前为官、后为魁"——每一个日干对应两颗化曜，前者主功名（官星），后者主科甲（魁星）。

### 5.2 十干化曜表（卷四官魁例）
| 日干 | 官星 | 魁星 |
|---|---|---|
| 甲 | 炁 | 月 |
| 乙 | 水 | 日 |
| 丙 | 罗 | 罗 |
| 丁 | 计 | 计 |
| 戊 | 孛 | 火 |
| 己 | 火 | 金 |
| 庚 | 金 | 水 |
| 辛 | 木 | 孛 |
| 壬 | 月 | 炁 |
| 癸 | 土 | 木 |

注：与《果老星宗》十干化曜表"甲炁乙水丙罗丁计戊孛己火庚金辛木壬月癸土"一致，但本书额外区分"官 vs 魁"双星制。

### 5.3 恩主
本生日干所属本气星（火命人之火、水命人之水），随身为富贵格之主。

### 5.4 用神 / 满用
古文中的"用"指"被取用之星"（≠子平用神）。一星滿用指诸星沉退、独此一星取用，主大贵。

## 6. 特殊星格名

### 6.1 太乙抱蟾
土星（太乙）与月（蟾）相会于酉未，主文朝秀士。

### 6.2 抱死鬼（太乙抱鬼）
亥戌丑宫月既晦时与孛同度，名"抱死鬼"。

### 6.3 朝斗
计都罗火孛聚于丑亥，名朝天拱斗，本是凶神反为上客。

### 6.4 玄武引驾
水星在日前作前导，又值吉神化三元为最妙；夜生人重身度主用之。

### 6.5 朱雀朝天 / 朱雀捧御
火星捧太阳前行得令为上格。

### 6.6 君臣庆会
日月五星齐聚朝拱主星，宛若君臣同朝；主梁栋之材、廊庙之器。

### 6.7 五曜连珠 / 三阳开泰
五星连珠为大格；宫身度三主俱躔阳度名"三阳开泰"。

### 6.8 阳刃地雌 / 天雄夹命
阳刃与地雌同夹命位；天雄星附命主性雄而横。

### 6.9 拱夹太岁 / 拱夹大耗
日月拱夹太岁为大吉、拱夹大耗为大败。

## 7. 限度术语

### 7.1 量天尺
按生时定坐宫之尺，本书强调"行限先依量天尺上按定坐宫"。

### 7.2 洞微大限
按宫位推大限，本书"次依洞微大限行去"。

### 7.3 流年 / 流星 / 流运
流年（太岁所到）、流星（流年所行星辰）、流运（行限主星）。

### 7.4 交宫过度
太阴交宫过度时刻有八刻深浅之分，是"共时不同命"的天文解释。

### 7.5 度主朝陽
度主飞起朝至太阳所在，为贵格但不可执泥。

### 7.6 注受 / 注受勋
干支与时位相会之处，主好运起点。

## 8. 古文修辞专名

### 8.1 漂流 / 漂蓬 / 漂泛
水星太过失制为漂；多用于"漂蓬落魄"等贬义。

### 8.2 鼓盆之叹
妻宫坏；典出庄子鼓盆而歌（丧妻）。

### 8.3 闲极 / 闲奴
闲宫之极、家奴星；命人坐之主非贵格。

### 8.4 师尼 / 缁黄
师尼即比丘尼、缁黄即僧道（本书有强 reframe 警告）。
