# 神相全编 — 术语表

> 术语量大且重叠（同一概念在 9 卷中多次出现），按"全书核心 + 各卷特色"分组列出 38 条代表性术语。
> 旁证层；不参与命盘硬判断。

---

## A. 总论 / 基础概念（11 条）

### 形 (xíng)
- **义**：身骨血肉的外在形态。
- **出处**：卷一·论形；卷三·五行象说；卷五·形神。
- **关联**：与"神""气""声"并列为"形神气声"四要素。

### 神 (shén)
- **义**：眼神所现之精神气宇；古文以"藏 / 露 / 清 / 浊 / 静 / 躁"分级。
- **出处**：卷三·论神；卷七·岩电道人神眼经；卷九·杨氏论神气。
- **关联**：与"骨"合称"神骨"（与冰鉴互参）。

### 气 (qì)
- **义**：呼吸吐纳所现之内蕴；古文有"气定 / 气浮 / 气壮 / 气虚"。
- **出处**：卷三·论气。
- **关联**：与"色"合称"气色"。

### 声 (shēng)
- **义**：声音之响、清、浊、续、断；为四要素之一。
- **出处**：卷三·论声；卷九·正声歌。

### 骨 (gǔ)
- **义**：骨骼。古文重"九骨"（颧骨、驿马骨、将军骨等命名骨位）。
- **出处**：卷一·骨肉；卷九·体骨歌。
- **关联**：神骨为相术第一观（与冰鉴互参）。

### 肉 (ròu)
- **义**：肌肉皮肉。古文与骨并论："骨主寒、肉主暖"。
- **出处**：卷一·骨肉总论。

### 色 (sè)
- **义**：面部气色。
- **出处**：卷一·论气色；卷九·正色歌。
- **caveats**：气色受光照、健康、情绪影响极大；现代禁用作硬判断。

### 形神气声 (xíng-shén-qì-shēng)
- **义**：相术四要素总称；卷三·五行象说为代表论述。
- **关联**：与冰鉴"神骨 / 刚柔 / 容貌 / 情态 / 须眉 / 声音 / 气色"七章可对应。

### 三停 (sān-tíng)
- **义**：面三停（额至眉、眉至鼻、鼻至颏）+ 身三停（头至腰、腰至膝、膝至足）。
- **出处**：卷一·面三停；卷二·身相三停。

### 五行形 (wǔ-xíng-xíng)
- **义**：木瘦 / 火尖 / 土厚 / 金方 / 水圆 五种基本体型。
- **出处**：卷二·五行形相；卷三·五行象说。

### 学堂 (xué-táng)
- **义**：四学堂 / 八学堂；面部主智慧 / 学问的部位群。
- **出处**：卷一·四学堂八学堂学堂诗。

## B. 部位类（10 条）

### 十三部位 (shí-sān-bù-wèi)
- **义**：天中 / 天庭 / 司空 / 中正 / 印堂 / 山根 / 年上 / 寿上 / 准头 / 人中 / 水星（口） / 承浆 / 地阁 共 13 个面部主要部位。
- **出处**：卷一·十三部位。

### 五官 (wǔ-guān)
- **义**：耳 = 采听官 / 眉 = 保寿官 / 目 = 监察官 / 鼻 = 审辨官 / 口 = 出纳官。
- **出处**：卷二·达摩五官总论。

### 五岳 (wǔ-yuè)
- **义**：额 = 衡岳 / 左颧 = 泰岳 / 右颧 = 华岳 / 鼻 = 嵩岳 / 颏 = 恒岳。
- **出处**：卷二·五岳。

### 四渎 (sì-dú)
- **义**：耳 = 江渎 / 目 = 河渎 / 鼻 = 济渎 / 口 = 淮渎。
- **出处**：卷二·四渎。

### 五星六曜 (wǔ-xīng-liù-yào)
- **义**：金木水火土五星 + 日月罗计紫炁六曜，皆配面部部位。
- **出处**：卷二·五星六曜说。
- **caveats**：与七政星命之"五星六曜"同名异用；不可与星盘直接换算。

### 六府 (liù-fǔ)
- **义**：上二府（辅角、天仓）+ 中二府（颧骨、命门）+ 下二府（腮骨、地阁）。
- **出处**：卷二·六府。

### 三才 (sān-cái)
- **义**：天（额）/ 人（鼻）/ 地（颏）三部。
- **出处**：卷二·三才三停。

### 流年部位 (liú-nián-bù-wèi)
- **义**：百岁面部流年图；童限至 99 岁的面部年龄分布。
- **出处**：卷一·流年运气部位歌。
- **caveats**：现代不允许据此对个人作具体年份吉凶判断。

### 十二宫 (shí-èr-gōng)
- **义**：命宫 / 财帛 / 兄弟 / 田宅 / 男女 / 奴仆 / 妻妾 / 疾厄 / 迁移 / 官禄 / 福德 / 父母。
- **出处**：卷一·十二宫诀。
- **caveats**："妻妾""男女"二宫对应现代婚育判断屏蔽。

### 印堂山根 (yìn-táng / shān-gēn)
- **义**：眉间为印堂，山根为鼻根。
- **出处**：卷四·相印堂；卷四·相山根。

## C. 形局 / 格局类（9 条）

### 五合五短五长 (wǔ-hé / wǔ-duǎn / wǔ-cháng)
- **义**：相五合（大小相称）/ 相五短（五体均短而灵）/ 相五长（五体均长而秀）。
- **出处**：卷五·相五合 / 相五短 / 相五长。

### 五露 (wǔ-lù)
- **义**：眼露 / 鼻露 / 耳露 / 唇露 / 喉露；古文以"五露俱不可"。
- **出处**：卷五·相五露。

### 八大八小 (bā-dà / bā-xiǎo)
- **义**：八种大相 / 八种小相。
- **出处**：卷五·相八大 / 相八小。

### 富贵寿福格 (fù-guì-shòu-fú gé)
- **义**：富格例 / 贵格例 / 寿相格 / 福德格例 四种"成格"。
- **出处**：卷三·富格例～福德格例。
- **caveats**：现代不作个人富贵寿福硬判断；只作语义提取。

### 凶相诸格 (xiōng-xiàng zhū-gé)
- **义**：孤格、夭相、窮蹇、刑剋、剋妻妾、剋子息、孤神、寡宿、亡神、劫殺、奸詐、貪食、惡死、溺水、火災 等近 25 格。
- **出处**：卷三·凶相诸格。
- **caveats**：**整段属强贬义 + 灾祸预测**；本 pack 仅记录目录，不复制内容；**禁用**于具体个人。

### 六恶六贱 (liù-è / liù-jiàn)
- **义**：六种恶相 / 六种贱相。
- **出处**：卷五·相六恶 / 相六贱。
- **caveats**：**强贬义**；不参与命盘判断；不可用于人际评价。

### 八相法 (bā-xiàng-fǎ)
- **义**：观人八相法；含威 / 厚 / 清 / 古 / 孤 / 薄 / 恶 / 俗 八格。
- **出处**：卷五·观人八相法。

### 三主三柱 (sān-zhǔ / sān-zhù)
- **义**：相之三主（初年 / 中年 / 末年）；论三柱即天柱地柱人柱。
- **出处**：卷二·相三主 / 论三柱。

### 体骨歌 (tǐ-gǔ gē)
- **义**：体骨成局之韵语口诀。
- **出处**：卷九·体骨歌。

## D. 动物比喻类（4 条）

### 动物眼相 (dòng-wù yǎn-xiàng)
- **义**：龙眼 / 凤眼 / 猴眼 / 象眼 / 狼目 / 蛇眼 / 鱼眼 / 鸡眼 等 30 余种以动物喻眼形。
- **出处**：卷三·相目论。
- **caveats**：仅作"形态分类标签"语义还原，不输出贬义判断（如"狼目主凶"屏蔽）。

### 动物耳相 (dòng-wù ěr-xiàng)
- **义**：鼠耳 / 猪耳 / 棋子耳 / 垂珠耳 / 贴脑耳 等。
- **出处**：卷四·相耳。
- **caveats**：同上。

### 动物口相 (dòng-wù kǒu-xiàng)
- **义**：吹火口 / 鲇鱼口 / 樱桃口 / 仰月口 / 覆船口 等。
- **出处**：卷四·相口。
- **caveats**：同上。

### 动物鼻相 (dòng-wù bí-xiàng)
- **义**：伏犀鼻 / 悬胆鼻 / 截筒鼻 / 鹰嘴鼻 / 蒜鼻 / 狮子鼻 等。
- **出处**：卷四·相鼻。
- **caveats**：同上。

## E. 各家相赋 / 韵语类（4 条）

### 神异赋 (shén-yì fù)
- **义**：陈抟传授麻衣的著名相赋；含名句"骨格为一世之荣枯，气色定行年之休咎"。
- **出处**：卷六·神异赋。

### 麻衣金锁赋 (má-yī jīn-suǒ fù)
- **义**：麻衣派根本相赋；与"银匙歌"并称。
- **出处**：卷七·麻衣金锁赋。

### 人伦大统赋 (rén-lún dà-tǒng fù)
- **义**：张行简集大成的相术总赋；分上下两篇。
- **出处**：卷七·上 + 卷八·下。

### 何知歌 (hé-zhī gē)
- **义**：以"何知人……"句式列举具体相征对应人生境遇的韵语；含"恶死歌""无子歌""刑害歌"等姊妹篇。
- **出处**：卷九·何知歌。
- **caveats**：**整段属灾祸 / 寿命 / 子嗣预测**；本 pack 仅作目录引用，**禁用**于具体个人。
