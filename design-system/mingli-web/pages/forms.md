# Forms — Surface Override

**Routes:** profile create, liuyao, fortune, need-input, verification, follow-up  
**Mode:** Operate  
**World:** Eastern Editorial Archive

## Motion thesis

- **Focal moment:** Form shell paper entrance once on mount.
- **Feedback:** Input border/background on hover/focus; choice/radio moss selected fill; primary action 2px lift + press scale.
- **Errors:** Nearby error text may enter with opacity + 4–6px y; never hide content behind motion.
- **Budget:** Feedback 180ms; shell 260–450ms; no layout animation.

## Rules

- Labels always visible; 48px controls; 44px targets.
- Transition props limited to transform / opacity / colors.
- Infinite animations forbidden on form surfaces.
