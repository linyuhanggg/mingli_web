模块以 `main.py` 定义通用 worker 框架：抽象出 `WorkSource`/`WorkProcessor` Protocol、`Worker` 数据类以及 `run_once`/`run_forever` 循环，并通过 `async_main` + `parse_args` 暴露 CLI（`--once`、`--poll-interval`）。`readings.py` 在该框架之上实现具体领域逻辑：`ReadingJobWorkSource` 通过 SQL `SELECT ... FOR UPDATE SKIP LOCKED` 抢占式领取 `ReadingJobRecord`，使用 claim_token + lease_generation + lease_expires_at 做租约防重入；`ReadingJobProcessor` 在事务内校验租约后调用 `SqlReadingOrchestratorFactory` 构建的 `ReadingOrchestrator` 执行业务流程，并以条件更新释放租约。`configured_reading_worker` 作为 async context manager 装配 Settings、Database、RuntimePort、NarrativeModelPort 与 AlertSink，并在 staging/production 环境强制要求真实适配器。依赖方向单向：`readings.py` → `worker.main`，反向不依赖，使 worker 核心可被测试替换为 `InMemoryWorkSource`/`RecordingProcessor`。
