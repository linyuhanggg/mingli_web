## 2. 视觉诊断（Assessment A）

### P1 高优先级（三件，先修）
1. **模板脸**：首屏 100% 文字、零盘面视觉；次 CTA 文案错成「多术合参」（合同是「看示例盘面」）；任务卡无领域图形。
2. **决策过载**：首页 13 平级入口（超出工作记忆 4–7）；命盘区 4 卡 3+1 破行、七政孤卡；Mega 菜单 13 项超合同；360 首屏第一张可点卡在折线之下（y≈837）。
3. **结果句与弃用词**：首屏无“算完长什么样”的预览；/pricing 出现「今日/本周」旧产品词（与 CHECKLIST 新地图冲突）。

### P2
- `--color-text-muted #8a8a8a` 全站 12–13px 元信息实测对比度 3.31–3.45:1，不达 WCAG AA（不干净感的元凶）；提到 ≥#6e6e6e 即可。
- 动效/阴影零剧本：唯一 hover 仅 5% 透明阴影 + 160ms；合同允许 120–280ms 微交互配额基本没用。

### P3 磨光项
h1 字重三家族漂移（700/580/620）；768 视口 h1 被压到 40px；/library 灰色主按钮破坏黑主按钮词汇；品牌副标“可核对盘面·中性界面”把工程姿态当口号；每日页首屏 3/4 空白。

**真实优点（保住）**：token/响应式纪律、状态诚实（身份未知/适配中/测试期无支付）、聚焦录入形态——这三样是新视觉世界的承重墙。

## 4. 结构清单（Assessment C）

- **规模**：web 67 page + 7 layout；admin 42 page；route.ts 0。组件 94 文件/18,279 行（web）+ 65/10,792（admin）；CSS 11,139 + 3,803 行；测试 105 个。
- **重复三宗最**：
  1. web 14 个术数入口 = 同一 9 行壳 ×14（差异仅 `productId`）；
  2. admin 37 个 5 行壳全转发 `AdminCatalogPage`：文件系统 + 41 条 `admin-route-catalog.ts` + 113 行 if/else 三层重复；
  3. web/admin 各持一份 8 组件 ui 库副本（已漂移：table 295↔300、drawer 56↔64），根 `ui/` 包只有 CSS。
- **其余实锤**：7 个不可达 legacy `/app/*` 页面与 next.config 双编码；`/account/invitations`≈`/invites`、`settings/privacy-data`≈`data-rights` 两组等价路由；`dashboard-hub`(662 行) 死代码。
- **Top10 重构候选**：R1 删 7 legacy 页 / R2 account 等价路由去重 / R3 admin catch-all 数据驱动 / R5 合并双份 ui 组件 / R6 tools/[tool] 拆分 / R7 spec 包装层去双写 / R8 删 dashboard-hub / R9 上帝组件拆分 / R10 CSS 去重。R4（14 术数动态段）被 C 明确标注“不建议近期做”（SEO 深链 + 契约绑定，纸面省行代价大于收益）。
