# 果天经/果老星宗 — 术语表

> 七政四余系统术语量极大，本表收 42 条核心术语；分 5 组：基础天文 / 11 曜 / 主星与神煞 / 格局 / 限度。

## A. 基础天文（10 条）

### 二十八宿 (èr-shí-bā xiù)
- **义**：黄道附近 28 个恒星组团；分东 / 北 / 西 / 南 四象七宿。
- **出处**：篇一·东 / 北 / 西 / 南七宿。
- **关联**：每宿含 1 个"星禽"（角木蛟、亢金龙……）+ 度数（角 12°、亢 9°……）。

### 星禽 (xīng-qín)
- **义**：二十八宿之每宿配以一动物 + 五行 + 七政之一组合（如"角木蛟"= 木属性的蛟龙）；用于宿度配五行。
- **出处**：篇一·度数所属。

### 十二宫 (shí-èr-gōng)
- **义**：黄道分 12 等份；中国版（子丑寅卯辰巳午未申酉戌亥）配西法（宝瓶 / 磨羯 / 人马 / 天蝎 / 天秤 / 双女 / 狮子 / 巨蟹 / 阴阳 / 金牛 / 白羊 / 双鱼）+ 中国分野。
- **出处**：篇一·宫分所属。
- **caveats**：本宫"双女"= 室女座；"阴阳"= 双子座；与字面意思不同。

### 度数所属 / 度数所在 (dù-shù suǒ-shǔ / dù-shù suǒ-zài)
- **义**：每宿包含的度数 + 该度数所在十二宫之归属。
- **出处**：篇一·度数所属 + 度数所在。
- **caveats**：**古值受岁差影响**，现代必须由 tool 重算。

### 节气行度 (jié-qì xíng-dù)
- **义**：24 节气太阳所躔之宿度；古书每节气一表。
- **出处**：篇一·太阳行度。
- **caveats**：**古值已被岁差打乱**；现代弃用。

### 命宫 (mìng-gōng)
- **义**：依出生时刻 + 太阳所躔起算的命主之宫。
- **出处**：篇一·安命度法。
- **caveats**：手算屏蔽，依工具。

### 限度 (xiàn-dù)
- **义**：大限（一限 / 行宫）+ 小限 + 童限的总称。
- **出处**：篇一·定限度法 + 定小限例 + 定童限例歌；篇五·洞微百六限说。

### 童限 (tóng-xiàn)
- **义**：童年期（一般 1-13 岁）之限运；古书有专歌。
- **出处**：篇一·定童限例歌。
- **caveats**：对个人未来年份禁用。

### 节气 / 七十二候 (jié-qì / qī-shí-èr hòu)
- **义**：24 节气分 72 候，每候 5 日。
- **出处**：篇一·二十四气七十二候之图。

### 入垣升殿庙旺喜乐 (rù-yuán / shēng-diàn / miào-wàng / xǐ-lè)
- **义**：星辰落于本宫 / 升于殿位 / 处于庙地 / 处于喜乐之宫的 4 种强势位置；与"贵格 / 贱格"对应。
- **出处**：篇一·星辰入垣 / 升殿 / 庙旺 / 喜乐 / 贵格 / 贱格图。

## B. 十一曜（11 条）

### 七政 (qī-zhèng)
- **义**：日 / 月 / 金 / 木 / 水 / 火 / 土 七大星；中国天文之"七政"。
- **出处**：篇一·七政之图。

### 四余 (sì-yú)
- **义**：罗（火之余）/ 计（土之余）/ 紫炁（木之余）/ 月孛（水之余）四隐曜。
- **出处**：篇一·七政之图；篇四·先天心法。
- **caveats**：四余为印度天文学传入；现代天文学无此 4 颗"星"，是计算出的"假想点"（黄白交点 / 月行近地点）。

### 十一曜 (shí-yī yào)
- **义**：七政 + 四余之总称。
- **出处**：篇四·先天心法。

### 罗（罗睺）(luó-hóu)
- **义**：黄道升交点；火之余。
- **caveats**：印度占星术之 Rāhu。

### 计（计都）(jì-dū)
- **义**：黄道降交点；土之余。
- **caveats**：印度占星术之 Ketu。

### 紫炁 (zǐ-qì)
- **义**：木之余；中国独有的虚星概念。

### 月孛 (yuè-bèi)
- **义**：水之余；近月点。

### 太阳 (tài-yáng)
- **义**：日；昼生主。
- **出处**：篇五·张果星宗十四·太阳算法日篇。

### 太阴 (tài-yīn)
- **义**：月；夜生主；身主之关键。
- **出处**：篇五·张果星宗十一·太阴论。

### 火星 / 土星 (huǒ-xīng / tǔ-xīng)
- **义**：与"罗""计"配对（火 = 罗之本，土 = 计之本）；昼忌火，夜忌土。
- **出处**：篇五·先天心法。

### 金水木火土五星 (jīn shuǐ mù huǒ tǔ wǔ-xīng)
- **义**：五大行星；构成 11 曜核心。

## C. 主星与神煞（13 条）

### 宫主 (gōng-zhǔ)
- **义**：命宫所属十二宫之五行星；如子宫属土，宫主为土星。
- **出处**：篇五·宫度主论。

### 度主 (dù-zhǔ)
- **义**：命度（命宫所躔的具体宿度）所属之星；如命躔虚日鼠则度主为日。
- **出处**：篇五·宫度主论。

### 身主 (shēn-zhǔ)
- **义**：太阴所躔度之主星；女命尤重；"昼生看命度主，夜生看身度主"。
- **出处**：篇五·宫度主论。

### 福主 (fú-zhǔ)
- **义**：福德宫之主星。
- **出处**：篇四·先天心法。

### 卦气 (guà-qì)
- **义**：天禄之余；张果原书核心隐曜之一。
- **出处**：篇四·至宝论。

### 斗标 / 注受 (dǒu-biāo / zhù-shòu)
- **义**：北斗之柄 / 朝廷之印；二者守命主大贵。
- **出处**：篇四·至宝论；篇二·斗标注受。

### 唐符 / 国印 (táng-fú / guó-yìn)
- **义**：直年之星 / 朝廷之印；二者武官 / 正印。
- **出处**：篇四·后天口诀；篇二·唐符国印。

### 天雄 / 地雌 (tiān-xióng / dì-cí)
- **义**：乾象 / 坤象；常人命中皆有；落空亡则无片瓦。
- **出处**：篇四·后天口诀。

### 阳刃 (yáng-rèn)
- **义**：阳干之刃神煞；煞星之最强者；与火罗配则尤忌。
- **出处**：篇二·阳刃；篇二·驾前神杀歌。

### 咸池 (xián-chí)
- **义**：桃花煞；金水坐子卯为"无礼之人"等贬义判语。
- **出处**：篇二·咸池。
- **caveats**：reframe 必须；女命相关条目按 safety-redlines。

### 三刑 / 六害 / 劫杀 / 亡神 (sān-xíng / liù-hài / jié-shā / wáng-shén)
- **义**：地支煞群；多与"凶亡""灾祸"语相关。
- **出处**：篇二·三刑六害劫杀亡神。
- **caveats**：reframe；硬判断 safety-redlines。

### 孤辰 / 寡宿 (gū-chén / guǎ-sù)
- **义**：孤虚煞；与婚姻判断相关。
- **出处**：篇二·孤辰寡宿。
- **caveats**：婚姻 safety-redlines。

### 天罗 / 地网 (tiān-luó / dì-wǎng)
- **义**：戌亥为天罗，辰巳为地网；两煞临命主"狱讼""博戏亡家"。
- **出处**：篇二·天罗地网。
- **caveats**：硬判断 safety-redlines。

## D. 格局组合（4 条）

### 经纬夹拱 (jīng-wěi jiā-gǒng)
- **义**：天经地纬两星夹拱命宫；为贵格。
- **出处**：篇四·至宝论。

### 朝拱 / 辅夹 / 引从 / 分会 (cháo-gǒng / fǔ-jiā / yǐn-cóng / fēn-huì)
- **义**：四种"拱"组合；星辰围绕命宫之布局。
- **出处**：篇一·星命溯源（互参）；篇四·至宝论。

### 五曜连珠 / 二星合璧 (wǔ-yào lián-zhū / èr-xīng hé-bì)
- **义**：五星连成一线 / 二曜（日月）合于一宫；万乘之主之极贵格。
- **出处**：篇五·张果星宗十一·太阴论引文。

### 太乙抱蟾 / 玉兔腾空 (tài-yǐ bào-chán / yù-tù téng-kōng)
- **义**：太阴与计都同宫 / 太阴升于天门；古典美格名。
- **出处**：篇四·先天心法；篇五·太阴论。

## E. 限度细分（4 条）

### 洞微百六限 (dòng-wēi bǎi-liù xiàn)
- **义**：限度共 106 年分配于 12 宫：命 15 + 禄 15 + 妻 11 + 田 4.5 + 子孙 4.5 + 奴仆 4.5 + 财 5 + 兄弟 5 + 相貌 10 + 疾厄 / 迁移 各 7.5。
- **出处**：篇五·张果星宗十六·洞微百六限说。

### 限主 (xiàn-zhǔ)
- **义**：本限所行宫之主星；统论限说之第一急务。
- **出处**：篇五·张果星宗十七·统论限说。

### 顺行 / 逆行 / 伏逆 (shùn-xíng / nì-xíng / fú-nì)
- **义**：星行黄道之顺逆 / 太阳光下不见之伏；影响吉凶力度。
- **出处**：篇五·统论限说。

### 三方对照 (sān-fāng duì-zhào)
- **义**：本宫 + 三合 + 对宫；星见三方对照分担吉凶力（本宫 10 / 对照 7 / 三合 4）。
- **出处**：篇五·统论限说。
