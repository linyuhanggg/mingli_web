## 决策

1. 用户批准以视觉真值中的“动态水墨 + 液态玻璃”作为 `/` 首页视觉试点，并要求进入动态原型阶段。
2. 本决策是 Direction C 的**首页专属表现层例外**，不是第二套全站合同。账户、产品录入、工作台、Admin 和其他路由继续服从 Direction C；不得据此把它们改成玻璃界面。
3. 首页保留既有 IA、路由、一级导航、任务入口与真实内容边界。Hero 主标固定为「十三术同根，五十五部古籍为证」，主 CTA 固定为「开始排盘」，次 CTA 固定为「命盘合参」。
4. 首页允许使用暖宣纸基底、淡水墨、用户提供的符箓与品牌图形、克制的朱砂/淡金点缀；允许液态玻璃顶栏，以及 Hero 或少量内容面的玻璃处理。它们不得变成密集的全页玻璃卡片，也不得牺牲文本、焦点、导航状态或 CTA 对比度。
5. 首页范围内，Direction C 对暖象牙/金色、玄学装饰、玻璃拟态和常驻装饰动画的绝对禁令由本记录精确覆盖；其余页面的默认禁令不变。

## 动态原型合同

- 可用装饰动效仅限：符箓随风缓慢漂移、水墨缓慢呼吸或平移、水滴/涟漪；
- 动画只使用 `transform` 与 `opacity`，采用长周期和克制幅度；
- 禁止滚动劫持，禁止持续 `blur`、`filter` 或布局动画，禁止让装饰影响阅读、点击、键盘路径或页面几何；
- 装饰层必须 `aria-hidden="true"` 且 `pointer-events: none`，不能承载信息；
- `prefers-reduced-motion` 下静态降级，导航、主张、真实内容和两个 CTA 均不得缺失或延迟。

## 不变边界

- 不新增、删除或改名一级导航，不调整现有产品 IA 或路由；
- 不伪造能力、盘面、古籍证据、用户评价、订单、价格或活动；
- 不把用户提供的符箓与品牌图形解释为新的产品能力或证据；
- 不修改 Direction C 对账户、工作台、Admin、可访问性、响应式和真实数据的合同。
