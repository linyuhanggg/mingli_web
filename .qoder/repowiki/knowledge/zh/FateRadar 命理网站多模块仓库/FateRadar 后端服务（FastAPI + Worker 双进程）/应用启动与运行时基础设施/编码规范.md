- 配置项通过 `pydantic-settings` 的 `BaseSettings` 声明默认值与约束，并在 `model_validator(mode='after')` 中集中执行跨字段的环境安全校验。
- 敏感字段统一使用 `pydantic.SecretStr` 并通过 `.get_secret_value()` 访问，避免在日志或序列化中泄露。
- 应用级共享状态通过 `application.state.*` 注入（settings、database、各类 rate limiter、otp delivery 等），由 `create_app` 一次性装配。
- 外部可替换能力（OTP 投递、模型、运行时）采用适配器模式，依据 `Settings` 中的字符串标识在启动期选择具体实现。
- 请求追踪通过中间件注入 `request.state.request_id` 并在响应头回写 `X-Request-ID`，所有 HTTP 日志以结构化 JSON 形式输出到 `mingli.api` logger。
- 网络客户端 IP 解析严格区分直连与可信代理，仅当对端位于配置的 CIDR 白名单内才解析 `x-forwarded-for` 链，否则回退到直连地址。
