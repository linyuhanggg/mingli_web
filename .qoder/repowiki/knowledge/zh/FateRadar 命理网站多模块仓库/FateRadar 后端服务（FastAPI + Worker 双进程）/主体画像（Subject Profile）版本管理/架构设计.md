模块按分层组织：`models.py` 定义 `SubjectProfile`（拥有者可为 User 或 Guest，通过 CheckConstraint 保证二选一）和 `ProfileVersion`（含加密 payload 字段），并通过 SQLAlchemy event 禁止更新以强制不可变；`schemas.py` 使用 Pydantic v2 声明请求/响应模型，对 timezone 调用共享校验器；`repository.py` 封装所有 SQL 访问，使用 `with_for_update()` 行锁 + 重复检查实现并发安全的版本分配，并通过 `EnvelopeCipher` 对 payload 进行加密封装后落库；`service.py` 编排业务用例（创建草稿、确认草稿、列出最新、认领访客所有权），将领域异常映射为自定义错误类型，并在认领时原子迁移 SubjectProfile、ReadingRoot 及 ReadingIdempotencyKey。依赖方向单向：service → repository → models，跨模块仅依赖 `app.security.envelope`、`app.identity.models`、`app.readings.models` 等基础设施。
