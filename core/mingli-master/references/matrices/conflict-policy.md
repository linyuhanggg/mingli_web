# 冲突裁判策略 (conflict-policy)

> 当多个 reference pack 给出不一致结论时的裁判规则。本文件是主 skill `mingli-master` 在输出前的最后一道滤镜。
> 原则：**保留分歧，标注理由，不强行揉合**。

## 0. 顶层原则

1. 古籍命理体系本就多源、多派、多解。差异不是 bug，是常态。
2. 主 skill 的价值不是"消除冲突"，而是"按问题类型给出可复盘的优先级"。
3. 任何冲突裁判都必须在输出中**标注采用方与被搁置方**，不得静默选边。
4. 如果事实层数据不足，所有冲突裁判降级为条件性表述。

## 1. 同体系内冲突

### 1.1 资料层级优先级

| 优先级 | 来源 | 字段 |
|---|---|---|
| 高 | 原典层 | `source_layer: primary` |
| 中 | 注释层 | `source_layer: commentary` |
| 低 | 现代流派层 | `source_layer: modern` |

- 原典 与 注释 冲突 → 默认采用原典；若注释明确指出原典刊误/错简，记入 `conflict_policy` 后采用注释。
- 注释 与 现代 冲突 → 默认采用注释。
- 现代 不得覆盖原典；若用户明确点名某现代流派，则在 `modern_notes` 字段中单独输出，不进入主结论。

### 1.2 同层级内冲突（八字内部最常见）

八字子平的格局 / 旺衰 / 调候 / 神煞四大派常给出不同结论。裁判顺序按**问题类型**：

| 问题类型 | 优先派别 | 理由 |
|---|---|---|
| 命局成败、有无格 | 格局派（子平真诠）| 月令为本，格局成败是宏观骨架 |
| 五行流转、能不能用某干支 | 旺衰派（滴天髓阐微）| 气势生克、通关病药 |
| 春夏秋冬冷暖、用神是否润燥 | 调候派（穷通宝鉴）| 月令气候直接决定调候用神 |
| 流年具体事项、应期 | 神煞辅助 + 大运流年 | 神煞用于事项点缀，不主主线 |
| 子平法源流 / 术语雏形 | 源流派（渊海子平）| 子平法骨架源头 |
| 综合查找 / 多角度补全 | 汇编派（三命通会）| 综合汇编型，不取舍只列举 |

**多派一致** → 直接采用。  
**多派不一致** → 输出"格局派认为 X / 旺衰派认为 Y / 调候派认为 Z"，并按问题类型给主推。

#### Batch 1A 补充：《三命通会》 vs 《渊海子平》 vs 《子平真诠》的裁判细则

| 场景 | 裁判 |
|---|---|
| 月令格局成败（精细）| 优先《子平真诠》原典；《三命通会》作综合查找；《渊海子平》作术语源流 |
| 术语解释有分歧（如"用神"语义）| 优先《子平真诠》（格局派用神） vs 《滴天髓阐微》（旺衰派用神），按问题类型选 |
| 经验断语回查（如"正官一位清贵"）| 优先《渊海子平》（早期经验性）；《三命通会》作汇查；不得当作铁律 |
| 徐乐吾评注与原典冲突 | 以原典为准；徐乐吾评注进入 `[徐评]` 标注，在输出中单独列出 |
| 现代格局派 vs 原典 | 现代不进 primary 层；只能进 commentary / modern 层 |
| 三命通会汇编 vs 子平真诠精修 | 三命通会是"多派列举"，子平真诠是"格局派单一精修"；按问题类型选 |

**核心规则**：

- 《三命通会》 ≠ 最终结论；是查找入口。
- 《渊海子平》 ≠ 最终结论；是源流入口。
- 《子平真诠》只精修格局派；旺衰 / 调候 / 神煞另论。
- 徐乐吾评注永远是 commentary 层；不得与原典混用。

### 1.3 紫微斗数内部

- 三合派（《全书》《全集》）与飞星 / 钦天 / 中州 / 河洛派常有同宫不同断的情况。
- 主 skill 默认只用三合派（原典层）。
- 飞星等现代流派只在用户明确点名时启用，启用后在结论中独立标注"X 派认为 …"，不与三合派结论合并。

### 1.4 六爻内部

- 《火珠林》是源流；实际断卦优先《增删卜易》《卜筮正宗》。
- 若《增删卜易》《卜筮正宗》互相冲突 → 按问题类型选：感情、家宅类倾向《增删卜易》；财、官、出行类倾向《卜筮正宗》。
- 神煞与六亲冲突 → 优先六亲、世应、用神动静。

### 1.5 奇门内部

- 飞盘 / 转盘 / 时家 / 拆补 / 茅山 等流派盘式不同。
- pack 内必须声明流派；**不得在同一次输出中混用两种盘式**。
- 流派由用户指定；用户未指定则默认时家转盘，并在输出中明确说明。

### 1.6 风水内部

- 阳宅 vs 阴宅：术语相同含义不同（如"砂"），**不得混用**。
- 阴宅形峦内部：`zangshu` 是乘生气/葬法源头，`hanlong-jing` / `yilong-jing` 偏寻龙辨穴，`zangfa-daozhang` 偏穴法/倒杖/二十四砂葬法，`rudi-yan-quanshu` 偏龙砂水向综合流程；冲突时先按功能层分流，不把倒杖规则反推成寻龙总纲。
- 阳宅理气：玄空 / 三元 / 三合 / 八宅 / 命理派 各有自己的吉凶判断。同一住宅同一坐向，不同流派可能完全相反。
- 默认策略：用户提供哪派坐向数据就用哪派；都没有 → 优先《黄帝宅经》《阳宅十书》《阳宅三要》（基础宅法 + 阳宅外形/福元游年/门主灶），不给精细理气结论。

## 2. 跨体系冲突（最关键）

按**问题类型**裁判，不是按"哪个体系更准"。

| 问题维度 | 主体系 | 其他体系定位 |
|---|---|---|
| 长期结构、十年大运 | 八字 / 紫微 | 卜筮、奇门给具体节点辅助；不能改长期结构判断 |
| 单一具体事件成败 | 六爻 / 梅花 / 六壬 | 八字、紫微只能给"整体倾向"，不能直接判该事成败 |
| 行动时机 | 择日 + 奇门 | 八字命局可作背景；六爻只在事件层补充 |
| 环境 / 居住 | 风水 | 八字提供"忌讳与喜用方向"的背景；不能让八字直接决定户型 |
| 旁证（外貌、状态）| 相法 | 仅作观察辅助，不改变命盘 / 卜筮主结论 |

### 2.1 跨体系冲突典型案例

| 冲突场景 | 处理 |
|---|---|
| 八字说"此年事业波折"，六爻问"这次跳槽能成"得吉卦 | 输出："长期看波折期；此次跳槽 short-term 可成。两层独立。" |
| 紫微夫妻宫差，六爻问"这段感情能否走下去"得吉 | 输出："紫微看长期匹配差；六爻只看眼前阶段。建议把短期决策与长期结构分开。" |
| 择日吉日，奇门盘不利方位 | 输出："日吉但方位不利；可改方位或改时辰。" |
| 风水阳宅吉，八字命主忌某方位 | 输出："住宅整体吉；卧室/书桌避开命主忌方。" |

## 3. 数据不足时的降级

| 数据缺失 | 影响 | 处理 |
|---|---|---|
| 出生时辰未知 | 八字无时柱、紫微无法定命宫 | 八字给前三柱倾向；紫微改用八字补充，不强排盘 |
| 出生地未知 | 真太阳时无法换算 | 标注误差范围，按出生时辰原值排，但所有结论加"待真太阳时复核" |
| 起卦时间不明 | 六爻 / 梅花 / 六壬 无法起卦 | 停止编造卦课；要求补充 |
| 户型坐向未知 | 风水阳宅无法理气 | 仅给形势 / 大原则建议 |
| 用户拒绝提供照片 | 相法不可用 | 跳过相法旁证 |

## 4. 输出格式约定

每次输出冲突时必须明确分块：

```text
【主结论】（按问题类型选定的体系结论）
【其他体系参考】（其他体系给出的不同观点 + 一句话说明为何不作主结论）
【共识】（如果有跨体系一致点）
【需要补充的事实层】（缺失的输入或工具）
```

## 5. 禁止的裁判方式

- 不得用"古籍说"作权威搪塞；必须落到具体典籍 + 出处。
- 不得把"现代师傅说"作为决定性裁判依据。
- 不得在同一结论中糅合相反的派别（例如同一坐向同时用玄空和八宅给吉凶）。
- 不得用"灵感 / 个人经验"覆盖原典层结论。
- 不得在事实层数据不足时给"铁口直断"。
