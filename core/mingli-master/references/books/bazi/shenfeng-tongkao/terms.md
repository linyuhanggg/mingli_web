# 神峰通考 — Terms

| term | layer | meaning_in_text | skill_use | caveat |
|---|---|---|---|---|
| 动静 | core | 张楠用于区分天干显露、地支藏蓄、岁运触发的理论入口。 | 八字理论解释。 | 需结合原文行号，不可泛化。 |
| 盖头 | core | 以天干如头面显露，地支如藏体，解释干支作用。 | 干支透藏判断。 | 不等同所有现代“盖头截脚”说。 |
| 病药 | core | 八字中所害之神为病，能去病者为药。 | 用神取法、调病去病。 | 不作医学类比输出。 |
| 雕枯旺弱 | core | 四病之一组，用于判断太过不及。 | 旺衰与病药结合。 | 需排盘工具。 |
| 损益生长 | core | 四药之一组，与病相对。 | 解释补救逻辑。 | 不承诺改运。 |
| 正官格 |格局 | 月令官星与财印配合。 | 格局查询。 | 需与《子平真诠》并读。 |
| 正财/偏财 | 格局 | 财为养命之源，身旺能任，身弱难任。 | 财格/从财解释。 | 财富断语必须软化。 |
| 从财/从杀 | 格局 | 弃命从财/杀等特殊格。 | 特殊格路由。 | 需严格条件，不可轻判。 |
| 女命 | risk | 文中多处涉及夫子、克制、寿夭等传统断语。 | 只作古籍观念解释。 | 高风险，必须 reframe。 |
| 古赋歌诀 | source | 五言独步、喜忌篇、万金赋等辑录材料。 | 引文来源索引。 | 需标注不是全为张楠原创。 |
