# 蘭臺妙選 — Rules

> 本文件抽取“文本内规则”，不是现代命理结论。所有规则都需要 `tool.bazi.paipan` 或等价排盘先给出干支、纳音、胎元、神煞、四时旺衰。

## LT-M01 三命事实框架

- rule: 天元、地元、人元谓之三命。
- source_anchor: fulltext.md L18
- applicable_to: 已计算的三元与四柱事实
- caveats: 仅作三元术语与事实组织方法；不授权格局或吉凶判断。
- verified: false

## LT-R01 三命与六旬为底层框架

本书开篇以“三命/六旬”建立论命对象：先看天元、地元、人元及六十甲子，再进入根基、格局、禄马、贵神、凶煞。

Skill 用法：当用户问题涉及“纳音格、古法禄命、三命”时加载本书；现代十神格局不应直接用本书主断。

## LT-R02 根基与格局必须同看

上篇反复将“四时生旺的根基”与“生月取用、三合成局的格局”并列。根基稳不等于格局真，格局高也要看凶煞伏藏、贵神向用。

Skill 用法：输出时说明“本书更重象格成败条件，而不是单一旺衰”。

## LT-R03 凶煞有制可反成光荣

“坐凶煞之交互，却主光荣”表明本书不是简单见凶即凶；七煞、羊刃、伤官等须看是否得制、得地、伏藏、向用。

Skill 用法：遇凶煞类问题，只能说“文本认为有制化条件时可转为可用之象”。

## LT-R04 纳音地支取象形成格名

上篇大量以地支物象与纳音组合命名，如马化龙驹、蛇化青龙、宝剑冲斗牛、灵槎入天河等。每一格都依赖特定干支、纳音、月份、时令、刑冲条件。

Skill 用法：不得只凭格名解释，必须回到 quote-index/chapter-map 查具体条件。

## LT-R05 中篇风险象必须 reframe

中篇集中收录恶煞、疾病、夭折、贫愚、刑伤等断语。它们在 skill 中只能作为“古籍风险分类方式”呈现，不能对现实个人作确定判断。

Skill 用法：输出格式固定为“古文术语 -> 文本含义 -> 现代安全改写 -> 不可断言项”。

## LT-R06 得时/失时改变同一象格的解释

下篇“文星入於河漢，得時者……失時者……”等句说明同一象格要看时令，不能只看组合存在。

Skill 用法：所有格名查询都要求列出“成格条件、破格条件、时令条件、证据短引”。

## LT-R07 与子平体系冲突时分层并列

本书的“格局、贵神、禄马、三元”与子平十神格局并非同一层。若与子平结论冲突，主 skill 应说明这是“纳音禄命旁证”，不覆盖子平主线。
