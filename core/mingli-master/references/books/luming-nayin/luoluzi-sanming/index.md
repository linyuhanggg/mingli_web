# 珞琭子三命消息赋（徐子平注本）

## 简介

《珞琭子三命消息赋》是中国早期禄命学（年月日时三命学）核心赋文之一，
约成书于北宋宣和、建炎年间（约 1119–1130），后世托名"珞琭子"或"陶弘景"，
然据《四库提要》考证应为北宋人所撰。徐子平为其注本作者（北宋·五代之间），
其注解为通行本，《永乐大典》收录后清代由四库馆臣裒辑成上下二卷。

本赋是后世"子平命学"理论之重要源流，宋以降王廷光、李仝、释昙莹、徐子平
四家注本流传，独子平注最为命学界所宗。"今称推八字者为子平"即源于此。

## 核心定位

- **天元—支元—人元** 三元模型：「以干为禄，向背定其贫富；以支为命，详顺逆以循环」
  - 天元（十干，主本气）
  - 支元（十二支，主命位）
  - 人元（支中所藏天干，主吉凶具体配位）
- **生克向背论**：以生日天元为主，看祖财（年月）、自立财（时支）、官印之有无与休旺
- **运程折除法**：「运行则一辰十岁，折除乃三日为年」
- **真五行/纳音**：天元配合纳音以辨剛柔（金剛火強、木盛花繁等）
- **三奇貴神格**：「三奇祿馬則貴命也」、「將星扶德、太乙加臨」
- **刑冲克破系统**：辰戌丑未四煞、勾绞、丧吊、孤辰寡宿、夹煞、伏吟反吟、裸形
