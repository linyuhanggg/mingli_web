# 外部项目架构对照

这份记录只提炼工程启发，不把 GitHub 热度、提示词长度或比赛分数当作
命理有效性的证明，也不复制许可证不明的实现。

## 本轮三个重点项目

| 项目 | 真正有用的部分 | 不能直接照搬的部分 | 本项目采用方式 |
|---|---|---|---|
| [china-testing/bazi](https://github.com/china-testing/bazi) | 把冲合刑害、藏干、十神、五行库存等盘面关系显式计算；数据表与解释分离的雏形 | 仓库没有 LICENSE 文件，也没有完整自动化测试；大量经验断语与计算混在命令行程序中，五行分数不能直接当旺衰真值 | 只作交叉测试与边界案例来源，不复制代码；继续使用本项目的版本固定适配器、JSON 事实层和冲突测试 |
| [jinchenma94/bazi-skill](https://github.com/jinchenma94/bazi-skill) | 信息收集顺序、节气交界、闰月、夜子时、时辰未知等输入边界写得清楚 | 本质是提示词与摘要参考，没有确定性排盘程序、证据哈希、规则适用性裁判或实证基准；姓名/曾用名等也不是每次排盘的必要输入 | 吸收输入依赖表与边界情形，但只追问会改变下一次计算的一个字段；所有历法仍交给适配器 |
| [Tianfu Agent / MingLi-Bench](https://destinylinker.github.io/MingLi-Bench/) | 确定性工具优先、规则也封装成按需工具、工具可见性分级、逐层不确定性；公开了选择题基准与局限 | Tianfu 的实现没有完整开源；其 50% 是 2025 年 40 题的截尾准确率，开放式咨询、追问和语言质量不在该指标内 | 实装问题契约、按域规则工具、置信上限、能力分级、答案隔离和冻结评分；生产链与基准链保持同构 |

## 其他直接基准

- [MingLi-Bench](https://github.com/DestinyLinker/MingLi-Bench) 把预计算盘面与
  模型回答分开，适合检查“会不会在正确盘上推理”，不证明现实预测效度。
- [BaziQA](https://github.com/ChenJiangxi/BaziQA) 提供 2021-2025 年 200 道
  封闭选择题，适合答案隔离、时间组合和领域错题诊断。
- [iztro](https://github.com/SylarLong/iztro) 是当前紫微事实适配器的固定版本
  来源；可靠排盘事实不等于已经具备可靠方向性紫微解释器。

## 已落地的架构结论

1. **事实先于叙事**：历法、四柱、大运、四课三传等必须由可验证程序产生。
2. **规则是有适用条件的工具**：按体系、问题域、时间层和章节条件加载，
   不把整本摘要塞进提示词。
3. **古籍不是投票箱**：同一源流的多本书只算相关证据；机器映射见
   `references/inference/source-lineages-v1.json`。
4. **能力按路由硬分级**：语料齐全不代表能算。八字和大六壬具备 Tier A
   事实/推理管线，但具体事件的实证准确度尚未建立；紫微仍是中性 Tier B。
5. **不确定性不能由模型任填**：结论置信度不得超过直接规则工具的上限；
   高置信还需独立机制组与独立源流；精确年份、金额、地点及封闭候选事件
   还受问题精度上限约束。
6. **评测与上线同构**：验证时不能偷偷加入生产不允许使用的紫微方向票、
   网络答案或事后结果。

## 当前基准边界

旧 v11 开发集单轮为 `31/77 = 40.26%`，但曾向模型展示中性紫微上下文，
只保留为开发诊断。最终 evaluation split 共 65 题，10 题因夜子规则或时区
缺失被事实层阻断；其余 55 题 forced-choice 为 `16/55 = 29.09%`。相对
四选一随机基线的单侧二项检验 `p = 0.286798`，Wilson 95% 区间为
`18.77% - 42.14%`，不能证明优于随机。allow-abstain 仅回答 4 题，答对
1 题，覆盖率 `7.27%`，也没有筛出可用的高准确子集。

开发冒烟还显示同一模型在同一 22 题上可从 `7/22` 波动到 `11/22`，因此
禁止挑最好一次作为成绩。封闭题的选项/理由先冻结，置信度再由运行器按
问题精度上限赋值，避免“知道自己只能低置信”反向改变选项排序。两套最终
预测在揭晓任一答案前生成。此前 validation split 因检查上游数据时泄露
11 道答案而整组退役，不计分、不调参。完整记录见
`references/regression/v16-architecture-validation.md`。
