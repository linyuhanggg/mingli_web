# 大六壬全流程逐屏规格

流程是同一路由 `/daliuren` 上的状态机（DESIGN §7）：

```text
S0 入口态 → S1 问题与时空录入 → S2 提交确认 → S3 课盘态（免费） → S4 深读选择/支付 → S5 报告态
                                                └→ S6 异常态族（贯穿全程）
```

每屏给出：目的 / 布局（360·768·1024·1440）/ **显示内容合同**（字段路径、呈现规则、缺失时行为）/ 交互 / 验收点。字段路径全部对齐 `DaliurenChartViewModel`（`daliuren-chart/v1`）；缺口标 `GAP-DL-xx`，汇总在文末。

**通用红线**：同前四份样板（无 raw JSON；空块不渲染不占位；零断语——`candidate_not_guarantee` 恒真、维度证据 `hard_verdict` 恒 null；引文透传；页面不横滚；四视口 + 键盘 + reduced-motion）。

**六壬特有布局裁决（本单派单明确）**：**四课三传是扫读主锚点，布局优先级高于天地盘全图**。传统排盘把天地盘画大，但用户判读动作发生在课与传上；天地盘是「查证层」不是「第一眼」。所有视口下课传区先于天地盘出现。

## S0 入口态（pristine）

**布局**：同六爻 S0（术标行通栏 → 1440/1024 双栏、768 剪影横条、360 隐藏剪影）。

**显示内容合同**：

| 区块 | 显示什么 | 来源 | 规则 |
|---|---|---|---|
| 术标行 | 印章「六壬」+「大六壬」+ 适用说明（如「以起课时刻立四课三传，逐课核验」）| 静态文案 | H1 为术名；≤20 字 |
| 空盘剪影 | `DaliurenBoard` silhouette：四课空列 + 三传空阶梯（主体）+ 缩小的天地盘空环（次要，360/768 剪影省略环） | 静态结构 | 剪影本身就体现「课传优先」的层级；无示例干支/天将 |
| 能力边界行 | 免费确定性课盘 + 已核验规则证据（类象/主客/应期候选）；深读按 Offer 状态 | 能力接口 | 不用工程词 |

## S1 问题与时空录入

**字段清单**（现有 `product-input-form` 字段保留，标签不变）：

| 字段 | 必填 | 控件与规则 |
|---|---|---|
| 当前问题 | 是 | 文本；帮助「一事一课」 |
| 判断侧重 | 是 | select：事情进展 / 人事关系 / 结果观察 / 应期观察（现有 `focus` 四值不变）；帮助「侧重决定盘面额外给出哪类已核验证据」——这是六壬版的「问题类别」，且**已经接线**（对照六爻 GAP-LY-01 尚未接线） |
| 应期观察窗口 | 侧重=应期时必填 | 开始/结束日期（现有 `timingStart/timingEnd`），范围 ≤31 天；帮助文案沿用现有「用于激活大六壬已核验的候选日期规则」「候选日期不是现实保证」 |
| 事件时间 | 是 | 年/月/日 + 时/分 + 时区 + 地点 + 事件时间口径（现有控件）；帮助「以实际起课时刻为准，决定月将加时与昼夜贵人」 |

**交互**：侧重切到「应期观察」时窗口字段就地展开（120ms，reduced-motion 关闭）；窗口跨度超 31 天就近报错。

**验收点**：四种侧重切换正确显隐窗口字段；键盘完整可用；360 无横滚。

## S3 课盘态（免费确定性课盘）——本流程的主屏

**目的**：四课三传 3 秒可扫读；天地盘作可展开的查证层；三条已核验规则证据（类象 LM-R01 / 主客 LR-17 / 应期候选 LM-R21）按侧重上屏，零断语。

**布局（课传优先，钉死）**：

- **1440**：工作条通栏 → 起课口径条通栏 → 双栏：**左盘面区 480–520px = 四课列（上）+ 三传阶梯（下）**，右阅读区（维度证据、应期候选表、课式传法、免费摘要）。**天地盘环放左栏课传之下**，默认收起为一行入口「展开天地盘」，展开后 420–460px 直径的环图。两栏独立滚动。
- **1024**：同构，环展开时直径 380px。
- **768**：单列：工作条 → 口径条 → 四课列 → 三传阶梯 → 粘性章节导航 → 模块流；天地盘默认收起，展开后转为**十二行三列表格**（环几何在窄视口放弃，同紫微 360 思路）。
- **360**：同 768；四课从横排四列转为 2×2（一二课上行、三四课下行，行内保持右一左四的传统序注记）；天地盘只提供表格形态。
- 章节锚点：`四课三传 / 天地盘 / 课式 / 证据 / 应期 / 深读`（无数据的锚点不渲染）。

### 工作条

同六爻工作条（返回 / 问题摘要 `question` 截断 / 更多）。无时间层 chips。

### M1 起课口径条（G3）

| 显示什么 | 字段 | 规则 |
|---|---|---|
| 问题全文 | `question` | 原样，超长折叠 |
| 日干支与时辰 | `core_facts.day_hour`（松散，GAP-DL-01 钉形） | 「丙午日 卯时起课」 |
| 月将 | `core_facts.month_general`（松散） | 「月将：亥（登明）」 |
| 贵人 | `core_facts.noble_person`（松散） | 「昼贵人：… 」含昼夜依据 |
| 旬空 | `core_facts.xunkong`（松散） | 「旬空：辰巳」，同时在课/传/盘对应支位加「空」角标 |

`core_facts` 为 null 时本条只显示 `question`；松散项各自缺失不占位。

### M2 四课列（盘面主体上半，必有字段）

`lessons[]`（恰好 4 项，`lesson_id/upper/lower`）：

- 四列排布，**传统右→左序**（一课在最右），每列头部小字标 `lesson_id`（服务端给的课名，如「一课·日干」——以真实值为准，前端不造课名）；360 转 2×2 仍保留序号注记。
- 每列两格：上神 `upper`（18px 域字）在上、下神 `lower`（16px）在下，中间细墨线。
- 上下神地支按五行固定字典染 `--element-*`（染色字典边界同八字）。
- 被 `xunkong` 命中的支加「空」角标（钉形后启用）。

### M3 三传阶梯（盘面主体下半，必有字段）

`transmissions[]`（恰好 3 项，`stage/branch/general`）：

- 三行阶梯：初传顶行左起、中传缩进一档、末传再缩进——阶梯方向体现传递次序，`stage` 枚举映射行头「初传/中传/末传」。
- 每行 = 行头 + 地支 `branch`（20px 域字，五行染色）+ 天将 `general`（14px 中性 chip，如「白虎」——不做吉凶染色）。
- 遁干位预留在支左侧（VM 未暴露，GAP-DL-03；缺失不占位）。
- 应期候选命中的传行（`timing_candidates[].anchor_earth_branch` 对应）挂金线徽章，点击滚动到 M6 应期表。

**课传联动**（§21.1/§21.4）：点击/聚焦任一课的上下神或任一传行 → 天地盘（若展开）对应支位、维度证据、应期表相关条目同步高亮；方向键在四课八格 + 三传三行间移动。语义替代：课传同步输出语义表格。

### M4 天地盘（查证层，默认收起）

- **环形态（1024+）**：外环 = 地盘十二支（`core_facts.earth_plate[]`，12 字符串，固定顺时针），中环 = 天盘（`heaven_plate[]`，松散对象含落支，GAP-DL-01），内环 = 十二天将（`heavenly_generals[]`，松散）。`plate_offset` 用于环图旋转对位（整数，已类型化）。贵人位金线小标。
- **表格形态（768/360，及环形态的语义替代）**：十二行 × 三列（地盘支 / 天盘支 / 天将），行头地支。
- 展开/收起状态记忆在会话内；展开不推走课传区（在其下方展开）。
- `earth_plate` 为 null 时整个 M4 入口不渲染。

### M5 课式与传法

| 显示什么 | 字段 | 规则 |
|---|---|---|
| 课式（发用方法） | `core_facts.lesson_method`（松散，GAP-DL-01） | 「贼克课·下贼上发用」类事实句 |
| 传法 | `core_facts.transmission_method`（松散） | 同上 |
| 课体格局 | `core_facts.structural_patterns[]`（字符串数组） | 中性 chip 列（如「元首课」）；**无出处锚点，点不开引文**——升级为带锚点对象见 GAP-DL-02；在锚点补齐前 chip 不带金线徽章（金线=可核验，不能虚挂） |

### M6 维度证据与应期候选（A 档核心模块，右栏首位）

**M6a 维度证据**（`core_facts.dimension_facts`，松散——2026-08-17 已实证产出三类，形状钉形进 GAP-DL-01）：

- 按侧重分组渲染已 matched 的规则证据：类象对应（LM-R01·大六壬秘本）、主客关系（LR-17·六壬指南，support/oppose 分向列出**不合并成结论**）、应期（LM-R21，与 M6b 呼应）。
- 每条 = 事实句 + 规则号 + `EvidenceBadge` → `EvidenceDrawer`（复用八字 M12 抽屉组件）显示来源锚点。
- 用户所选侧重无 matched 证据时该组整组不渲染（不显示「暂无证据」占位）；`hard_verdict` 恒 null，任何条目不得出现成败措辞。

**M6b 应期候选表**（`core_facts.timing_candidates[]`，**全类型化**，六壬 A 档主打）：

| 列 | 字段 | 呈现 |
|---|---|---|
| 候选日期 | `solar_date` + `day_ganzhi` | 「2026-09-02 · 庚申日」tabular 数字 |
| 候选支 | `branch`（锚点 `anchor_earth_branch` 进悬停详情） | 域字 + 点击联动三传/天地盘 |
| 距起课 | `days_after_cast` | 「第 N 天」 |
| 出处 | `source_pack` + `source_rule`（LM-R21） | `EvidenceBadge` → 抽屉 |

表头下固定边界句（对应 `candidate_not_guarantee: true`）：「以下为古籍规则产生的候选日期，不是保证的应期」。`timing_candidates` 为 null 且用户侧重≠应期 → 整表不渲染；侧重=应期但为 null → 一行事实说明「本课未产生候选日期」（这是运行时真实结果，非占位）。

### M7 免费基础摘要 + 深读入口

同八字 M11/M13：摘要只复述已上屏事实（四课、三传支与天将、课体名——如有），不新增判断。

**S3 状态清单**：loading（四课列 + 三传阶梯骨架）/ ready / partial（`core_facts=null`：四课 + 三传完整可读——两者都是必有强类型字段，六壬的 partial 态和梅花一样体面；M1/M4–M6 不渲染）/ error / unavailable。

**验收点**：所有视口课传先于天地盘出现；天地盘收起态不占空间、展开有表格替代；四课右→左序有课名注记；应期表边界句常驻、无成败措辞；键盘可遍历课格与传行；页面无横滚。

## S4 深读选择与支付 / S5 报告态 / S6 异常态族

与八字 S4/S5/S6 同构（bazi-flow-spec 为准），差异：

- S4 SKU 样例引用来自课传与维度证据；不得出现吉凶承诺。
- S5 报告 Claim Unit 锚点指向课/传/证据行，点击回跳 S3 高亮；深读文本供给缺口并入 GAP-BZ-02 同族跟踪（六壬深读明确未完成，见 2026-08-17 证据「完整大六壬成败、吉凶、学校裁判、三术合断和深读仍未完成」——S4/S5 上线以 Offer 能力接口为准，深读不可用时入口按 locked/unavailable 文案基线处理，不做「即将上线」空承诺）。
- S6 增加六壬特有异常：**应期窗口非法**（跨度>31 天/起止倒置）——本机就近拦截；服务端拒绝时错误文案指回窗口字段。

## ALGO-GAP 清单

### GAP-DL-01 · core_facts 松散对象钉形（P1，阻塞口径条/天地盘/维度证据对位）

- 缺什么：`day_hour`、`heaven_plate[]`、`heavenly_generals[]`、`lesson_method`、`month_general`、`noble_person`、`transmission_method`、`dimension_facts`、`xunkong` 全部是无键约束松散对象。数据已真实产出（V53 liuren Runtime 证据 2026-08-16/17），但天地盘三环对位、维度证据分组渲染没有稳定键。
- 期望的数据形状（示例）：`heaven_plate[i] = { earth_branch, heaven_branch }`；`heavenly_generals[i] = { earth_branch, general }`；`month_general = { branch, name }`；`noble_person = { day_night, branch }`；`dimension_facts = { [dimension]: Array<{ rule_id, source_pack, source_anchor, fact_text, direction? }> }`。以 Runtime 实际输出钉形，同 GAP-LY-03 模式。
- 影响：不补则 M1/M4/M5/M6a 只能通用键值渲染，六壬盘退化为定义列表。

### GAP-DL-02 · 课体格局无出处锚点（P2）

- 缺什么：`structural_patterns` 是裸字符串数组，课体名（元首/重审等）点不开古籍出处，与「金线=可核验」的证据语言冲突。
- 期望：升级为带 `source_pack/source_anchor/rule_id` 的对象数组（对照六爻 `sourcePattern` 结构），或另供 `source_conditioned_patterns` 同构字段。

### GAP-DL-03 · 三传遁干未暴露（P3）

- 缺什么：传统课盘三传标配遁干（旬内天干），为确定性事实，VM 无字段。
- 期望：`transmissions[]` 增加 `hidden_stem`；低优，不阻塞主盘。

### 术语释义词表（并入 GAP-BZ-03，不另开编号）

六壬词条：月将、贵人（昼夜）、四课、三传（初中末）、十二天将、课体名、发用、旬空、应期候选。

## 实现顺序建议

1. **先行（必有字段即成盘）**：四课列 + 三传阶梯（`lessons/transmissions` 强类型必有，partial 态即完整可读）+ M6b 应期候选表（`timing_candidates` 全类型化、输入侧重已接线——六壬是五术中唯一「问题侧重→证据模块」链路已全通的，应作为该交互模式的样板落地）。
2. 随 GAP-DL-01 钉形跟进：M1 口径条 + M4 天地盘 + M5 课式 + M6a 维度证据。
3. M5 课体金线徽章等 GAP-DL-02。
