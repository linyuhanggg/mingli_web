# 三命通会 — Terms

> 字段：`term` / `definition` / `source_chapter` / `cross_system` / `verification_status`。
> `verification_status`：`verified` / `pending_verification` / `unverified`（CTP 文本未对四库本影印复核者一律 `pending_verification`）。
> 跨体系同名词（如"正印"在卷三神煞与卷六十神都出现）须显式标 `cross_system`。
