# 撼龙经 — Rules

> 九星龙脉核心规则；所有 verified 为 false。涉吉凶规则均加 caveats 现代使用边界。

## R-01: 高山平地寻龙之别

- **source_chapter**: zonglun
- **rule**: 高山须认星峰起、平地龙行别有名；峰以星名取其类，星辰下照山成形。"高水一寸即是山、低水一寸即是平洋。"
- **applicable_to**: 形势派寻龙总纲
- **caveats**: 现代使用边界：仅作文化研究参考。
- **verified**: false

## R-02: 九星三吉与二大凶

- **source_chapter**: beichen
- **rule**: 九星中贪狼、巨门、武曲为三吉，左辅右弼为辅佐；禄存、廉贞、破军、文曲多关煞或祖星，须与三吉合方为贵。
- **applicable_to**: 龙脉吉凶分类总判
- **caveats**: 现代使用边界：仅作文化研究参考。
- **verified**: false

## R-03: 贪狼正形五种

- **source_chapter**: tanlang
- **rule**: 贪狼正形五：尖（笋顶）、圆（四面同）、平（卧蚕高顶）、直（决脊引绳）、小（笔头插塔）；其余欹、斜、侧、巖、倒、破、空七者非正。
- **applicable_to**: 贪狼星形辨认
- **caveats**: 现代使用边界：仅作文化研究参考。
- **verified**: false

## R-04: 廉贞为祖

- **source_chapter**: lianzhen
- **rule**: 火星廉贞高顶生宝殿，分宗派祖；贪巨武曲皆从廉贞出。"贪狼若非廉作祖，为官也不到三公"。
- **applicable_to**: 龙脉源头判断
- **caveats**: 现代使用边界：仅作文化研究参考。
- **verified**: false

## R-05: 巨门多关峡少而护卫多

- **source_chapter**: jumen
- **rule**: 巨门行龙少鬼劫；两傍多罗列，水界分处夹龙行；其少关峡、护送无容左右离。
- **applicable_to**: 巨门龙脉辨认
- **caveats**: 现代使用边界：仅作文化研究参考。

## R-06: 禄存九形辨

- **source_chapter**: lucun
- **rule**: 禄存九形：顿鼓、覆釜、鹤爪、肋扇、悬鹑、平洋、长蛇、兠鍪、落花；各形主作不同（神坛、关锁、罗星等）。
- **applicable_to**: 禄存星形分类
- **caveats**: 现代使用边界：仅作文化研究参考。

## R-07: 文曲淫邪辨

- **source_chapter**: wenqu
- **rule**: 文曲蛇行、撒网为淫邪；若无星峰为辅则散漫不结；男主酒色、女主内乱（古文措辞）。
- **applicable_to**: 文曲凶煞辨别
- **caveats**: 现代使用边界：古文评价语，不作现代决定论陈述；仅作文化研究参考。
- **verified**: false

## R-08: 武曲与左辅之辨

- **source_chapter**: wuqu
- **rule**: 武曲覆钟、左辅覆釜；钟高釜矮，二者形似而辨。武曲端严富贵；辅弼随龙厚薄取。
- **applicable_to**: 武曲与左辅辨别
- **caveats**: 现代使用边界：仅作文化研究参考。

- **applicable_to**: 破军作用辨认
