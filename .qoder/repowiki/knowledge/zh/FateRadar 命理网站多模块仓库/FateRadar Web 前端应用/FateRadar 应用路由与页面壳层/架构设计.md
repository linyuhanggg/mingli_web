模块以 Next.js App Router 的目录即路由约定组织：根 `layout.tsx` 提供全局 `<html lang="zh-CN">`、Noto Sans/-serif SC 字体与站点级 Metadata（title template、viewport、manifest），并引入 `globals.css`；根 `page.tsx` 作为营销首页，通过 `PublicPageShell` 包裹，使用 `@/components/home-motion` 中的动画组件渲染 hero、任务入口、方法论与定价卡片。

受保护区域通过子目录 layout 实现：`app/app/layout.tsx` 与 `app/account/layout.tsx` 均导出 `PrivateShell` 包裹的布局，并声明 `dynamic = "force-dynamic"`、`revalidate = 0`、`fetchCache = "force-no-store"` 以及 `robots: { index: false, follow: false, nocache: true }`，使 `/app/*` 与 `/account/*` 走动态渲染且不被搜索引擎收录。

`app/app/` 下按业务域划分功能路由：`ask/liuyao`（一事一问六爻）、`bazi`（八字概览）、`fortune/today` 与 `fortune/week`（今日/近七日运势）、`profile/new`（新建档案）、`profiles`（档案列表）、`readings/[readingId]`（带参数的解读详情）；该子树还集中定义了 Next.js 错误边界 `error.tsx`、加载态 `loading.tsx` 与 `not-found.tsx`，统一复用 `StatusPanel` 组件呈现 loading/error/empty 状态。

公开静态页 `methodology`、`pricing`、`privacy`、`support`、`terms` 各自独立 page 文件；PWA 能力由 `manifest.ts` 暴露，`robots.ts` 显式禁止爬虫进入 `/app/`、`/account`、`/api/`。依赖方向单向向下：页面仅消费 `@/components/*` 与 `@/lib/product-capabilities` 等上层模块，不反向引用业务逻辑。
