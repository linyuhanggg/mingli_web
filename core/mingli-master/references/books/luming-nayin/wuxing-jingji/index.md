# 五行精纪（南宋·廖中辑）

## 简介

《五行精紀》三十四卷，南宋廖中辑录，南宋绍定元年（1228）岳珂作序。
本书是宋代禄命学集大成之百科式辑录，搜罗北宋至南宋初期百家命书赋诀，
按"六十甲子→乾神→支神→五行→年月日时胎→吉贵神→凶煞→贵局→
男女命→子息→形貌→疾病→大运二运"分门别类编纂。

岳珂序云："廖君儒也，刊芜翦谬，欲託以傳。" 文忠周公（欧阳修）亦曾序之。
本书为后世明代《三命通会》直接祖本，宋元命学百家赋诀绝大多数借此书得以保存。
李虚中、徐子平、珞琭子等早期赋文片段均见录于此。

## 核心定位

- **34 卷分类百科**：自六十甲子纳音始，终于歲運，覆盖早期命学全部门类
- **乾神系统**：第三/四/五卷专论甲乙/丙丁/戊己/庚辛/壬癸十干各论
- **吉神/凶煞分立**：第十三–二十二卷论吉贵神（天乙、禄、马、印、食、三奇、合、进神、华盖、金舆、学堂、贵局），第廿三–二十七卷论凶神（劫煞、亡神、三刑、六害、空亡、冲破、金煞、凶煞）
- **男女命分论**：第廿九卷分释男命/女命例及父母位
- **专题分论**：第三十卷子息/僧道/九流/吏卒/形貌；第三十一卷疾病壽夭
- **运程系统**：第三十三/三十四卷大运/小运/二运/太岁/歲運

## 文本结构

原书繁体中文，正文层之外多有"○"分段标记的小注。本蒸馏：
- **卷为单元**：每卷一章节，分论小节（如"論甲乙""論丙丁"）合并入对应主卷
- **总览为主**：考虑到 34 卷 8591 行的体量，本批 D1 仅做卷级覆盖与典型术语/规则抽取
- **D2 待补**：每卷内部具体赋诀的细粒度抽取留待 D2 batch
