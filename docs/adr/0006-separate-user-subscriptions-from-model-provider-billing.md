# 用户订阅与模型厂商账务完全分离

用户购买的是本产品定义的数字服务权益，不购买模型、Token 或 API Key。P0 保留两种单次深度解读；达到平台准入门槛并验证留存后，P1 才可新增独立的连续陪伴订阅。每次续费成功建立不可变 Subscription Cycle，并通过现有 Entitlement Ledger 授予当期权益。

模型 API 的按量账单或自托管云资源续费属于经营成本，由企业云账户自动充值、自动续费和预算告警保障。模型厂商欠费、限流或故障不得改变用户订阅状态，也不得核销未完成的用户权益。

## Consequences

订阅签约、周期扣款、权益和报告交付分别建模；签约成功不等于当期已付款，退订不提前收回本期权益。跨端只能存在一个有效合同，重复续费通知必须幂等。模型凭据只在服务端，历史 Accepted 报告不依赖模型在线即可查看。
