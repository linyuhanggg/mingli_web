# 青囊经 — Rules

> 理气派核心规则；所有 verified 为 false。涉阴阳吉凶规则均加 caveats 现代使用边界。

## R-01: 河图四象生八卦

- **source_chapter**: shang-huashi
- **rule**: 河图止有四象，每方二数析之成八；卦由四象生、爻由三交生；乾坤二卦为母六卦为子。
- **applicable_to**: 理气派象数推演基础
- **caveats**: 现代使用边界：仅作传统象数学习参考；不构成任何现实预测。
- **verified**: false

## R-02: 先后天八卦体系

- **source_chapter**: shang-huashi
- **rule**: 先天卦以阴阳对待言（天地定位、山泽通气、雷风相薄、水火不相射）；后天卦以阴阳流行言（震巽离坤兑乾坎艮）；二者源出一时但用不同。
- **applicable_to**: 理气派卦理基础
- **caveats**: 现代使用边界：仅作文化研究参考。
- **verified**: false

## R-03: 中五立极九宫定位

- **source_chapter**: shang-huashi
- **rule**: 中五立极、临制四方；戴九履一、左三右七、二四为肩、六八为足，统中五而为九。
- **applicable_to**: 玄空九宫飞星基础
- **caveats**: 现代使用边界：仅作传统象数研究参考；具体飞星推演必须使用 tool.fengshui.luopan，严禁手算。
- **verified**: false

## R-04: 阳本于阴，阴育于阳

- **source_chapter**: shang-huashi
- **rule**: 阳之妙不在阳而在阴，陰中之陽乃真陽；故"陽以相陰，陰以含陽"；天地之道阳常本阴而阴常育阳。
- **applicable_to**: 理气派阴阳观哲学基础
- **caveats**: 现代使用边界：哲学陈述，不作现代物理或生物学解释。
- **verified**: false

## R-05: 因形察气立人纪

- **source_chapter**: zhong-huaji
- **rule**: 天分星宿地列山川，气行于地形丽于天；故应"因形察气"以立人纪。
- **applicable_to**: 理气派形气推演通则
- **caveats**: 现代使用边界：仅作文化研究参考；不构成天人感应的现代科学陈述。
- **verified**: false

## R-06: 阴阳相见福祿永贞

- **source_chapter**: zhong-huaji
- **rule**: 山水朝应、阴阳相见，得冲和之正则福禄永贞；失冲和之正则相乘而禍咎踵门。
- **applicable_to**: 理气派山水朝应判断
- **caveats**: 现代使用边界：仅作文化研究与古典美学参考；"祸咎"等表述为古文措辞，不作现代决定论陈述。
- **verified**: false

## R-07: 形止气蓄、万物化生

- **source_chapter**: zhong-huaji
- **rule**: 天之所临、地之所感，形止气蓄而万物化生；气感而应、鬼福及人。
- **applicable_to**: 理气派与形势派共通命题
- **caveats**: 现代使用边界：仅作文化研究参考；"鬼福及人"为古代修辞，不作现代陈述。
- **verified**: false

## R-08: 乘风则散、界水则止

- **source_chapter**: xia-huacheng
- **rule**: 外气行形而内气止生；气乘风则散、界水则止；故审气重乘界二字。
- **applicable_to**: 理气派审气总纲（与形势派共通）
- **caveats**: 现代使用边界：仅作传统选址美学参考。
