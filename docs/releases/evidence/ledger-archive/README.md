- 本目录是**历史证据**，不是权威。范围、状态、门禁、当前断点和下一步一律以 `docs/CHECKLIST.md` 为准。
- 归档不改变任何任务状态。`VERIFIED`、`BROWSER_VERIFIED`、`USER_ACCEPTED` 的判定仍只由 §11 与 §1.3 决定。
- 归档条目中的历史结论可能已被后续工作推翻；`docs/CHECKLIST.md` §0 规则 4「不伪造历史」在此继续适用，
  纠错请新增 dated addendum，不要覆盖本目录原文。
