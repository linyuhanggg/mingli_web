- 每个业务域文件自包含一个 `APIRouter(prefix=..., tags=[...])`，并在模块级导出 `router`，由 `router.py` 统一注册到 `/api/v1`。
- 端点函数通过 `Depends(database_session)` 获取异步数据库会话，并在写入路径末尾显式调用 `await session.commit()`。
- 敏感或用户私有响应统一调用 `mark_private(response)` 设置 `cache-control: private, no-store` 与 `x-robots-tag: noindex, nofollow, noarchive`。
- 业务异常在路由层被捕获并转换为 `ApiProblem(status=..., title=...)`，使所有错误以统一的 Problem JSON 格式返回。
- 需要鉴权的端点通过组合 `require_owner`/`require_owner_csrf`/`require_device_csrf` 等依赖完成身份与 CSRF 校验，而非在 handler 内重复实现。
- 写操作端点在执行业务逻辑前先调用 `check_rate_limiter(limiter=..., key=..., title=...)` 进行 per-owner 限流，超限抛出 429 并携带 `Retry-After`。
