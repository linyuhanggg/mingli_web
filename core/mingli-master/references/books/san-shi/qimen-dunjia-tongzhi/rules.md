# 奇门遁甲统宗大全 — Rules

## Distillation Rules

1. 保留版本标记：本 pack 是 Taiyi 网页转写底本 + CTP/NLC 锚点，不得称为“影印逐页校勘定本”。
2. 保留条件结构：格局名、三奇六仪、八门、值符值使、神煞避忌必须和宫位、时令、主客、动静、用事类别一起蒸馏。
3. 凡例优先：遇到具体断法冲突时，先读凡例中关于取舍、动静、选择配合和衰旺休囚的原则。
4. 卷四至九合并处理：Taiyi 将卷四至九并入“奇门演义”，后续 skill 只能按合并章节引用，不能伪造独立卷四、卷五等完整页码证据。
5. 与择日联动：凡涉及造葬、迁居、出行、兵事避忌等择时问题，调用择日 corpus 互证。
6. 与排盘工具联动：凡涉及起局、置闰、超接、符使定位等计算，必须转交排盘/算法模块或人工核验，不从自然语言直接硬算。
7. 安全边界：不得给出医疗、法律、投资、灾祸、婚育等重大现实决策的确定性结论。
