- HTTP 契约统一使用 OpenAPI 3.1.0，并在 `components/securitySchemes` 中以 `apiKey in cookie` 形式声明会话 Cookie（如 `mingli_session`、`mingli_admin_session`）。
- 所有请求/响应 schema 均显式设置 `additionalProperties: false` 并列出 `required` 字段，禁止隐式扩展属性。
- 枚举值通过 JSON Schema 的 `enum` 或 OpenAPI 的 `enum` 严格限定（如身份渠道 phone/email、阅读状态 input_ready/waiting_input/...、StaffRole support/finance/ops/superadmin）。
- 跨版本可移植载荷采用 `oneOf` 联合类型并以 `kind` 常量字段区分状态（命令用 describe/prepare/complete，结果用 described/prepared/accepted/stopped）。
- 共享的子结构抽取到 `schemas/` 下的独立 JSON Schema 文件，并通过 `$id` 提供稳定 URI（如 `https://fateradar.cn/contracts/...`），再由 OpenAPI 通过相对 `$ref` 引用其 `$defs`。
- 安全相关参数（CSRF、幂等键）集中在 `components/parameters` 中统一定义，各 endpoint 通过 `$ref` 复用而非重复声明。
