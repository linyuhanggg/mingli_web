# 穷通宝鉴 — Procedures

> 本书核心是"调候取用流程"。流程编号 `QP-NN`。
> 所有流程严格依赖 `tool.bazi.paipan`：四柱与节气换月必须先由工具给出。
> 不允许手算节气、手算月令；任何手工作业都视为不可信。

---

## QP-01 调候取用主流程（标准入口）

**目的**：在确定盘已由 `tool.bazi.paipan` 取得四柱后，按本书"十干 × 月令"逐查调候用神组合。

**前置条件**：

1. 已有四柱（年月日时干支）。
2. 已确定**节气分界**下的真实月令（不以朔望、不以历法月份）。
3. 已知日干（十干之一）。

**步骤**：

1. **取日干 D**：从盘中读出日柱天干。
2. **取月支 M**：从盘中读出月柱地支。
3. **判季节 S**：M ∈ {寅卯辰} → 春；{巳午未} → 夏；{申酉戌} → 秋；{亥子丑} → 冬。
4. **查 chapter-map**：在 `chapter-map.md` 中按 `D + 三S` 锁定章节子目（如 `bing-huo/sanxia`）。
5. **查 rules.md**：根据章节锁到 `QR-NN-MM`（如 QR-02-02）。
6. **取调候用神**：按规则 `statement` 中的"用 X 为先 / 佐 Y / 忌 Z" 列出**典型用神组合**。
7. **核盘中实情**：盘中是否真的透出该用神？
   - 透出且无伤 → 标记"调候配齐"。
   - 透出但被克合 → 标记"调候有损，须辨救应"。
   - 不透出但藏支 → 标记"虚用，取其同类"。
   - 完全不透 → 标记"调候缺失，本盘调候层薄弱"。
8. **输出**：调候用神组合 + 配齐/有损/虚用/缺失 标记。
9. **不在本流程内做的事**：判富贵、断吉凶、断疾病、断子嗣 — 这些必须合参旺衰（`ditiansui-chanwei`）和格局（`ziping-zhenquan`），并由综合裁判流程给出。

**caveats**：

- 节气分界一律以工具为准，禁止手算。
- "典型用神组合"是教学语义，不是强制配方；盘无对应天干时不可强配。
- 调候不能单独决定命格高低；必须与旺衰、格局合参。

## QP-02 调候用神 vs 旺衰用神冲突裁判

**目的**：当本书取出的"调候用神"与《滴天髓阐微》的"旺衰用神"冲突时，按下列优先级裁判。

**步骤**：

1. **判寒暖燥湿是否极端**：盘中四柱、季节、地支藏干合参，判断日主所处环境的寒暖燥湿是否进入"极端区间"。
   - 极端示例：冬令水多、夏令火炎、燥土无水、湿木无火。
2. **极端者优先调候**：若环境极端，本书规则优先；旺衰让位。
3. **非极端者优先旺衰**：若环境不极端，《滴天髓阐微》旺衰用神优先；本书"调候组合"作辅。
4. **同时存在格局问题** → 进入 `ziping-zhenquan/QP-XX 月令格局成败流程`，三派结论汇总后裁判。

**caveats**：

- "极端"判定本身具有主观性，建议在实际系统中由 `matrices/routing-matrix.md` 提供更细颗粒度的阈值。
- 三派分歧不可强行合一；冲突裁判属于"最终判断层"。

## QP-03 月令调候 + 节气换月对齐

**目的**：保证"三春／三夏／三秋／三冬"的章节锁定不出错。

**步骤**：

1. 取盘的出生时间 → 调用 `tool.bazi.paipan` → 获得月令地支 M。
2. **不要**用阳历或农历月份直接映射到月令；必须由工具按节气分界。
3. 工具返回值落在哪个节气区间内，即取该节气所在月支：
   - 立春～惊蛰 → 寅；惊蛰～清明 → 卯；以此类推。
4. 月支锁定后再走 QP-01 第 3 步以下流程。

**caveats**：

- 节气交接前后 1 小时内（甚至 1 天内）的盘，必须重新由 tool 校核；不允许人工估算。
- 凌晨子时、夜子时的处理交由 paipan 工具的 `time_zone` / `wee_hours_policy` 选项。

## QP-04 调候用神不透时的"虚用"流程

**目的**：当本书规则要求的天干在盘中不透时，给出回退处理。

**步骤**：

1. 检查地支藏干 → 是否有该天干的"藏"。
2. 若有藏 → 标记"虚用"，输出"该用神在地支藏干中存在，但天干未透；其势减弱"。
3. 若藏干被冲合 → 标记"虚用受损"。
4. 若藏干也无 → 标记"调候缺失"，**禁止**强行用相邻天干替代（如丙缺补丁）。
5. 缺失时回到 QP-02：进入旺衰 / 格局合参，重新判断。

**caveats**：

- "虚用"是教学语义；命例的实际效力须由综合判断确定。
- 不允许臆造调候用神来补缺。

## QP-05 用神组合相互作用核查（"配齐与不悖"）

**目的**：本书反复强调"X Y 两透者贵"、"X Y 不悖者贵"。本流程明确何谓"配齐 / 不悖"。

**步骤**：

1. **配齐**：所要求的两个或三个天干同时出现于年/月/时三干（不强求月时透）。
2. **不悖**：两个用神之间无以下关系：
   - 直接相合化掉（如丙辛合化水）；
   - 直接相克（如壬水克丙火，注意此项在丙日"既济"非"克身"，需上下文判别）；
   - 被同盘他干夹冲。
3. **既济**：火与水、土与木在合法克制下成"既济"（互济、互成），不视为悖。
4. **悖**：用神被克合化掉，即使天干透出也不算"配齐"。

**caveats**：

- "贵"在本流程中只是子平派传统标记，不作社会意义判断。
- 化神成败、合化条件须查 `sanming-tonghui` 五合化气章。

## QP-06 与《滴天髓阐微》"寒暖燥湿"互参流程

**目的**：本书的调候组合常需与滴天髓"寒暖燥湿"章互证。

**步骤**：

1. 走完 QP-01 取出本书调候用神组合。
2. 跳到 `bazi/ditiansui-chanwei/rules.md` 查 DR-NN-NN（寒暖燥湿章）。
3. 比对两书结论：
   - 一致 → 直接采纳。
   - 不一致 → 按 QP-02 冲突裁判。
4. 输出"双书互证 / 双书分歧"标记。

**caveats**：

- 双书互证是常见用法，但不是本书的硬性规定；只在主 skill 需要可信度上抬时调用。

## QP-07 写作输出层（给主 skill 的语义包装）

**目的**：将本书取出的调候用神组合，包装成主 skill 可直接输出的语义。

**步骤**：

1. 输出格式：
   - "调候层（《穷通宝鉴》）：日干 D 生于 M 月（季节 S），调候用神为 [用神组合]，盘中状态：[配齐/有损/虚用/缺失]。"
2. **禁止**直接复制本书原文超过 80 字（参 quote-index.md）。
3. **禁止**输出"必富贵 / 必贫贱"等铁口判语；调候本身不能独立支撑。
4. 必须提示"本结论需与旺衰（《滴天髓阐微》）、格局（《子平真诠》）合参"。
5. 健康、寿命、子嗣、女命相关判语 → 走 `matrices/safety-redlines.md`；不在本 pack 提供。

**caveats**：

- 主 skill 接到本流程输出后，仍可能因路由层（如怀孕、医疗、法律边界）拒绝输出。
- "贵格 / 贱格"在本 pack 仅作历史标记，不作社会评价。
