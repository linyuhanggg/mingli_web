# 五行精纪 — 流程库（procedures）

> 全书覆盖型流程梳理。**所有需要排盘的步骤一律依赖 `tool.bazi.paipan`，禁止 LLM 手算干支/纳音/神煞**。本流程库供文化研究与教学辅助参考，不替代任何专业咨询。

## P-WX-01 纳音五行查取与判读

- **purpose**: 给定四柱（年/月/日/时），查出四柱纳音并判读五行偏旺/缺。
- **steps**:
  1. 依赖 `tool.bazi.paipan` 起四柱（年/月/日/时干支），不得手算。
  2. 依赖 `tool.bazi.paipan` 返回四柱纳音五行（六十甲子纳音）。
  3. 判读：以日柱纳音为本命纳音；统计四柱纳音五行分布。
  4. 参照《五行精纪·卷一/二·六十甲子上下》各甲子条目，提取纳音象义（如"海中金不畏丑未"、"炉中火得木而生"）。
  5. 输出：本命纳音 + 五行强弱 + 文化象义参考。
- **tool_dependency**: `tool.bazi.paipan`
- **source_chapter**: 卷一·甲子海中金至癸巳长流水；卷二·甲午沙中金至癸亥大海水
- **caveats**: 纳音五行 ≠ 真五行（甲己合化土），二者并存；不得替代真五行用神判断；不作铁口断。
- **verified**: false

## P-WX-02 乾神十干与支神十二支判读

- **purpose**: 判读日主天干（乾神）与四支（支神）的本气、生克与神煞所属。
- **steps**:
  1. 依赖 `tool.bazi.paipan` 起四柱，提取日主天干与四支地支。
  2. 参照卷三·甲乙、卷四·丙丁、卷四·戊己、卷五·庚辛、卷五·壬癸条，提取日主天干气性（甲为栋梁、乙为枝叶、丙为太阳等）。
  3. 参照卷六·支神条，提取地支本气（子为癸水、寅为甲木+丙火+戊土等）与所主神煞。
  4. 参照卷七·五行一、卷八·五行二、卷九·五行三，对照纳音五行+真五行综合判读。
  5. 输出：日主气象 + 四支气象 + 五行综合判读。
- **tool_dependency**: `tool.bazi.paipan`
- **source_chapter**: 卷三-五·乾神十干；卷六·支神；卷七-九·五行一二三
- **caveats**: 仅作命书文化研究参考，不作铁口断。
- **verified**: false

## P-WX-03 吉贵神扫描（天乙/禄/马/三奇/华盖等）

- **purpose**: 系统扫描四柱中的吉贵神煞（天乙贵人、禄、马、三奇、华盖、金舆、学堂等）。
- **steps**:
  1. 依赖 `tool.bazi.paipan` 起四柱并返回神煞列表（天乙贵人/禄/马/三奇/华盖/金舆/学堂/科名/荫补/武职等）。
  2. 参照卷十三·吉贵神、卷十四·天乙贵人、卷十五·禄、卷十六·马、卷十七·禄马官神、卷十八·印瑤食三奇合、卷十九·进神正印库墓财、卷二十·华盖金舆学堂科名荫补武职，提取每个神煞的吉象义。
  3. 标注命中神煞与所在柱位（年/月/日/时）。
  4. 输出：吉贵神清单 + 各神煞文化象义 + 古书吉断参考（仅作研究）。
- **tool_dependency**: `tool.bazi.paipan`
- **source_chapter**: 卷十三-二十·吉贵神类；卷廿一-廿二·贵局上下
- **caveats**: ⚠️ 神煞断语为古代命学概念，**仅作命书文化研究参考**；不作铁口断富贵贫贱；不替代现代职业/教育规划咨询。
- **verified**: false

## P-WX-04 凶神凶煞扫描（劫煞亡神/三刑/空亡/羊刃/孤辰寡宿）

- **purpose**: 系统扫描四柱中的凶神凶煞，标注并强 reframe。
- **steps**:
  1. 依赖 `tool.bazi.paipan` 起四柱并返回凶煞列表（劫煞、亡神、三刑、六害、空亡、冲破、金煞、羊刃、孤辰、寡宿、伏吟、反吟等）。
  2. 参照卷廿三·凶神、卷廿四·劫煞亡神、卷廿五·三刑六害空亡、卷廿六·冲破金煞、卷廿七·凶煞，提取每个凶煞的古书断语。
  3. 标注命中凶煞与所在柱位。
  4. **强制 reframe 输出**：所有凶煞断语统一加 caveats 模板（"涉及寿夭/疾病/婚配/家庭，仅作文化研究参考"）。
  5. 输出：凶煞清单 + 文化象义 + 现代 reframe 提示。
- **tool_dependency**: `tool.bazi.paipan`
- **source_chapter**: 卷廿三-廿七·凶神凶煞类
- **caveats**: ⚠️ 凶煞断语含大量古代命学**铁口断语**，本流程**严格 reframe**；不得用于断病、断寿、断婚、断子、断刑狱；不替代医学/法律/婚姻咨询；现代须批判性阅读。

## P-WX-05 男女命与小儿关煞判读

- **purpose**: 古书男女命与小儿关煞条目判读，**特别强 reframe**。
- **steps**:
  1. 依赖 `tool.bazi.paipan` 起四柱。
  2. 男命：参照卷廿九·男女命父母位、卷三十·子息僧道九流吏卒形貌，提取古书男命断语（限职业/家庭文化象义层）。
  3. 女命：**严格 reframe**——参照同卷古书女命条（伤夫煞、克子煞等），仅作命书历史研究参考，**严禁用于现代女性命运判读**；提示用户该层含明显父权时代偏见。
  4. 小儿：参照卷廿八·杂释小儿，仅作命书文化研究展示；**严禁**用于断小儿生死/疾病。
  5. 输出：男命/女命/小儿古书条目（带强 reframe 标注）。
- **tool_dependency**: `tool.bazi.paipan`
- **source_chapter**: 卷廿八·杂释小儿；卷廿九·男女命父母位；卷三十·子息僧道九流吏卒形貌
- **caveats**: ⚠️ **特别强 reframe**：女命条目含父权时代偏见，仅作历史研究；小儿关煞**严禁**用于断小儿命运；男命职业断语仅作文化参考，不替代现代职业咨询。

## P-WX-06 大运/小运/太岁岁运推断

- **purpose**: 排出大运/小运/太岁岁运并提取古书运程象义。
- **steps**:
  1. 依赖 `tool.bazi.paipan` 起大运（顺逆排法）、小运、流年太岁。
  2. 参照卷三十二·大运小运、卷三十三·二运太岁、卷三十四·岁运，提取每运的古书象义条目。
  3. 标注命主当前所在大运、流年与古书象义对照。
  4. 输出：运程象义参考（大运/小运/流年三层）。
- **tool_dependency**: `tool.bazi.paipan`
- **source_chapter**: 卷三十二-三十四·运程类
- **caveats**: 运程古书断语含吉凶铁口断，**仅作命书文化研究参考**；不作具体年份的祸福铁口断；不得用于股市/投资/医疗/法律决策。

## P-WX-07 论疾病/壽夭判读（强 reframe）

  4. 输出：古书条目原文 + 强 reframe 标注。
- **tool_dependency**: `tool.bazi.paipan`
- **source_chapter**: 卷三十一·子息僧道九流吏卒形貌·疾病壽夭
- **caveats**: ⚠️ **严禁**作铁口断病/断寿；**严禁**替代医学诊断；仅作命书历史/文化研究层；现代须严格 reframe，宜批判性阅读。
