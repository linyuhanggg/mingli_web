# 神相全编 — 规则集

> 全书 9 卷，本 rules 抽取 ~38 条代表性规则，编号 `SR-NN-MM`（NN=01..09 表卷次，MM=01..NN 表卷内序号）。
> 旁证层；不参与命盘硬判断；含贬义条文统一附 reframe + safety-redlines caveats。
> 字段：`id` / `statement` / `source_chapter` / `source_anchor` / `applicable_to` / `caveats` / `verification_status`。

---

## 通用 caveats（适用于所有规则）

1. **旁证层**：本书所有规则均**仅作旁证参考，不参与命盘硬判断**。命盘（八字 / 紫微 / 七政）冲突时一律以命盘为主。
2. **贬义 reframe**：凡涉及"贱""恶""凶""愚""贫"等价值判语，调用时必须执行 reframe（替换为中性描述 + 现代视角）。
3. **safety-redlines**：寿命 / 死亡 / 疾病 / 富贵贫贱 / 子嗣 / 婚配 不得对具体个人输出硬判断。
4. **现代禁用**：流年部位、十二宫、何知歌、凶相诸格、六恶六贱、富贵贫贱诸相 在涉及具体个人时**禁用**。
5. **不接收照片**：本规则集不支持基于真人面部图像的判断输出。
6. **动物比喻**：仅作形态分类标签返回，不输出原文吉凶判语。
