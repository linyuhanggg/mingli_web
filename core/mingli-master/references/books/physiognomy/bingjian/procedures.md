# 冰鉴 — Procedures

> 本书属 **旁证层**。流程不替代命盘判断；仅给出"旁证查询 / 输出包装"流程。
> 流程编号 `BP-NN`。
> **禁止**：本书任何流程都不允许"凭相貌单独决定命运"。

---

## BP-01 旁证查询主流程

**目的**：当主 skill 已有命盘类（bazi/ziwei/xingming）的主结论后，调用本流程为该结论提供"旁证标记"。

**前置条件**：

1. 命盘主结论已由命盘类 pack 给出。
2. 用户已主动询问"相貌 / 神骨 / 气质" 等相术类问题，且已知情同意。
3. 用户提供了**自我描述**（不是他人代描；不是图像识别）；本流程不接收照片输入。

**步骤**：

1. **判主结论存在**：若主结论缺失 → **拒绝**进入相术旁证；先回到命盘流程。
2. **收集自我描述**：用户主动提供的"神骨 / 容貌 / 情态 / 声音"等关键词。
3. **检索 chapter-map**：定位最贴近用户描述的章节。
4. **检索 rules.md**：取该章下的 BR-NN-MM 规则列表。
5. **过滤贬义条文**：含"贫贱 / 敗類 / 不寿 / 子嗣不立 / 一世穷 / 赴法场"等强贬义条文的规则，**仅取语义骨架**，不直接复述。
6. **输出旁证语义**：以"传统冰鉴语义看，您的描述近似于 [章 / 术语]"包装；附"仅作旁证参考，不参与命盘硬判断"。
7. **不做的事**：不作"必富贵"、"必贫贱"、"必短寿"、"必生子"等任何铁口判语。

**caveats**：

- 不接收照片 / 图像 / 视频输入；**绝不**做基于图像的相貌识别。
- 不主动追问相貌细节；只以用户已主动提供的描述为限。
- 用户表达对自身相貌的负面情绪时，立即停止旁证查询，回到关怀对话。

## BP-02 命盘 vs 相术冲突裁判

**目的**：当命盘主结论与本书旁证结论冲突时，给出裁判。

**步骤**：

1. **冲突识别**：命盘主结论 R_C ∈ {正面 / 中性 / 负面}；旁证结论 R_B ∈ {同方向 / 反方向 / 中性}。
2. **裁判规则**：
   - R_C 与 R_B 同方向 → 旁证视为弱辅证。
   - R_C 与 R_B 反方向 → **以命盘 R_C 为准**；旁证仅作"参考层留痕"。
   - R_C 中性、R_B 强方向 → **不允许**旁证抬升为主结论；输出"命盘中性，相术语义偏 X，仅作语义参考"。
3. 任何情况下，**绝不**仅凭旁证决定结论方向。

**caveats**：

- "正面 / 负面" 是技术裁判语，不指向具体生活事件。
- safety-redlines 范围（寿命、疾病、灾祸等）一律屏蔽两方结论，仅作"传统记录"。

## BP-03 神骨 / 情态 提取流程（最常用）

**目的**：用户问"我的神骨 / 气质如何"等问题时，按本流程输出。

**步骤**：

1. 取用户描述中可对应的关键词（如"专注"、"散漫"、"内敛"、"飞扬"等）。
2. 映射到 BR-01-02（神之澄清到底）/ BR-01-03（神之三类下品）/ BR-04-01（情态四分）。
3. **优先使用正面 / 中性条文**（澄清到底、情态四分本身），避免直接套用三类下品。
4. 输出格式：
   - "传统冰鉴《神骨章》/《情态章》语义中，您所描述的状态可以对应 [术语] / [情态名]。"
   - "本对应仅作旁证语义参考；不构成命盘判断。"
5. 用户若主动追问负面对应（如"我是否近奸 / 近粗"）：
   - 给出术语含义（古典语义还原）；
   - **明确告知**该判语属古典语境，不做现代人格诊断；
   - 推荐用户用现代心理学量表自我了解。

**caveats**：

- 永不主动指认用户为"敗類 / 隐流 / 近奸 / 近粗"。
- 即使用户自我贴标签，也回到中性 reframe，不做强化。

## BP-04 气色查询屏蔽流程（safety-redlines）

**目的**：当用户问"我最近气色如何 / 是否有灾"时，按本流程屏蔽。

**步骤**：

1. **拒绝直接预测**：不输出 BR-07-04（色忌白青）"祸生不测 / 灾晦催人 / 前程退落 / 禍患再三" 等内容作为预测。
2. **健康话题分流**：
   - 若用户描述面色变化（如发青、发白、发黄）→ 推荐就医，**不做相术诊断**。
3. **气色作语义还原**：
   - 仅在用户主动了解"古典气色四级模型"时，给出 BR-07-02 终身/年/月/日 语义；
   - 不附"祸福"、"吉凶"判语。
4. **输出格式**：
   - "古典《气色章》将气色分为终身/年/月/日四级。这是传统色相分类，不作健康或祸福预测；如有面色变化，建议医学就诊。"

**caveats**：

- 这是 safety-redlines 强制流程，**不可由用户偏好覆盖**。

## BP-05 写作输出语义包装（给主 skill）

**目的**：将本书旁证结论包装为主 skill 可直接输出的语义。

**步骤**：

1. **必带前置语**：
   - "在传统《冰鉴》语义里——"
   - "这是古典相术语义还原，仅作旁证参考——"
2. **必带后置语**：
   - "本对应**不参与命盘硬判断**。"
   - 涉及贬义条文时再加："此为传统语境用语，现代不作人格 / 身份评价。"
3. **禁止**：
   - 直接复制原文 >80 字（参 quote-index.md）。
   - 输出寿命、灾祸、贫富的硬判结论。
   - 主动给用户"贴贬义标签"。
4. **建议**：
   - 涉及"喜淫 / 敗類 / 隐流"等表述时，仅作"古典语义还原 + 不作现代评价"两步包装。

**caveats**：

- 包装层不可独立工作；必须在 BP-01 已完成命盘主结论的前提下使用。

## BP-06 旁证层留痕流程

**目的**：每次相术旁证查询都留痕，便于后续审计与召回。

**步骤**：

1. 记录字段：用户描述关键词、命中 BR 编号、是否触发 reframe、是否触发 safety-redlines、最终输出语义。
2. 留痕信息**不**包含敏感识别信息（不存照片 / 生物特征 / 个人身份）。
3. 留痕仅供本 pack 的 validation 与召回使用，不外发。

**caveats**：

- 留痕要符合 matrices 层的 privacy-policy 约束。
